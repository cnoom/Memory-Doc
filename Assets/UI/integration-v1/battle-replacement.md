# 战斗界面正式资源替换指引

日期：2026-10-17。目标画布1920×1080。本文用于将V05的旧示例组件替换为已批准的独立资产。U01已于2026-10-21按用户授权视觉定稿，可按稿接入；未覆盖状态继续采用既有规范。不能把U01截图直接铺作游戏界面，亦不能把本文当成游戏实现。

## 入口和文件

- 资源路径、尺寸、SHA256、批准状态：仓库docs/design/art-inventory/developer-asset-registry.json；交付包资源索引.json。
- 机器可读映射与布局：本目录battle-replacement.json。assetPaths以Assets/UI或美术资源v1根目录为基准。
- 组合预览：仓库ImageReview/batches/battle-u01/normal.png和boss_phase3.png，仅作替换检查。保留原V05确认参考，不覆盖它。
- 通用规则：本目录README.md。原图、源像素窗口与屏幕坐标是不同单位，不能混用。

## 卡面合成与字号

C04源尺寸960×1280：window=[156,300,649,496]，专用windowMask为cardframes/border_card_attack_ornate_c04_window_mask.png；title=[235,153,545,107]，effect=[180,858,600,280]。其他框必须独立读spec，不能复用这组数值。U01读书笔记使用cover，其他插画逐张检查剑尖/主体裁切；不要把有色或黑色画面误当透明瑕疵统一抠色。

文本始终在屏幕层单独渲染。U01卡名中心(76,31)、13px宋体，摘要中心x72、y136/151/165、11px黑体；均为卡格局部坐标，颜色#252F32。**这是当前预览的密度，不是已验证的最低可读字号**。实际客户端要检查小卡阅读；完整效果放详情，不允许只把大卡文本烘焙后整体缩小。不为放大文字改变牌阵格位。

常规正文黑体；标题宋体。浅面板正文#252F32，深底文字#F1EEE2，辅助#48575A，选中/焦点#648891。按钮四态字体颜色按对应页面token与integration-v1总说明，不按贴图明暗猜色。敌人名32px、学者名29px、行动标题23px、意图25px、辅助15–18px。数值必须读实际状态。

## 接入顺序与验收

1. 建立ID映射并校验hash，先替换无人背景与独立立绘，检查没有双人物。
2. 替换卡背与所有框，逐框使用遮罩；检查16格固定、背面无信息泄露、标记层不盖卡文。
3. 替换HUD、生命条、行动条、按钮；图形与文本分别绑定；条段数量随Boss阶段和修饰变化。
4. 导入字体；验证长名、多词条、多状态及真实颜色。低字号或溢出列为待解决项，不能用截断掩盖。
5. 用上述夹具输出1920×1080同状态截图，与U01做50%叠加；再与V05核对结构及已批准行为。新增构图变化单独列出，不能宣称全部像素一致。
6. 测720p、各Boss阶段、生命0/满、临界、详情和暂停；重点检查角色/HUD避让、字体、贴图边缘、输入阻断、重复提交。

交付至少包含：asset ID映射、布局配置、实机截图、对照差异表、未解决项。源脚本tools/art/scripts/compose_battle_u01.py仅为文档仓库组装工具，不移植其示例状态作为战斗逻辑。

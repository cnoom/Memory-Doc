## 1. 游戏概述

### 1.1 一句话概述

《记忆勇者》是一款以"记忆配对"为核心机制的卡牌肉鸽游戏。玩家在背面朝上的牌阵中凭记忆翻开卡牌寻找匹配，匹配成功触发卡牌效果来击败单一强敌。每一次翻牌都是行动，也推进敌人的攻势——记忆越准，代价越小。

### 1.2 核心卖点

- **记忆即策略**：记住牌面位置是核心技能，高手与新手之间有清晰的技艺差距。
- **词条即能力**：卡牌上的词条是独立的被动特性，可能改变匹配规则、在翻牌时触发效果、或持续生效影响桌面——词条不限于"匹配标签"。
- **翻牌即代价**：没有能量、没有回合，每一次翻牌都推进敌人行动条，每个决策都有重量。

### 1.3 参考作品

- **杀戮尖塔（Slay the Spire）**：Run结构、牌组构建、遗物系统、敌人意图。
- **记忆配对游戏（Memory/Concentration）**：桌面翻牌配对的核心玩法。

## 2. 核心战斗机制

### 2.1 战斗目标

- **胜利条件**：敌人血量归零。
- **失败条件**：玩家血量归零。

### 2.2 玩家资源

| 资源 | 说明 |
|---|---|
| **血量（HP）** | 持久资源，跨战斗保留（run内）。归零 = 游戏结束。 |
| **格挡（Block）** | 临时防御资源，抵消受到的伤害。每次受击时优先消耗格挡，格挡值不跨战斗保留（每场战斗开始为0）。 |

### 2.3 翻牌与匹配流程（精确规则）

战斗桌面铺满背面朝上的卡牌。玩家通过"翻牌"行动来触发效果和配对。

**核心约束：任意时刻桌面上最多一张正面朝上的牌。**

#### 翻牌操作的分步结算：

```
玩家点击一张背面牌翻开
│
├─ 步骤1: 将桌面上其他正面牌翻回背面
│
├─ 步骤2: 这张牌正面朝上
│
├─ 步骤3: 结算这张牌的"翻牌时"词条效果
│         （仅含"翻牌时触发"词条的牌才有效果）
│
├─ 步骤4: 匹配判定
│         检查这张牌与步骤1中刚翻回的那张牌是否存在匹配关系
│         ├─ 匹配成功 → 进入步骤5
│         └─ 不匹配 → 这张牌保持正面朝上（等待下一次翻牌判定）
│
├─ 步骤5: 匹配结算（若匹配成功）
│         ├─ 触发两张牌各自的基础效果
│         ├─ 触发促成匹配的词条加成效果
│         ├─ 触发"配对时"词条效果
│         ├─ 触发"被消除时"词条效果
│         └─ 两张牌从桌面消除
│
└─ 步骤6: 行动条 +1（所有效果结算完毕后的最后一步）
```

**特例——病毒牌（敌人污染能力塞入的干扰牌）：**
病毒牌走独立流程，不参与步骤4~5的匹配判定：
- 翻开时（步骤3）：触发负面效果 → 立即从桌面移除。
- 无法匹配、不等待、不留在桌面。
- 翻开它的代价仍为行动条 +1（步骤6照常执行）。

**关键规则：**
- 行动条 +1 永远是最后一步，发生在所有卡牌效果结算之后。
- 这意味着"行动条 -X"的卡牌效果先结算，再执行 +1，为操控行动条提供了设计空间。

#### 翻牌流程示例：

1. 玩家翻开第一张牌（A）→ A 正面朝上，行动条 +1，A 的翻牌词条（如有）触发。
2. 玩家翻开第二张牌（B）→ A 翻回背面，B 正面朝上，B 的翻牌词条触发。
3. 匹配判定：B 与 A 是否匹配？
   - **匹配** → 结算效果，两牌消除，行动条 +1。
   - **不匹配** → B 留在桌面正面。行动条 +1。
4. 玩家翻开第三张牌（C）→ B 翻回背面，C 正面朝上...（循环）

### 2.4 匹配规则

**默认匹配规则 = 同名匹配。**

两张卡牌**名称完全相同**才能匹配。这是绝大多数卡牌的匹配方式。

- 不存在相似卡名（如"火球术"和"大火球术"）。卡牌名称是唯一标识。
- 特殊匹配关系只能通过**匹配型词条**实现（见 3.2 节）。

### 2.5 行动条机制

```
行动条: 0 ──→ [阈值] ──→ 敌人行动 ──→ 重置为0
         翻牌+1
         重新铺满+2
```

- 行动条从 0 开始。
- **玩家每翻一张牌，行动条 +1**（在所有效果结算后）。
- **玩家主动"重新铺满桌面"，行动条 +2**。
- 行动条达到敌人阈值 → 敌人执行意图所示的行动 → 行动条重置为 0。
- **配对成功不影响行动条**。防御完全依赖卡牌效果。
- 某些卡牌效果可以减少行动条（如冰冻状态、特定词条）。

### 2.6 批次补充规则

桌面牌从玩家牌组抽取。当桌面上牌被消耗后，按以下规则补充：

**补充触发条件：**
- 当前桌面上所有**可配对的牌**都被消除后，才补充新一批。
- "可配对"指：桌面上是否存在至少一对能匹配的牌。
- 残留的未配对牌（无法互相匹配的单牌）不触发补充，它们留在原位。

**补充方式：**
- 残留的未配对牌**位置不变**。
- 新牌从牌组抽取，铺到空出的槽位。
- 玩家之前翻过的残留牌，其位置和内容信息对玩家有效（凭记忆可利用）。

**批次的意义：**
- 每一批 = 一个小目标，"清掉这批所有配对"有清晰的成就感。
- 批次切换时记忆"归零重来"，但这是玩家主动完成带来的，挫败感低。
- 残留牌创造跨波次的记忆价值——下一批可能补上同名牌，凭记忆直接配对。

### 2.7 重新铺满桌面（主动操作）

玩家随时可以选择"重新铺满桌面"，作为卡住时的紧急逃生手段。

**效果：**
- 当前桌面所有牌（包括残留牌）进入弃牌堆。
- 从牌组重新抽牌铺满桌面。

**代价：**
- 行动条 **+2**。

**用途：**
- 桌面残留牌无法配对且玩家记不住/找不到时，强行重置。
- 配合牌组循环（牌组耗尽 → 弃牌堆洗回），重新铺满 = 一次"洗牌重抽"。

### 2.8 牌组循环

战斗中存在三个牌区：

| 牌区 | 说明 |
|---|---|
| **牌组（Deck）** | 未抽到桌面的牌，桌面补牌从此抽取。 |
| **桌面（Board）** | 当前铺开的牌（背面/正面朝上）。 |
| **弃牌堆（Discard）** | 被消除的牌、被"重新铺满"清除的牌。 |

**牌组耗尽规则：**
- 当牌组抽空时，弃牌堆的所有牌重新洗回牌组。
- 消耗堆的牌**不参与**重新洗牌（它们在本场战斗内永久消耗）。

> 注意：消耗堆只在单场战斗内生效。战斗结束后，所有牌（包括消耗堆）回到牌组，供下一场战斗使用。详见 6.2 节。

### 2.9 战斗结束

- **胜利**：敌人血量归零。结算奖励（卡牌/金币/遗物）。
- **失败**：玩家血量归零。Run 结束。

## 3. 卡牌与词条系统

### 3.1 卡牌结构

每张卡牌由以下部分组成：

| 字段 | 说明 | 示例 |
|---|---|---|
| **名称** | 卡牌的唯一标识，决定同名匹配 | 「火球术」 |
| **类型** | 攻击 / 技能 / 护盾 等 | 攻击 |
| **稀有度** | 普通 / 罕见 / 稀有 | 普通 |
| **基础效果** | 配对成功时触发的主要效果 | 造成6点伤害 |
| **词条** | 0~N个，卡牌的被动特性列表 | 见 3.2 节 |

### 3.2 词条系统（核心设计）

**词条 = 卡牌的被动特性。** 词条不只是"匹配标签"，它是挂在卡牌上的规则修饰符，可以是任意类型的效果。

#### 词条触发时机（5种）

| 时机 | 说明 | 示例 |
|---|---|---|
| **翻牌时** | 这张牌被翻开时触发（无论是否配对） | "随机翻开周围一张背面牌" |
| **配对时** | 这张牌参与匹配成功时触发（基础效果之外） | "额外造成2点伤害" |
| **进入桌面时** | 这张牌被铺到桌面时触发 | "相邻牌获得+1伤害" |
| **被消除时** | 这张牌因配对消除时触发 | "抽1张牌到桌面" |
| **持续型** | 这张牌**背面朝上**在桌面上时持续生效 | "相邻牌的翻牌效果+1" |

**持续型词条的关键规则：**
- 持续效果**只在背面朝上时生效**。
- 牌被翻开后，持续效果**暂停**（翻开 = 暴露，效果失效）。
- 这创造了策略考量：为了利用持续效果，可能要避免翻某些牌，但那也意味着放弃它的配对机会。

#### 词条类型分类

**① 匹配型词条（改变匹配规则）**

这是唯一能突破"同名匹配"默认规则的词条类型。声明特殊的跨名匹配关系。

| 词条 | 效果 | 说明 |
|---|---|---|
| `[共鸣]` | 可与任意其他带`[共鸣]`的牌匹配 | 法术系通用共鸣 |
| `[剑盾]` | `[剑]`与`[盾]`可跨名匹配 | 攻守连招 |

这类词条是**稀缺的**，只出现在少数特殊卡牌上。绝大多数卡牌只能同名匹配。

**② 翻牌型词条（翻开即触发）**

| 词条 | 效果 |
|---|---|
| `[窥探]` | 翻开时：随机翻开周围一张背面牌 |
| `[侦察]` | 翻开时：揭示相邻1张牌的内容（短暂可见） |
| `[护盾]` | 翻开时：获得2点格挡 |

**③ 持续型词条（背面朝上时生效）**

| 词条 | 效果 |
|---|---|
| `[守护光环]` | 背面朝上时：相邻牌的基础效果+1 |
| `[威压]` | 背面朝上时：敌人行动条增长-1（每次翻牌+0） |

**④ 消耗型词条**

| 词条 | 效果 |
|---|---|
| `[消耗]` | 这张牌配对消除后进入消耗堆，而非弃牌堆。本场战斗内不再可用。 |

**消耗规则细节：**
- 仅带`[消耗]`词条的牌进消耗堆，它的配对搭档正常进弃牌堆。
- 消耗只在单场战斗内生效，战斗结束后所有牌（含消耗堆）回到牌组。

**⑤ 功能型词条（配对时/被消除时/进入桌面时）**

| 词条 | 触发时机 | 效果 |
|---|---|---|
| `[连锁]` | 配对时 | 额外触发桌面另一张牌的翻牌效果 |
| `[回响]` | 被消除时 | 抽1张牌到桌面 |
| `[腐化]` | 进入桌面时 | 相邻牌的基础效果-1 |

#### 词条数量

- 每张卡牌的词条数量**不设上限**。
- 实际设计中通过稀有度和平衡性控制，普通卡通常 0~1 个，稀有卡可以更多。

#### 匹配判定（精确算法）

当玩家翻开第二张牌时：

1. 取第一张牌（刚翻回的）的名称 `N1` 和词条集 `T1`。
2. 取第二张牌的名称 `N2` 和词条集 `T2`。
3. 判定匹配：
   - **同名匹配**：`N1 == N2` → 匹配成功。
   - **词条匹配**：检查是否存在词条对 `(a, b)`，其中 `a ∈ T1`，`b ∈ T2`，且 `a` 声明了与 `b` 的匹配关系 → 匹配成功。
4. 只要满足任一条件 → **匹配成功**。

## 4. 敌人系统

敌人是玩家所有决策的压力来源。核心职能：用行动条制造时间压力，用意图系统提供策略信息，用特殊能力制造变数。

### 4.1 敌人结构

```
敌人 = {
  名称:         「石巨人」
  最大血量:     当前血量 / 最大血量
  行动条:       当前值 / 阈值
  意图:         下次行动将做的事（对玩家完全可见）
  能力:         被动效果列表
  状态:         增益/减益列表
  阶段:         （仅Boss）当前阶段及切换条件
}
```

### 4.2 意图系统

**敌人完全公开下次行动**，包括类型和数值。借鉴杀戮尖塔的意图系统，玩家可据此规划配对策略。

| 意图类型 | 显示内容 | 玩家应对策略 |
|---|---|---|
| **攻击** | "下次攻击造成X点伤害" | 优先配护盾/回血牌 |
| **蓄力** | "正在蓄力，下次攻击翻倍" | 趁机全力输出 |
| **防御** | "将获得X点护甲" | 可能需要破甲手段 |
| **特殊** | "将使用[能力名]" | 根据效果应对 |
| **狂暴** | "行动条阈值降低" | 加速击杀 |

意图在行动条重置时刷新——玩家始终能看到敌人下次会做什么。

### 4.3 敌人能力

敌人拥有类似卡牌"词条"的被动特性，用来制造变数。

**核心设计原则：敌人只能干扰桌面牌的物理状态，不能干扰玩家的记忆。** 系统层面不存在"已被记忆"状态。系统只记录牌的位置和内容，玩家记不记得是玩家自己的事。敌人只能动牌，不能动记忆。

#### 能力分类

**位置干扰型：**
| 能力 | 效果 |
|---|---|
| 「混乱」 | 行动时随机交换桌面2张牌的位置 |
| 「换位」 | 行动时将桌面最左和最右的牌互换 |
| 「洗牌」 | 行动时重新随机排列所有桌面牌 |

**可用性干扰型：**
| 能力 | 效果 |
|---|---|
| 「封锁」 | 行动时给一张桌面牌加`[封锁]`标记，暂时无法参与匹配 |
| 「冰封」 | 行动时冻结一张桌面牌，翻开时不触发词条效果 |

**桌面污染型：**
| 能力 | 效果 |
|---|---|
| 「污染」 | 行动时往桌面塞一张病毒牌（无法匹配、翻开即触发负面效果并移除） |
| 「增生」 | 行动时复制一张桌面牌（增加一张同名牌，可能帮助或干扰玩家） |

**节奏施压型：**
| 能力 | 效果 |
|---|---|
| 「急躁」 | 行动条阈值低（如7而非10），更频繁攻击 |
| 「重击」 | 攻击伤害高但行动条阈值也高 |
| 「连击」 | 行动条满时连续攻击2次 |
| 「狂暴」 | 血量低于50%时行动条阈值降低 |

#### 病毒牌

敌人通过"污染"能力塞入桌面的干扰牌。

**特性：**
- 不属于玩家牌组，是敌人专属的特殊牌。
- **无法匹配**——不能与任何牌配对。
- **翻开即结算**——翻开时触发负面效果，然后立即从桌面移除。
- 不会永久卡死桌面，玩家有多种处理方式：
  - 不小心翻到 → 承受负面效果 + 行动条 +1，但病毒牌被清除。
  - 记得它在哪 → 主动避开，但它持续占位阻碍配对。
  - 主动翻它清掉 → 承受代价换桌面干净。
  - 花行动条 +2 重新铺满 → 不承受病毒效果，但敌人加速。

### 4.4 普通敌人 vs Boss

**普通敌人：**
- 1~2 个能力。
- 单阶段。
- 行动条阈值较低（更快结束战斗）。
- 血量适中。

**Boss：**
- 3~4 个能力。
- **多阶段**——血量降到阈值触发阶段切换。
- 阶段切换时改变能力组合、行动条阈值、意图模式。
- 可能改变桌面规则（如阶段2开始封锁词条）。
- 必掉稀有遗物。

#### Boss 设计示例

```
═══════════════════════════════════════
  记忆吞噬者（第一章 Boss）
  ─────────────────────────────────────
  阶段1（100%~60%血量）：
    行动条阈值: 10
    能力: [混乱]——每次行动随机交换2张牌位置
    意图模式: 攻击 / 蓄力 交替
  
  阶段2（60%~30%血量）：
    行动条阈值: 8（更频繁）
    能力: [混乱] + [封锁]
    意图模式: 攻击 / 特殊（封锁词条）
  
  阶段3（30%~0%）：
    行动条阈值: 8
    能力: [混乱] + [封锁] + [污染]
    意图模式: 狂暴连击
═══════════════════════════════════════
```

## 5. 状态效果系统

战斗中存在持续性的状态效果，影响敌人和玩家。状态效果是卡牌策略的延伸。

| 状态 | 效果 | 来源 |
|---|---|---|
| **灼烧** | 每次行动条满时受到X点伤害 | 火焰系卡牌/词条 |
| **冰冻** | 行动条增长-1（每次翻牌+0），持续N拍 | 寒冰系卡牌/词条 |
| **护甲** | 抵消下次受到的X点伤害 | `[护盾]`词条 |
| **易伤** | 受到伤害+50%，持续N拍 | 特定卡牌 |
| **虚弱** | 敌人攻击伤害-25%，持续N拍 | 特定卡牌 |

> 注：上表中"火焰系"、"寒冰系"为**示例性的设计方向**，具体由哪些卡牌/词条施加这些状态，在卡牌内容设计阶段确定。状态效果系统是框架，不绑定特定词条。

## 6. Meta系统

### 6.1 Run结构：节点地图

杀戮尖塔式分支地图。玩家在地图上选择路径，逐节点推进。

```
        [战斗]         [精英]
       /      \       /      \
  [战斗]──[事件]──[商店]──[战斗]──[篝火]
       \      /       \      /
        [商店]         [事件]
              \        /
              [Boss]
```

#### 节点类型

| 节点 | 说明 |
|---|---|
| **战斗** | 普通战斗，胜利后获得奖励（卡牌/金币/遗物） |
| **精英** | 强敌，高风险高回报，必掉遗物 |
| **商店** | 花金币买卡牌、遗物、移除卡牌 |
| **篝火** | 回血 或 升级一张卡 |
| **事件** | 随机遭遇，做选择获得奖励或惩罚 |
| **Boss** | 章节最终Boss，必掉稀有遗物 |

#### 章节结构

一层地图 = 一个章节，末尾是 Boss。默认设计为 **3 章**（约 30~40 场战斗），通关即胜利。

### 6.2 牌组系统

#### 牌组构成

- **起始牌组**：每个角色有固定初始牌组（约10张）。
- **战斗中获取**：每次胜利后从3张随机卡牌中选1张加入牌组。
- **牌组是桌面牌的来源池**——战斗时从牌组抽牌铺桌面。

#### 牌组与记忆策略的关系（核心设计）

这是记忆配对玩法和传统牌组构建的**核心差异点**：

> **牌组里同名牌的数量，直接决定桌面配对的难易度。**

- 牌组里某张牌只有1份 → 它上桌面时很难找到同名搭子，只能靠特殊词条跨名匹配，否则无法触发效果。
- 牌组里某张牌有4份 → 桌面上容易出现多张同名，配对机会大，但记忆难度也大。
- 牌组牌种太多太杂 → 桌面全是不同名的牌，几乎无法配对。

**这创造了独特的 deckbuilding 策略——控制牌组的"重复度"：**

| 流派 | 特点 | 优劣 |
|---|---|---|
| **精简流** | 少量卡牌每种多份 | 桌面配对容易，但卡牌种类少、效果单一 |
| **多样性流** | 很多种卡牌各1~2份 | 依赖跨名词条匹配，灵活但记忆负担重 |
| **均衡流** | 核心卡3~4份 + 功能卡1~2份 | 平衡但需要精心构建 |

#### 牌组操作行为

| 行为 | 场景 | 说明 |
|---|---|---|
| **添加卡牌** | 战斗后 / 事件 / 商店 | 牌组增大 |
| **移除卡牌** | 商店 / 事件 | 牌组精简，提升配对稳定性 |
| **升级卡牌** | 篝火 | 提升单卡效果（不改变数量） |
| **复制卡牌** | 特殊事件 | 增加某卡重复度（强化配对） |

#### 桌面铺牌规则

- **固定数量**：每场战斗桌面固定铺 12 张牌（6对基准）。
- 与牌组大小无关，从牌组随机抽 12 张铺桌面。
- 记忆难度可控，玩家能形成稳定的记忆习惯。
- 牌组大小的影响通过"哪些牌被抽到桌面"来体现，而非桌面规模。

#### 战斗结束后的牌区处理

| 牌区 | 战斗结束后 |
|---|---|
| 牌组 | 保留 |
| 弃牌堆 | 回到牌组 |
| **消耗堆** | **回到牌组**（消耗只在单场战斗内生效） |

### 6.3 角色系统

每个角色有差异化定位，影响初始牌组和被动能力。

#### 角色设计草案

```
═══════════════════════════════════════
  角色一：学者
  ─────────────────────────────────────
  被动: 游戏开始时查看牌组顺序前5张
  
  初始牌组: 以情报型词条为主（侦察、标记），
           擅长信息获取，降低记忆压力
  
  定位: 新手友好，通过"看牌"能力弥补记忆不足
═══════════════════════════════════════

  角色二：狂战士
  ─────────────────────────────────────
  被动: 血量越低，翻牌触发的伤害效果越强
  
  初始牌组: 以攻击/火焰词条为主，效果直接，
           牌组重复度高（易配对），但效果单一
  
  定位: 暴力输出，血量管理是策略核心
═══════════════════════════════════════

  角色三：术士（解锁角色）
  ─────────────────────────────────────
  被动: 可消耗自身血量来"锁定"一张桌面牌保持翻开
  
  初始牌组: 以跨词条匹配和消耗流为主，
           高风险高回报
  
  定位: 进阶角色，主动操控桌面信息
═══════════════════════════════════════
```

### 6.4 遗物系统

遗物是**持久被动效果**，贯穿整个 run。针对记忆玩法特化。

#### 遗物示例

**记忆辅助类：**
| 遗物 | 效果 | 稀有度 |
|---|---|---|
| 「记忆水晶」 | 每场战斗开始时，桌面所有牌短暂可见2秒 | 普通 |
| 「思维导图」 | 翻过的牌位置在桌面上保留淡淡轮廓标记 | 罕见 |
| 「占卜球」 | 每场战斗可主动使用1次：揭示桌面任意3张牌 | 稀有 |

**桌面操控类：**
| 遗物 | 效果 | 稀有度 |
|---|---|---|
| 「永恒之烛」 | 每场战斗有1次机会：翻牌后不翻回其他正面牌 | 罕见 |
| 「稳定锚」 | 敌人的换位/混乱能力对你无效 | 稀有 |
| 「双生符」 | 同名匹配成功时，额外触发1次其中一张牌的效果 | 稀有 |

**配对强化类：**
| 遗物 | 效果 | 稀有度 |
|---|---|---|
| 「共鸣石」 | 每场战斗前3次配对额外+2伤害 | 普通 |
| 「连锁核心」 | 配对成功时，桌面随机一张牌也被翻开 | 罕见 |

**资源管理类：**
| 遗物 | 效果 | 稀有度 |
|---|---|---|
| 「急救包」 | 每场战斗开始时回5血 | 普通 |
| 「吸血鬼之牙」 | 配对消除时回复1血 | 罕见 |

### 6.5 金币系统

- 保留杀戮尖塔式金币系统。
- 战斗/事件获得金币。
- 商店消费金币购买卡牌、遗物、移除卡牌。

## 7. 设计原则

以下是贯穿整个设计的核心原则，用于指导后续内容扩展和平衡性调整。

### 7.1 记忆是核心资源

玩家的记忆能力是这个游戏区别于其他卡牌游戏的核心。所有设计决策都应问一个问题：**"这个设计是增强还是削弱了记忆的价值？"**

- 增强记忆价值的设计：✓ 大部分翻牌组合无法匹配（匹配是稀缺事件）、✓ 残留牌跨批次保留位置、✓ 敌人干扰针对桌面物理状态。
- 削弱记忆价值的设计：✗ 通用属性匹配（如所有"火焰"牌都能互配）、✗ 翻开的牌永久可见、✗ 系统能"抹除"玩家的记忆。

### 7.2 翻牌是唯一行动

玩家在战斗中的唯一行动是"翻牌"。没有出牌、没有使用技能、没有能量管理。这意味着：

- 每一次翻牌都必须有重量——它推进敌人，所以不能无脑乱翻。
- 卡牌效果的触发完全由"翻牌"和"匹配"两个事件驱动。
- 所有策略都浓缩在"翻哪张牌"这一个决策上。

### 7.3 敌人只能动牌，不能动记忆

系统层面不存在"已被记忆"状态。系统只记录牌的位置和内容。敌人干扰玩家只能通过改变桌面牌的物理状态（移位、封锁、污染），不能直接操作玩家的记忆。

### 7.4 词条统一所有规则修饰

消耗、匹配规则、翻牌效果、持续效果——这些都通过"词条"这一统一机制来表达。这保证了系统的扩展性和一致性：任何新的卡牌行为都可以通过新增一个词条来实现，而不需要增加新的系统层。

## 附录：术语表

| 术语 | 定义 |
|---|---|
| **桌面（Board）** | 战斗中铺开的牌阵，卡牌在此被翻开和配对 |
| **牌组（Deck）** | 玩家在本 run 中收集的所有卡牌，桌面补牌从此抽取 |
| **弃牌堆（Discard）** | 被消除/清除的牌暂存区，牌组耗尽时洗回 |
| **消耗堆（Exhaust）** | 带`[消耗]`词条的牌配对消除后进入，本场战斗不再可用，战斗结束回牌组 |
| **行动条（Action Bar）** | 敌人的蓄力值，翻牌+1、重新铺满+2，满则敌人行动 |
| **意图（Intent）** | 敌人公开的下次行动预告 |
| **词条（Tag）** | 卡牌的被动特性，触发时机有5种 |
| **同名匹配** | 两张卡牌名称完全相同即匹配（默认规则） |
| **批次补充** | 桌面可配对的牌全清后补充新牌的机制 |
| **重新铺满** | 玩家主动操作，清桌面+重铺，代价行动条+2 |
| **病毒牌** | 敌人塞入桌面的干扰牌，翻开即触发负面效果并移除 |
| **格挡（Block）** | 临时防御资源，抵消伤害，每场战斗开始清零 |
| **遗物（Relic）** | 持久被动效果，贯穿整个 run |
| **Run** | 一次完整的游戏流程，从开始到通关/失败 |

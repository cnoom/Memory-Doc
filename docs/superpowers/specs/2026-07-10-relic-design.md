## 1. 设计说明

### 1.1 遗物定位

遗物是**持久被动效果**，贯穿整个run，是Meta成长的核心载体。原型阶段设计26件遗物，覆盖以下设计维度：

| 维度 | 说明 | 对应学者流派 |
|---|---|---|
| **记忆辅助** | 降低记忆难度，提供信息优势 | 情报爆发流 |
| **桌面操控** | 改变翻牌/配对的基础规则 | 全流派通用 |
| **配对强化** | 提升配对收益或改变配对行为 | 配对循环流 |
| **防御续航** | 提升生存能力 | 全流派通用 |
| **行动条操控** | 影响敌人节奏 | 全流派通用 |
| **牌组操控** | 影响牌组构成或抽取 | 知识转化流 |

### 1.2 稀有度与获取

| 稀有度 | 数量 | 获取途径 |
|---|---|---|
| **普通** | 8件 | 普通战斗掉落、商店、事件 |
| **罕见** | 8件 | 精英战斗掉落、商店、事件 |
| **稀有** | 6件 | 精英战斗低概率掉落、商店高价 |
| **Boss** | 4件 | Boss击杀后必掉（三选一） |

Boss遗物为**最强遗物**，通常带有显著代价或改变玩法的强力效果，类似杀戮尖塔的Boss遗物。

### 1.3 设计约束

- 遗物不能"抹除记忆"（遵循GDD §7.3原则），只能改变桌面物理状态或提供系统层信息。
- 遗物效果需与学者卡牌、敌人能力形成有意义的交互。
- 数值平衡对齐学者基准（60血，配对6~10伤害，格挡每回合清零）。

## 2. 普通遗物（7件）

普通遗物提供基础增益，出现概率最高。全部为纯被动效果。

### 记忆辅助类

```
═══════════════════════════════════════════════════════
  记忆水晶                              [普通]
  ─────────────────────────────────────────────────────
  效果: 每场战斗开始时，桌面所有牌短暂可见 2 秒
  
  设计意图: 最基础的情报遗物。开局2秒一览全局，
           让玩家在战斗开始就建立初步记忆。
           配合学者被动（查看牌组前5张）形成情报优势。
           对混乱史莱姆/记忆窃贼的换位有缓冲作用。
═══════════════════════════════════════════════════════

  笔记本                                 [普通]
  ─────────────────────────────────────────────────────
  效果: 每场战斗开始时，自动标记桌面 2 张牌
       （标记：牌面内容对玩家持续可见，直至其被配对消除）
  
  设计意图: 持久情报遗物。与"记忆水晶"的区别——
           记忆水晶是短暂全揭示（考验记忆），
           笔记本是持久部分揭示（稳定信息）。
           适合不擅长快速记忆的玩家。
═══════════════════════════════════════════════════════
```

  设计意图: 配对附带情报。每次配对都有概率窥探一张牌，

## 3. 罕见遗物（6件）

罕见遗物提供组合型效果，改变战斗节奏。全部为纯被动效果。

### 记忆辅助类

```
═══════════════════════════════════════════════════════
  思维导图                               [罕见]
  ─────────────────────────────────────────────────────
  效果: 翻过的牌位置在桌面上保留淡淡的轮廓标记
       （仅显示"这里翻过"，不显示内容）
  
  设计意图: 位置记忆辅助。帮你记住哪些位置翻过，
           降低位置记忆负担，但内容仍需自己记。
           对混乱史莱姆/记忆窃贼的换位有追踪作用——
           可以看到牌被移走了（轮廓还在原位）。
═══════════════════════════════════════════════════════
```

### 桌面操控类

```
═══════════════════════════════════════════════════════
  永恒之烛                               [罕见]
  ─────────────────────────────────────────────────────
  效果: 翻开一张牌时，若它与桌面上其他正面牌同名，
       则不将其他正面牌翻回（保持正面朝上）
  
  设计意图: 改变翻牌规则。当翻到同名牌时不触发翻回，
           让玩家能同时持有多张正面牌。
           奖励精准记忆——你记得某位置是同名牌，翻它就能保留之前的正面牌。
           配合高重复度牌组（笔记系）可同时暴露多张牌。
═══════════════════════════════════════════════════════
```

### 配对强化类

```
═══════════════════════════════════════════════════════
  连锁核心                               [罕见]
  ─────────────────────────────────────────────────────
  效果: 配对成功时，桌面随机 1 张背面牌被翻开
       （不触发其翻开效果，仅揭示内容）
  
  设计意图: 被动情报+配对联动。每次配对都附带情报收益，
           叠加学者情报流。与"双生骰"区别——连锁核心是
           纯揭示（不触发效果，不推进行动条），更安全。
═══════════════════════════════════════════════════════

  蓄能水晶                               [罕见]
  ─────────────────────────────────────────────────────
  效果: 每连续成功配对 3 次（无失败配对），
       下一次配对额外 +5 伤害
  
  设计意图: 连击奖励。鼓励精准记忆配对，
           失败配对会中断连击。高手的伤害放大器。
           对学者情报流极契合——情报越准连击越长。
═══════════════════════════════════════════════════════
```

### 防御续航类

```
═══════════════════════════════════════════════════════
  吸血鬼之牙                             [罕见]
  ─────────────────────────────────────────────────────
  效果: 每次配对消除时，回复 1 点血量
  
  设计意图: 配对续航。每次配对回1血，
           一场战斗配对10次=回10血。
           鼓励高频配对打法，配对越多越肉。
           
  交互注意: 配对消除才回血，翻开未配对不回。
           "失败配对"（翻开两张不同牌）不回血。
═══════════════════════════════════════════════════════

  能量护盾                               [罕见]
  ─────────────────────────────────────────────────────
  效果: 每回合结束时，若你的格挡 ≥ 5，额外保留 3 点格挡
       至下回合（超过5的部分仍清零）
  
  设计意图: 格挡留存遗物。鼓励堆格挡——
           如果每回合配出5+格挡，下回合保留3点。
           改变"格挡每回合清零"的规则，奖励防御型打法。
═══════════════════════════════════════════════════════
```

## 4. 稀有遗物（5件）

稀有遗物提供改变玩法的强力效果。全部为纯被动效果。

```
═══════════════════════════════════════════════════════
  稳定锚                                 [稀有]
  ─────────────────────────────────────────────────────
  效果: 敌人的换位/混乱/洗牌能力对你无效
       （桌面牌位置不会被敌人移动）
  
  设计意图: 完全免疫位置干扰。对混乱史莱姆、记忆窃贼、
           记忆吞噬者（全阶段都有混乱）是克制遗物。
           拿到后这些敌人的核心威胁被消除。
           但不免疫封锁/污染。
═══════════════════════════════════════════════════════

  双生符                                 [稀有]
  ─────────────────────────────────────────────────────
  效果: 同名匹配成功时，额外触发 1 次其中一张牌的基础效果
  
  设计意图: 配对效果翻倍。同名匹配后，多触发一次基础效果。
           对笔记(6伤害)意味着配对=12伤害+6伤害=18伤害。
           注意：仅"同名匹配"触发，匹配型词条配对不触发。
═══════════════════════════════════════════════════════

  时间织锦                               [稀有]
  ─────────────────────────────────────────────────────
  效果: 每回合行动条增长量 -1（每次翻牌行动条+0而非+1）
       但重新铺满仍 +2
  
  设计意图: 改变行动条经济。每回合翻牌不推进行动条，
           玩家可以无限翻牌（直到牌组耗尽或主动停止）。
           极强的节奏遗物，但重新铺满仍有代价。
           
  平衡说明: 这会大幅降低战斗难度，因此设为稀有。
           配合学者情报流，可实现近乎无限的情报收集。
═══════════════════════════════════════════════════════

  镜像回声                               [稀有]
  ─────────────────────────────────────────────────────
  效果: 每次配对成功时，25% 概率将配对的两张牌中的
       一张复制一份放回桌面（背面朝上）
  
  设计意图: 牌组扩充遗物。配对的牌有概率循环回桌面，
           等效于"免费"多一次配对机会。
           对高价值牌（真理之眼、图书馆）极强。
           
  交互注意: 复制品是背面朝上新牌，玩家不知道其位置。
           需重新记忆。
═══════════════════════════════════════════════════════

  学者徽章                               [稀有]
  ─────────────────────────────────────────────────────
  效果: 你的"揭示"和"标记"效果数量 +1
       （如"揭示2张"变为"揭示3张"，"标记1张"变为"标记2张"）
  
  设计意图: 学者专属强化遗物。放大所有情报效果。
           与学者的卡牌体系（读书笔记、批注、目录等）
           形成乘法效应。对其他角色价值较低。
═══════════════════════════════════════════════════════
```

## 5. Boss遗物（4件）

Boss击杀后必掉，三选一。强力效果，部分带代价。

```
═══════════════════════════════════════════════════════
  全知之眼                               [Boss]
  ─────────────────────────────────────────────────────
  效果: 每场战斗开始时，桌面所有牌内容对玩家可见
       （持久可见，整场战斗有效）
  
  代价: 你的最大血量 -10
  
  设计意图: 终极情报Boss遗物。整场战斗全明牌，
           记忆压力完全消失。代价是降血。
           对学者是完美契合——知识就是力量，
           但身体更脆弱了。
           
  交互注意: 血量降幅是永久的（整run有效），
           后续战斗容错更低。
═══════════════════════════════════════════════════════

  混沌核心                               [Boss]
  ─────────────────────────────────────────────────────
  效果: 每回合开始时，随机将桌面 2 张牌互换位置，
       然后揭示互换后的 2 张牌内容（持续可见）
  
  代价: 无
  
  设计意图: 以毒攻毒型Boss遗物。每回合强制换位，
           但告诉你换了哪两张。制造动态记忆挑战，
           同时提供部分情报。适合喜欢挑战的玩家。
           
  设计哲学: 不是所有Boss遗物都是纯增强。
           这件遗物改变记忆玩法——记忆不再是静态的，
           而是每回合动态更新。
═══════════════════════════════════════════════════════

  无尽书库                               [Boss]
  ─────────────────────────────────────────────────────
  效果: 每次配对成功后，从弃牌堆随机取 1 张牌放回桌面
       （背面朝上，不触发入场效果）
  
  代价: 无
  
  设计意图: 牌组循环加速。配对消除的牌会循环回桌面，
           桌面永远不会清空。等效于无限战斗资源。
           
  平衡说明: 虽然看似强力，但回桌的牌是随机的，
           玩家不知道位置和内容，记忆压力反而增加。
           是"资源无限但记忆有限"的有趣张力。
═══════════════════════════════════════════════════════

  记忆王冠                               [Boss]
  ─────────────────────────────────────────────────────
  效果: 你的所有能力牌的持续效果翻倍
       （如"+1伤害"变为"+2伤害"，"每翻牌获1专注"变为"获2专注"）
  
  代价: 无
  
  设计意图: 能力牌强化Boss遗物。让能力牌的持续效果翻倍。
           对学者（有多张能力牌）极强。
           全神贯注的专注积蓄翻倍、博闻强识增伤翻倍等。
           
  设计哲学: 鼓励玩家围绕能力牌构筑。
           拿到后改变deckbuilding优先级——
           能力牌的价值大幅提升。
═══════════════════════════════════════════════════════
```

## 6. 道具系统（药水/消耗品）

### 6.1 道具定位

道具是**主动使用的消耗品**，每场战斗中使用后消失（类似杀戮尖塔的药水）。与遗物的区别：

| | 遗物 | 道具 |
|---|---|---|
| 效果类型 | **纯被动** | **主动使用** |
| 持续性 | 永久（整run） | 一次性（用完消失） |
| 携带上限 | 无限制 | 原型阶段3个槽位 |
| 获取途径 | 战斗/事件/商店 | 战斗/事件/商店 |

道具提供玩家**主动选择时机的紧急手段**——在关键时刻扭转战局。

### 6.3 道具总览

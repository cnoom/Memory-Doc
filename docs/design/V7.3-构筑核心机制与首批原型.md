# V7.3 · 构筑深化与机制精简 — 核心规则及首批原型

- 状态：策划候选，待评审；非生产卡表，不改 Unity。
- V7.3 为研发策划版本，不是发行版本号。已确认移除蓄步，见 [蓄步移除与移动机制边界](./V7.3-蓄步移除与移动机制边界.md)。其余具体卡文、数值及投放均未获最终确认。
- 以 V7.2 已落地战斗、96 奖励牌 / 33 遗物为基线；保持同名配对、双实例独立结算与配对前快照、双回合、职业共享卡池、现有行动条及伤害分类。旧火冰继续暂缓，不引入能力牌、位置配对、蓄能或新操作按钮。

## 1. 构筑架构

战斗方向：连击（高频命中）、流血（施加与逐段消耗）、中毒（随敌回合结算的长线成长）、护盾（防御与反击）。卡牌机制：配对（精确兑现）、翻开（探索即时收益）、翻回（容错与成长）、消耗（战斗内精简）。它们是可混搭的设计标签，不是职业、硬锁池或玩家必须选择的流派。力量、护甲、易伤、虚弱、治疗与独立附伤为通用组件。

| 机制 | 核心乐趣 | 主要收益 | 设计红线 |
|---|---|---|---|
| 配对 | 准确找到目标并兑现 | 可靠的主要输出、配对连锁 | 不新增位置、连续成功顺序等强制条件；不要求背记计数 |
| 翻开 | 未配对也有反馈 | 少量即时伤害、格挡、施加状态 | 真实翻开才触发；保留行动条代价；重复收益需低于无风险循环临界点 |
| 翻回 | 暂未配对不完全亏损 | 少量即时防御或实例成长，随后配对兑现 | 不奖励主动制造无意义失败；新增累计成长有上限；离场生命周期遵循现有实例契约 |
| 消耗 | 前期投资、后期精简 | 一次性成长、牌组集中 | 双实例整对消耗；不重新引入生命/格挡/毒等支付资源；全消耗及只剩一对边界须验证 |

配对仍是主要收益来源；翻开、翻回是容错与构筑分支，不能普遍替代正确配对。特殊成型组合允许不同策略，但不得让无风险反复翻同牌成为通用最优。

## 2. 共同触发契约

- 实际背→正才是翻开；实际正→背才是翻回。详情、入场展示、虚拟重放效果、离场均不额外触发真实翻牌事件。
- 同名两实例各执行一次；卡文数值默认单实例。整对级效果每次成功配对只触发一次，必须明确标注；配对前的条件快照不因 A 的结算而倒灌 B。
- 不改变 V7.2 行动条及状态/伤害分类。直接攻击、卡/遗物独立附伤受既有力量等规则；流血、中毒等状态来源伤害不吃通用增减伤。不引入递归命中。
- 本轮优先无新增持久资源、无额外选择、无位置条件。若使用本场首次、累计次数等，优先简单自动计数，UI 提供可见的强化数值或进度；不得在背面泄露隐藏身份。
- 特殊效果重放不等于真实翻开，默认不重放移动、翻回、消耗、状态机事件或其他遗物，不生成虚假操作数。首批不引入普遍的翻开效果重放。
- 消耗沿用成功配对双方离场；本场不回洗，下场恢复 Run 卡。镜像回声等返还例外保持既有语义，触发计数区分“带消耗属性的配对”与“实际移除实例”。

## 3. 第一批原型（12 张候选改造，不新增身份）

下表是用于实验的初始单实例数值，不是最终平衡。优先覆盖移除蓄步造成的空缺、记忆操作与战斗桥接。现有未列入首批的蓄步牌须在完整移除前补齐替代效果；不能只合入部分替换便宣称已移除蓄步。

| 卡牌 | 候选卡文 | 角色 / 区别 |
|---|---|---|
| 游刃 | 造成2段3点伤害。[翻回] 本实例每段基础伤害+1，最多2次。 | 翻回×连击，有限成长 |
| 藏锋 | 获得6格挡。[翻开] 若本实例本场曾翻回，获得2格挡。 | 回访防御，与复习的翻回即时防御区分 |
| 穿书 | 获得6格挡；若本实例本场曾翻回，下一次直接攻击追加1段3点伤害。 | 翻回×连击，与夹页的无条件准备区分，需比较取舍 |
| 脚印 | 造成7点伤害。[翻开] 若本实例本场首次真实翻开，造成2点独立附伤。 | 探索即时收益，不要求记忆移动 |
| 飞墨 | 获得6格挡。[翻回] 施加1层中毒；每实例每场最多2次。 | 翻回×中毒，与毒刺翻开施毒区分 |
| 流影 | 造成6点伤害。[翻开] 本实例本场首次真实翻开时施加1层流血。 | 翻开×流血 |
| 盾击 | 造成6点直接伤害，额外造成1包等于配对前自身格挡一半（向下取整，最多8点）的独立附伤。 | 护盾兑现，不主动消耗格挡 |
| 毒发 | 造成6点直接伤害；若敌人配对前有中毒，整对额外触发一次当前中毒状态伤害，不减层。 | 中毒主动兑现；一次整对，不制造敌回合或定时中毒事件 |
| 页角 | 获得7格挡。[翻回] 本实例基础格挡+2，最多2次。 | 翻回×护盾，区别旧识的渐进成长；需复核同质化 |
| 稳步 | 获得7格挡和1护甲。[消耗]。 | 消耗×防御，持续护甲与一次性卡位投资 |
| 构篇 | 获得7格挡；整对按本场此前实际消耗的配对数获得力量（每2对1层，最多2层）。[消耗]。 | 消耗终端，不把本对计入快照 |
| 近注 | 造成2段3点伤害；若本次攻击结算前自身力量≥1，获得3格挡。 | 连击×防御，与并击区分；普通牌独立价值 |

毒发的即时中毒为状态来源伤害，不触发“敌回合定时中毒”遗物；具体状态层数冻结时点需在实现契约中单独锁定，原型建议配对前快照。构篇的配对计数不得因镜像回声返还虚增。页角与旧识、穿书与夹页若实测仍为简单优劣关系，则优先再次改造，不为凑数保留。

### 3.1 遗物原型（4 件）

| 遗物 | 候选效果 | 验证点 |
|---|---|---|
| 共鸣石 | 每次成功同名配对造成1包基础1点独立附伤（整对一次）。 | 精确配对收益；力量放大及配对高频风险 |
| 旧页徽章 | 每个玩家回合首次真实翻开本场曾翻回的牌时获得2格挡。 | 与笔记本3格挡同质，最终不可照搬；作为对照原型，优先试验改成首次回访产生1点独立附伤或直接放弃 |
| 封口绷带 | 每次实际消耗整对后获得3格挡（整对一次）。 | 区分返还与真正消耗，保护消耗前期 |
| 双生符 | 每个玩家回合首次成功配对时，若本对至少一个实例具有印刷翻开效果，造成1包基础3点独立附伤。 | 提升翻开牌配对价值，不伪造翻开事件；与连锁核心差异化 |

旧页徽章的格挡候选与笔记本重合，不作为推荐最终效果；首批实验可直接使用伤害候选。所有数字待平衡。

## 4. 战斗方向的下一轮设计

| 方向 | 保留机制 | 希望新增的差异化收益 | 禁止 |
|---|---|---|---|
| 连击 | 力量逐段放大、已有逐段增伤 | 段数驱动格挡/独立附伤 | 递归追加或无限计数刷取 |
| 流血 | 有效直接攻击触发、逐段减层 | 补层、额外触发、状态与防御桥接 | 将状态伤害改成吃力量的附伤，或无条件无限补层 |
| 中毒 | 敌回合指定时点结算、无自然衰减 | 翻牌叠毒、即时毒伤兑现、防御 | 重复敌回合事件或重新引入毒支付 |
| 护盾 | 格挡与护甲不同职责 | 按现有格挡/护甲兑现、反击 | 无上限无风险永久防御或重复计入本对新格挡 |

## 5. 原型验证（非运行结果）

先在固定种子与同等替牌数下进行受控战斗；基线 V7.2 与候选分别测试记忆档 0/50/100，至少覆盖重复牌组和全异名牌组、短战与长战。先使用相同敌人、职业、起始生命、行动条代价；后验证学者翻回被动及 Boss 遗物的交互。记录正确配对、真实翻开/翻回、实际消耗对数、每次行动产生的收益、无效操作、首次受伤、击败敌人所需操作、剩余生命。不得只看通关率或单次高伤。

专项：翻开/翻回真实事件、同名快照、状态伤害来源、消耗返还/耗尽/仅剩一对、敌人周期强化、额外附伤不递归、合法移动不产生蓄步、所有职业共享。以自动化排除失控循环，再由真人测试构筑理解、组合发现及是否愿意改变选牌；不预设趣味性达标比例。原型在独立分支，不影响当前动效和前两场真人试玩基线。

## 1. 已确认的战斗核心规则

### 1.1 同名配对、实例与翻开/翻回

- 仅**同名牌**成功配对；不恢复异名共鸣、关联符号或能力牌类型。
- 一次配对的两张战斗实例**各执行自己的默认效果一次**，并在配对成功瞬间使用相同的**不可变前置条件快照**（力量、目标状态、易伤、条件资格等）；实例自身已经积累的临时强化仍分别计算。A实例在本次刚施加的状态不能使B实例重新满足原本不满足的快照条件。
- [翻开]仅指真实背→正，[翻回]仅指真实正→背；浏览详情、UI预览、非真实展示动画均不触发。
- 学者：每次真实**翻回**，该实例可强化的有益固定数值+1，最多2层；不强化段数、次数、负代价、百分比等，与卡牌自身临时强化独立；离场清零。
- 锁定文案示例：**S04「探卷」普通·攻击：造成2段2点伤害。[翻开] 临时伤害+1。** 同一实例翻开两次可显示「造成2段（2+2）点伤害。」动态来源在详情中分列。
- 一份Run卡在战斗中对应两张配对实例；起始Run牌为打击×4（每实例6直伤）、格挡×4（每实例6格挡），开场4×4格子是16个战斗实例，不是16份待替换起始牌。

### 1.2 正式双回合时序（本版本新增）

1. **BattleStart**：初始化牌桌、角色、敌人、状态、遗物。
2. **PlayerTurnStart**：先处理回合初**改变护甲**的效果，再按此时护甲层数**仅一次**产生等量格挡；随后结算其它回合初及上次敌回合延后的格挡，再允许操作。开局即有第1个玩家回合。
3. **PlayerAction**：玩家可在同一回合多次翻牌、配对和操作移动。当前操作的所有卡牌、移动、离场、状态及遗物效果必须排空才推进敌人行动条。
4. **ActionBarAdvance**：按合法操作的行动条代价推进。未满继续当前玩家回合；达到阈值只标记**待切换**，不能打断正在结算的配对/移动。
5. **PlayerTurnEnding**：触发并排空「玩家回合结束」效果，才结束玩家回合。
6. **EnemyTurnStart／EnemyAction／EnemyActionResolved**：敌方回合开始，执行一次完整意图（含多段、非攻击、换位），结算关联状态、被动、遗物。中毒保留行动条实际满所对应敌方回合中的**一次**指定结算，不在开始/结束阶段重复伤害。
7. **EnemyTurnEnding／Cleanup**：先排空回合末效果，再判定旧格挡保留（如R16）、清理其余旧格挡，清理完毕才正式结束敌人回合；之后进入下一个PlayerTurnStart。**敌人回合末不再由护甲产盾**。
8. 任意阶段战斗已终局，立即停止后续事件；未发生的回合初、末效果不补发。

「每周期」不再允许无归属地出现在新卡文/遗物文案中。按事件区分**每玩家回合、每敌人回合、跨玩家回合与紧接敌方回合的窗口**，并保持一次触发上限。

### 1.3 护甲、格挡（本版本重要改版）

- **护甲**＝本场持续的防御层数，本身不吸伤、不被普通伤害削减；**玩家回合开始时**生成等层数格挡，每玩家回合仅一次。
- **格挡**＝即时抵消伤害的临时值；敌人回合结束后清理未保留的旧盾。护甲当下获得并不立即发盾，直到下次玩家回合初。
- 回合初改变护甲的效果**先于护甲发盾**；发盾后新增护甲不在当前回合补发。
- 敌人回合期间触发的“供下次玩家回合使用”的格挡，在事件账本中排队到下一玩家回合初兑现，不提前发盾然后被回合末清理。
- 示例：玩家有3护甲、旧格挡4；敌人造成6伤害，先消耗4盾、生命-2；敌人回合末清旧盾，下一玩家回合初护甲再给3格挡。R16等保留例外另算。
- **敌方护甲如何定义、旧削甲效果如何迁移仍未最终裁决**；暂不把旧敌方护甲实现直接套用新的玩家护甲语义。

### 1.4 移动与蓄步（本版本交互简化）

- 卡牌要求移动时，先选存在合法方向的**背面、非病毒、非封锁**来源牌；**只显示合法上/下/左/右方向**；选一个方向后自动移入相邻空格或与合法相邻背面牌交换，不再点击目标格，也无远距/斜向。
- 来源可重选、请求可跳过，非法/过期提交不改变牌桌。每战斗实例一次效果触发最多一项移动请求；同名配对两实例各请求时逐个处理，第二次必须根据**最新棋盘**重新计算合法方向。
- 每次有效空位移动使来源实例蓄步+1；相邻交换使双方实例各+1；**敌人造成的真实移动同样计数**。蓄步本身无数值硬上限。
- **真正翻开**时，将本窗口`PendingSteps`原子锁入`FlipLockedSteps`，同时清空待兑现窗口；卡牌与遗物共读同一锁定值。全战轨迹`LifetimeSteps`及「曾移动」标记单独记录，不得反复拿已兑现步数叠加同来源效果。
- **X37「穿书」远距离交换已移除**；当前卡牌候选转为蓄步条件下的下次攻击追加段，尚需实战平衡。

## 2. 状态与伤害来源（最新最终裁决）

### 2.1 状态持续

| 状态 | 何时生效 | 衰减或重置 |
|---|---|---|
| 力量 | 每段直接攻击、卡牌/遗物自身产生的符合规则的独立附伤各+1/层 | 本场持续，不自然衰减 |
| 流血 | 每段**有效直接攻击**命中时，按当前流血层数产生一包**状态伤害** | 每触发一次-1层；不递归 |
| 中毒 | 实际敌行动条满对应敌方回合的行动后阶段，按中毒层数产生一次**状态伤害** | 不自然衰减；每敌人回合不重复结算 |
| 易伤 | 目标受到直接攻击、卡牌/遗物自身独立附伤时+50% | **目标对手的回合结束**计时 |
| 虚弱 | 状态持有者造成的直接攻击伤害-25% | **持有者自身回合结束**计时 |
| 护甲 | 玩家回合开始产盾 | 本场持续，不自然衰减 |
| 格挡 | 承受可抵消的伤害 | 敌人回合结束清旧盾，保留除外 |

- 易伤/虚弱**重复施加增加持续回合数，不叠倍率**。
- 刚施加的某批回合制减益**不在其本次所属计时回合的末尾立即递减**；旧批次正常到期、新批次有自己的首次递减回合，避免反复刷新使旧持续期凭空延长。
- 玩家回合1给敌人1回合易伤→本次玩家回合末不扣；玩家回合2的直伤可增幅，玩家回合2末到期。玩家回合1给敌人1回合虚弱→敌人回合1的直接攻击减伤，敌人回合1末到期。

### 2.2 **统一伤害来源：所有状态伤害不吃通用加成**

**最终原则：任何`StatusDamage`只按该状态自身层数、次数与效果公式决定伤害量，不接受力量、易伤、虚弱、遗物通用增伤或其它通用百分比伤害修正。** 可以通过卡牌/遗物改变状态层数或合法触发频率，但不能把普通增伤乘到状态包上。

| 伤害来源 | 力量 | 易伤 | 虚弱 | 通用遗物增伤 |
|---|---|---|---|---|
| 直接攻击段 | 有效 | 有效 | 若攻击者虚弱则降低 | 按具体遗物 |
| 卡牌自身独立附伤 | 有效 | 有效 | 不作为直接攻击降低 | 按具体遗物 |
| 遗物自身独立附伤 | 有效 | 有效 | 不作为直接攻击降低 | 按具体遗物 |
| **流血状态伤害** | **无效** | **无效** | **无效** | **无效** |
| **中毒状态伤害** | **无效** | **无效** | **无效** | **无效** |
| 未来状态来源伤害 | **无效** | **无效** | **无效** | **无效** |

- **状态伤害仍然经格挡→生命→死亡检查**，不等于无视防御；护甲本身不在受伤管线中吸伤。
- 一次连续三段直接命中触发4层流血时，状态包依次4、3、2，总9；即使攻击者有力量、目标有易伤也不改变这9点。4层中毒在符合时机的一次结算造成4点状态伤害。
- 因“敌人已有中毒/流血”条件而由X22等卡牌**自身生成的独立附伤**仍属于`CardDamage`，可以按卡牌/遗物来源正常受力量和易伤。R29等遗物独立包同理；B04血契剑鞘不增强状态包。
- 非状态伤害采用固定加法先合并、适用百分比再乘算、最后统一向下取整的既有规则；同名配对仍使用冻结前置快照。
- 灼烧/冰冻在V7.2新Run暂缓；此前“灼烧改为敌人行动后×2”只是**未采用的实验**，不擅自改写旧存档规则。

## 3. 卡牌与奖励池修订

### 3.1 从六轴收缩为四条**允许混搭**的主要构筑方向

| 主轴 | 启动/强化 | 代表兑现与跨轴 |
|---|---|---|
| 力量＋连击 | 逐段增伤、力量来源 | 轻刃、并击、余震、更多多段攻击；与流血有效命中或卡牌独立附伤组合 |
| 流血＋命中 | 开篇、挫锋、划痕、承接提供流血 | 直接攻击多段消耗流血；可用卡牌/遗物条件附伤与其它轴混搭 |
| 中毒＋附伤 | 毒雾、毒刺、毒针等上毒 | 毒发、苦药、渗毒斩；毒状态伤害固定，卡牌独立附伤仍可叠力量 |
| 记忆操作（翻回＋蓄步） | 复习、挪页、移页签等 | 探卷、游刃、穿书、追影；可连接任何攻击/防御牌 |

**格挡/护甲**作为所有轴可以使用的通用防御模块，不强行设第五套单独的“纯防御流派”。任意职业可以使用公共奖励牌组合主轴与副轴，不出现职业锁池和单一流派强制保底。

### 3.2 池范围与章节节奏

- 历史**110种**奖励卡保留原ID和文案历史；其中**14种涉及火冰**暂缓：`N11、X24、X25、X28、S17、N12、N14、X26、X27、X29、X55、S23、X30、X59`。V7.2正常新Run不得从奖励、商店或其它随机投放源生成这些卡；旧存档需另有兼容策略。

- 第一章目标：替换8份初始Run卡，形成基础可用构筑；第二章目标：至少一个主要机制与可运作副轴；第三章目标：提升上限和补齐终结。
- 章节投放、普通/罕见/稀有权重、三选一结果及获取成本须做路径/随机种子实证。**第一章每条合法路线至少有8次实际可用替牌机会**仍是待验证目标（建议10–12次容错），不是当前已经被证明的功能。

## 5. UI、词典及交互变化

1. 卡牌详情是**独立可复用组件**，接收卡牌或卡背公开状态的数据；战斗、牌库、商店、奖励、事件等入口共用，不能只在棋盘中实现。
2. 所有**专有名词**（格挡、护甲、力量、流血、中毒、易伤、虚弱、翻开、翻回、移动、蓄步、消耗、多段、回合、状态伤害、附加伤害等）有可查看的简短/展开解释，词典同源。
3. 动态效果与实例成长要显示基础、临时、学者、力量及适用其它来源；**状态伤害不得错误展示通用增伤**。同名配对冻结值与详情在相同上下文下可对账。
4. 点击面板外或非交互区域关闭详情；解释词语的点击不应把整个面板误关闭；关闭事件**不能穿透棋盘引起翻牌**。
5. 背面牌详情只允许显示已公开的覆盖状态等信息，不允许传入或泄露隐藏卡名、ID、类型或插画；支持长文本滚动、不同屏幕尺寸。

## 8. 本版验收目标（非已通过结果）

- **玩法**：第一章可以真正替换8份弱起始牌；第二章主轴+副轴具备实际可取得的启动/兑现件；第三章完成构筑而非才得到必需启动件。
- **系统**：任何事件都有唯一明确归属（Battle/PlayerTurn/PlayerAction/EnemyTurn/StatusDamage），护甲与格挡只有一个正本时点。
- **强度**：多段和状态层数可以创造组合，而**状态伤害本身不接受通用增伤乘法**，避免“力量×易伤×毒/血”失控。
- **内容**：新Run只从有效候选池投放，历史卡/遗物保留ID可兼容、暂缓火冰不污染候选；未裁决[消耗]有清晰功能门禁。
- **呈现**：卡牌详情在所有入口一致解释术语与动态伤害，不泄露背面隐藏信息，不阻挡或穿透误操作。

**版本结论**：V7.2已经完成核心回合/状态/伤害来源/移动/护甲/精简池方向的**策划裁决**；卡牌与遗物具体强度、[消耗]、奖励经济及Unity实现仍待联合验收。

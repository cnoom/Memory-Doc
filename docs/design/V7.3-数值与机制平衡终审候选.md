## 1. 数值标尺与静态算例

单实例起始牌5/5首测（6/6、5/6对照）。纯数值普通8～9，普通机制6～8，罕见机制基础6～10左右，稀有按引擎独立估值；不是统一硬上限。格挡与伤害不能机械相加。普通重击/铁卫9/9作为无前置参照。以下无升级、学者、敌格挡、百分比修正、遗物，假设所有段均有效且敌人存活，双实例完全同态，仅用于静态算例。

流血6层、6段有效直接攻击：无补层为6+5+4+3+2+1=21；血潮第三次正常减层后补2层时为6+5+4+5+4+3=27，最后2层；同时血潮棱镜第三次再补1层时为6+5+4+6+5+4=30，最后3层。仅在第三次实际结算后、敌存活时生效，不包括撕裂指环不减层或其它施血。这里没有把状态伤害乘力量/易伤，也未把追加独立附伤误算直接命中。

护甲若首回合内获得2层，此后4次自身回合初均正常发生时累计8格挡，但并不等于实际抵消8HP，可能被清理。力量同理，以未来段/包数衡量，不能只估当对输出。起始牌的同名集中天然降低配对难度：理想16格、两种各8实例、完全随机且首次翻开后的另15格均未知时，第二翻命中7/15≈46.7%；八种各2实例时1/15≈6.7%。这不是实战命中率（已知信息、补牌、行动条、策略均改变概率），说明必须对比单位有效操作收益和卡组身份密度，而非仅用5/9直接比。

## 2. 本轮建议冻结的作用域和非递归规则

- 普通伤害/格挡按单实例独立执行；新增长期力量、护甲或整对准备优先整对一次，明确文本例外保留。配对前条件和伤害修正所需快照沿现行不可变规则；本对新获力量/护甲/状态不改写已锁定的另一实例的条件。实际命中、格挡扣除、流血减层及死亡按实时事件。
- 流血、中毒状态来源伤害统一不吃力量、易伤、虚弱、血契剑鞘等通用修正，照常经过格挡和生命。直接攻击段及卡牌/遗物独立附伤按32号伤害来源与取整规则；不创建基础为0的条件附伤包来获取力量。真实有效直接攻击定义保持现行实现，必须先对源码确认；不能擅自将格挡全抵消定义改为未命中。
- 新增“本实例本场首次/最多N次”只在真实翻开/翻回时记账，重铺、详情、展示、位置变化、存读档、离场再入不重置次数；现有临时数值离场清零语义仍需保留（次数不清零，临时成长是否随离场清零明确遵循既有实例修正生命周期）。若实现重建战斗实例，必须有稳定战斗身份或等价记录，不能使已用次数复活。缓毒/整理的治疗为本场同卡名首次满足条件的成功配对；其他按整对、实例或回合的具体作用域。
- [消耗]两实例一同实际入消耗堆，发布既有带消耗配对事件及可区分的实际去向信息（可用同事件字段而非强制新事件）。镜像回声首次返还整对仍为合法消耗配对，但不是实际消耗；封口绷带、构篇、随风成阵、叠页行军旗及候选记忆王冠统一实际入堆语义，旧档仍按明确版本策略。终局中断未完成不虚报，不改变Run库存。
- 准备态候选：同来源同一目标窗口未兑现时刷新而非叠加（不增加剩余次数，保留较高合法数值）；不同来源独立存在；成功攻击牌配对锁定并消费针对下一攻击配对的准备，技能配对/翻回不消费，跨回合可持续到兑现或战斗结束；伤痕反制/反制在各自首个实际符合条件的敌攻事件消费，鲜红涂刃在首个符合条件的玩家直接命中消费。准备态无须新增按钮或玩家手动计数；UI显示清楚。连环索引只增强配对两实例的原生段（包含印刷条件追加段，不含遗物/准备态额外追加），按两实例确定顺序前6段；穿书首个直接攻击段，夹页追加2段；连锁核心计有效直接段达到6后追加1段，自身追加不再触发自身。各来源合法效果可以组合，但不可递归或回写已冻结资格。具体相同事件优先级、旧预备队列、直接攻击中途终局须以代码核验后形成测试契约；不可直接按新文案覆盖旧行为。
- 升级第一轮使用生产已存在的机制，不先全局改倍率；实施前审计可升级数值映射。建议升级只改明确的卡面基础伤害/格挡/治疗/施加状态等授权数值；次数、段数、条件阈值、额外效果上限、整对系数、稀有度、行动条、消耗属性及全局状态公式默认不升级，特殊卡另审。示例仅按历史+50%向上取整规则，5→8、9→14，需核验现行；不能因5/5弱化就擅自禁止初始牌升级。必须检查技能升级是否连带永久力量/护甲、翻开施毒、治疗等成长；若无显式字段白名单，先提出单独升级规则PR。
- 不改变双回合、对称护甲、敌周期强化、合法移动和敌人换位、背面信息隐藏。不引入全局力量/毒/护甲硬上限作为平衡捷径。状态长期成长的过强先由卡牌供给、次数或整对作用域修正。

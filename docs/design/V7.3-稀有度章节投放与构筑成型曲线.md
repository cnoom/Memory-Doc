# V7.3 · 稀有度、章节投放与构筑成型曲线

日期：2026-11-25。状态：Draft / 策划实验候选；不修改生产。基线为 PR #14 的 `31bf74433275b314c2db69d1c09e9fc37e29b331`《V7.3-卡池与遗物逐项重构候选》。参考 V7.2 28/29/30/34 号协议。用户已确认移除蓄步及降低起始牌；以下具体投放、权重、阈值与效果调整为提案，需最终评审和验证。

## 1. 设计目标及固定约束

- 第一章发现方向、替换弱起始牌；第二章构筑真正产生循环；第三章强化、混搭与兑现，不能把启动或唯一可用引擎压到最后一章。
- 普通牌具独立战斗价值，罕见牌连接机制，稀有牌改变循环/提高兑现上限；不按卡文复杂度或基础值简单评级。任何轴均无需指定遗物或稀有卡才能起步。
- 96奖励身份、33遗物身份不增减，14火冰卡/3火冰遗物冻结，卡名与美术键不重用。职业共享池，重复卡允许，配对/翻开/翻回/消耗是横向机制而非硬锁。
- 累计章节池，早期卡可在之后出现；当前生产选择、权重、价格、战斗/精英/Boss/商店/事件获取规则先不改，正常战斗不掉遗物。三选一去重保持现有合同；未实测具体抽样入口、稀有度空档处理、地图机会和实际初始Run配置，实施前以当前源码确认，不能将本稿当成运行结果。

### 额外数值与触发风险（非最终卡文）

- 磨锋纹提前时建议将“自身配对前力量为0”获力明确为整对一次+1力量，避免两实例都读取零力量而直接+2。与试锋的攻/防启动对称；先测原效果与整对效果，不擅自合入。
- 稳步由普通升罕见，保持上一稿消耗+护甲候选，仍须检查双实例各+1护甲对章一的累计防御；不能依靠稀有度解决无限叠加。若过强另做整对+1护甲对照。
- 章一毒发按上一稿整对一次状态伤害、配对前毒层，不制造定时毒伤事件；与毒雾、飞墨联测。章二血潮按第三次实际流血伤害补2层，整对一次；检查与棱镜叠加和敌死亡边界。
- 普通流影仅本实例首次真实翻开施血，跟踪次数不得被视觉预览或离场重入错误刷新。降低稀有度不改变效果。
- 初始牌5/5只是首选试验；同名集中优势仍需计算。篝火升级规则以生产核验为准，若全数值同比升级使起始牌升级后挤压机制牌、或放大次数上限/条件阈值，先审计升级字段和升级收益，不无授权禁止升级或改变升级倍率。

## 5. 构筑成型路径与代表组件

下表为实际可组合的例子，不是固定必拿卡、奖励硬保底、职业专属或数值已平衡的推荐牌库。每个体系至少有普通启动+普通或罕见桥接；同类卡应可替代而非要求特定名字。

| 轴 | 一章：独立启动→最小组合 | 二章：核心引擎与副轴 | 三章：强化兑现 |
|---|---|---|---|
| 连击 | 试锋/磨锋纹→轻刃/墨锋/三拍；夹页提前提供准备 | 磨砺、并击、游刃、近注、号令，连锁核心非必需 | 千刃、论证成篇、连环索引；与护盾/流血/消耗混搭 |
| 流血 | 开篇/挫锋→三拍/锯齿；承接作为防御补层 | 影袭、对照、鲜红涂刃、撕裂、血潮；棱镜为额外引擎 | 定稿、血祭、绝唱（跨状态）；不是唯一可兑现来源 |
| 中毒 | 毒雾/毒刺/飞墨→缓毒或毒发 | 毒针、墨蚀、订正、苦药、渗毒斩；毒血互换连通流血 | 腐蚀环作为一次性叠毒加速；绝唱跨状态终端 |
| 护盾 | 皮甲/稳步→刃甲；续甲、铁卫保证防御 | 盾击、反制、草稿、余盾、虎魄盾；能量护盾增强持盾 | 续写、随风成阵、长夜编目；与中毒或连击混搭 |

消耗贯穿四轴：一章急救包/破绽打击/稳步；二章磨砺/号令/应急护符/排阵等；三章构篇、随风成阵、腐蚀环等。仅按真实消耗事件计入构篇/随风成阵/叠页行军旗，返还不计；记忆王冠语义另审。不能把“消耗=弱牌只用一次”设计为所有消耗牌的定位。消耗缩小战斗牌组的价值须结合补牌规则、行动条、同名密度及记忆档测量。

### 可得性静态示例

只做理想化三张互异、全池等概率抽样；真实稀有度、章节、商店/事件、重复候选政策、权重和玩家选择未纳入。假设第一章某组有2个候选，旧39张池单次出现至少一个约15.0%，新42张池约13.9%，增加总池不必然提升可得性。新池中力量启动试锋/磨锋纹为2个，毒收益缓毒/毒发为2个，而旧一章两组均为0个。新池各组单次理想出现约13.9%，若固定6次独立菜单约59.3%至少见一次。该值不是完成构筑概率，且在罕见与普通混组时不能代替真实算法。实际应记录来源/兑现牌同时拥有并能触发的比例，不仅记录出现。

## 6. 奖励和遗物投放策略

先采用 A：保留生产抽样算法，只替换经审定的章次/稀有度及卡牌版本池。初始牌试验与章次试验分开；A0原V7.2、A1仅V7.3卡文+起始牌、A2再加入本稿章次/稀有度，使用同种子，避免把弱化与投放变化混成一次实验。

如果 A2 仍导致成型缺口，先评估 B：不读当前卡组的小幅全局权重修正（按缺失角色，候选权重×1.25，对照×1.0）。仍不足才评估 C：单个候选位对已有启动但缺兑现的轴弱倾向×1.5，其他位不变，非匹配合法卡仍有非零概率；保留稀有度抽样和去重语义，不强制三选一分成流派，不为玩家隐藏地设定单一职业方向。若多轴同时符合，按预先固定的可复现规则而非最佳预测选轴；具体随机实现必须先写契约。以上倍数仅实验参数，不是正式上线决定。地图/奖励机会不足应先修机会，再改权重；不要靠权重掩盖无法合法获得卡牌的路径。

遗物沿用原33件稀有度：普通11、罕见11、稀有7、Boss4；普通/罕见/稀有/Boss实际获取途径保持V7.2合同（普通战斗不掉、持有排除、合法池耗尽处理、种子、商店/事件等）。不设章次新锁、不增加稀有保底。代表角色：普通木盾/苦液瓶/血纹夹/磨刃石/封口绷带独立可用；罕见连锁核心/能量护盾/锯刃戒/酸蚀漏斗/撕裂指环强化循环；稀有血潮棱镜/毒蚀心脏/叠页行军旗/镜像回声推动成型与混搭。稳定锚、沿迹罗盘、双生符、共鸣石需重点评审强度与档位；若效果太弱优先改效，不仅因名称/旧稀有度保留。Boss遗物独立对照（全知之眼、混沌核心、记忆王冠、血契剑鞘），不要求某个Boss奖励才能成型；现行Boss候选不足回退逻辑需核实，不扩大普通战掉落。

## 1. 游戏概述

### 1.1 一句话概述

《记忆勇者》是一款以"记忆配对"为核心机制的卡牌肉鸽游戏。玩家在背面朝上的牌阵中凭记忆翻开卡牌寻找匹配，匹配成功触发卡牌效果来击败单一强敌。每一次翻牌都是行动，也推进敌人的攻势——记忆越准，代价越小。

### 1.2 核心卖点

- **记忆即策略**：记住牌面位置是核心技能，高手与新手之间有清晰的技艺差距。
- **词条即能力**：卡牌上的词条分为三类（触发型、效果型、匹配型），灵活组合出各种行为——改变匹配规则、在特定时机触发效果、修改卡牌去向等。
- **翻牌即代价**：没有能量，每一次翻牌都推进敌人行动条，每个决策都有重量。游戏以敌人行动作为隐性回合分隔（详见 [核心战斗机制](./01-核心战斗机制.md#25-行动条机制)）。

### 1.3 参考作品

- **杀戮尖塔（Slay the Spire）**：Run结构、牌组构建、遗物系统、敌人意图。
- **记忆配对游戏（Memory/Concentration）**：桌面翻牌配对的核心玩法。

## 2. 设计原则

以下是贯穿整个设计的核心原则，用于指导后续内容扩展和平衡性调整。

### 2.1 记忆是核心资源

玩家的记忆能力是这个游戏区别于其他卡牌游戏的核心。所有设计决策都应问一个问题：**"这个设计是增强还是削弱了记忆的价值？"**

- 增强记忆价值的设计：✓ 大部分翻牌组合无法匹配（匹配是稀缺事件）、✓ 残留牌跨批次保留位置、✓ 敌人干扰针对桌面物理状态。
- 削弱记忆价值的设计：✗ 通用属性匹配（如所有"火焰"牌都能互配）、✗ 翻开的牌永久可见、✗ 系统能"抹除"玩家的记忆。

### 2.2 翻牌是唯一行动

玩家在战斗中的唯一行动是"翻牌"。没有出牌、没有使用技能、没有能量管理。这意味着：

- 每一次翻牌都必须有重量——它推进敌人，所以不能无脑乱翻。
- 卡牌效果的触发完全由"翻牌"和"匹配"两个事件驱动。
- 所有策略都浓缩在"翻哪张牌"这一个决策上。

### 2.3 敌人只能动牌，不能动记忆

系统层面不存在"已被记忆"状态。系统只记录牌的位置和内容。敌人干扰玩家只能通过改变桌面牌的物理状态（移位、封锁、污染），不能直接操作玩家的记忆。

### 2.4 词条统一所有规则修饰

消耗、匹配规则、翻牌效果、卡牌去向——这些都通过三类词条（触发型、效果型、匹配型）这一统一机制来表达。这保证了系统的扩展性和一致性：任何新的卡牌行为都可以通过新增词条来实现，而不需要增加新的系统层。

## 4. 术语表

| 术语 | 定义 |
|---|---|
| **桌面（Board）** | 战斗中铺开的 4×4 网格牌阵（16格），卡牌在此被翻开和配对 |
| **相邻** | 以某格为中心的8格范围（上下左右+四个对角），边缘格相邻格数较少 |
| **牌组（Deck）** | 玩家在本 run 中收集的所有卡牌，桌面补牌从此抽取 |
| **弃牌堆（Discard）** | 丢弃/离场的牌暂存区，牌组耗尽时洗回 |
| **消耗堆（Exhaust）** | 带`[消耗]`词条的牌进入弃牌堆时改为进入此处，本场战斗不再可用，战斗结束回牌组 |
| **行动条（Action Bar）** | 敌人的蓄力值，翻牌+1、重新铺满+2，满则敌人行动 |
| **意图（Intent）** | 敌人公开的下次行动预告 |
| **词条（Tag）** | 卡牌的规则修饰符，分三类：触发型（时机+效果）、效果型（行为修饰）、匹配型（修改匹配规则） |
| **同名匹配** | 两张卡牌名称完全相同即匹配（默认规则） |
| **翻回（Flip-back）** | 主状态由正面转为背面（挤掉、被效果翻回），触发`[翻回]`词条 |
| **丢弃（Drop）** | 背面状态下移出桌面（重新铺满、被效果移走），触发`[丢弃]`词条，随后触发`[离场]` |
| **离场（Leave）** | 牌被移出桌面（匹配成功、能力牌翻开即移出等），触发`[离场]`词条（原`[消除]`）；背面牌移出在`[丢弃]`后触发，正面牌移出只触发`[离场]` |
| **批次补充** | 桌面可配对牌对数≤1时补充新牌的机制 |
| **重新铺满** | 玩家主动操作，清桌面+重铺，代价行动条+2 |
| **病毒牌** | 敌人塞入桌面的诅咒牌，通过`[翻开]`词条组合实现负面效果+移除，非特殊类别 |
| **格挡（Block）** | 临时防御资源，抵消伤害，每回合结束时清零 |
| **回合（Turn）** | 敌人两次行动之间的间隔（行动条从重置到填满为一个回合） |
| **遗物（Relic）** | 持久纯被动效果，贯穿整个 run，无主动使用能力 |
| **道具（Potion）** | 主动使用的消耗品，用完消失，携带上限3个 |
| **Run** | 一次完整的游戏流程，从开始到通关/失败 |

# V7.3 · 蓄步移除与移动机制边界

- 裁决日期：2026-11-25
- 状态：用户确认移除蓄步；卡牌/遗物替代效果待评审；Unity 尚未迁移。
- 本文覆盖 V7.3 目标中与 V7.2 文档 23/25/26/28/29/30/33 等冲突的蓄步设计；历史 V7.2 规则仍用于说明当前实现，不宣称已下线。

## 1. 已确认裁决

移除蓄步构筑、移动计数、翻开锁定、蓄步成长和兑现。不引入蓄能等替代资源。保留少量可选的玩家移动以及敌人换位、合法位置判断和移动轨迹反馈；移动不再生成蓄步。保留同名配对、翻开、翻回、消耗及连击、流血、中毒、护盾等共享构筑机制。降低记忆与空间操作叠加的负担。卡牌/遗物身份、名称和美术优先复用，不删历史 ID。

## 4. 实施前置与工程边界

1. 先完成上述卡牌/遗物的替代卡文、触发规则、数值及投放清单，避免将旧效果直接删除造成空卡。
2. 在游戏仓固定基线审计 PendingSteps、FlipLockedSteps、LifetimeSteps、HasMovedThisBattle 及其他蓄步字段、效果、事件、UI 详情和背面标识、AI/遥测、保存恢复、合同、测试的实际引用；其中曾移动标记仅在仍有明确非蓄步用途时保留。不得误删合法移动事件及实例身份追踪。
3. 保留敌人移动与合法方向操作的原有行为，不额外推进敌方行动条或泄露身份；换位双方不再获得蓄步。混沌核心等受影响效果按最终卡文复评。
4. 当前 V7.2 可试玩版本不因本策划稿变更。V7.3 存档策略待实施评审，至少保证新版本新局、保存、继续正确；旧存档不作未经验证的兼容承诺。
5. 不修改框架包，不恢复能力牌、位置几何配对或复杂的额外操作。避免替代效果退化成大量相同的翻回增伤；收益需有非递归边界。

## 5. 验收门

- 静态：正式 V7.3 卡牌、遗物、敌人、UI 不再依赖蓄步资源或展示蓄步关键词；旧历史资料/兼容代码如保留须明确标注。
- 战斗：玩家合法移动、敌方换位、混沌核心换位、轨迹反馈、身份不泄露、正常行动条与配对均正确；移动无蓄步增长、无隐性蓄步加成。
- 构筑：9 张蓄步牌替代效果和相关遗物逐项测试，移动不成为必需构筑资源；翻开、翻回、配对和消耗的回归测试通过；避免故意失败或递归触发产生无风险收益。
- 内容：最终卡池与商店、战后奖励、事件一致；稳定 ID、美术键、卡文及设计合同对账；新版本新局/保存/继续验证。
- Unity：按本地验证工具运行受影响专项、EditMode/PlayMode 全量及 Player 实机验收。以不同记忆档的固定种子测试和真人试玩比较操作次数、战斗时长、理解负担与构筑趣味性，不将自动化通过等同于趣味性验证。

将本裁决纳入 V7.3 构筑核心设计：四个战斗方向（连击、流血、中毒、护盾）× 四个卡牌机制（配对、翻开、翻回、消耗），力量等作为共享属性，不再规划蓄步流。先设计小规模原型再整批迁移。本文件不批准其余 96 张牌或 33 件遗物的最终重设计数值，不包含 Unity 变更。

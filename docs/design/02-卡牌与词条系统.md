## 1. 卡牌结构

每张卡牌由以下部分组成：

| 字段 | 说明 | 示例 |
|---|---|---|
| **名称** | 卡牌的唯一标识，决定同名匹配 | 「火球术」 |
| **类型** | 攻击 / 技能 / 能力 / 诅咒（见第2节） | 攻击 |
| **稀有度** | 普通 / 罕见 / 稀有 | 普通 |
| **基础效果** | 配对成功时触发的主要效果 | 造成6点伤害 |
| **词条** | 0~N个，卡牌的规则修饰符列表（见第3节） | 见第3节 |

## 2. 卡牌类型

卡牌分为四种类型，类型通过**卡面类型色**（描边边带+卡名徽带，v1.17 起）在翻开后识别；**卡背全类型统一**（通用卡背，见 09 §4.4.2），背面不泄露类型——"翻牌前只知道位置、不知道内容"是本作记忆挑战的基线。

| 类型 | 类型色 | 定位 | 行为 |
|---|---|---|---|
| **攻击** | 红色 | 伤害输出 | 参与同名匹配，配对触发伤害效果 |
| **技能** | 蓝色 | 功能/辅助 | 参与同名匹配，配对触发功能性效果 |
| **能力** | 紫色 | 持续生效 | 特殊生命周期（见第4节） |
| **诅咒** | 紫黑 | 负面干扰 | 塞入玩家牌库，翻开触发负面效果 |

**通用卡背的策略意义（2026-08-25 由四色卡背改为通用）：**
- 背面信息归零，记忆体验回归纯粹的"记位置+记内容"。
- 诅咒牌无法从背面识别——规避靠翻开后记住位置，或学者情报能力（[标记]/[揭示]），情报流价值提升。
- 能力牌同理：判断"哪张是能力牌"依赖记忆或情报，"留还是翻"的决策更紧张。
- 类型识别发生在翻开后：类型色边带+胶囊第一眼可读，作为即时反馈而非预习信息。

## 3. 词条系统（核心设计）

词条是挂在卡牌上的规则修饰符，分为三类：

### ① 触发型词条（时机 + 效果描述）

词条名代表**触发时机**，后跟具体的效果描述。同一时机的词条在不同卡上可有不同效果。**每次效果触发，该牌按顺序记入记忆堆**（记录规则见 [01·牌区系统](./01-核心战斗机制.md#93-记忆堆记录规则)）。

**触发时机关键词（固定集合，共5种）：**

| 时机关键词 | 含义 | 内置约束 |
|---|---|---|
| `[翻开]` | 主状态由背面转为正面时触发（见 [01·卡牌状态](./01-核心战斗机制.md#4-翻牌与匹配流程精确规则)） | — |
| `[翻回]` | 主状态由正面转为背面时触发 | — |
| `[丢弃]` | 背面状态下移出桌面时触发 | 触发后继续触发`[离场]` |
| `[离场]` | 牌从桌面被移出时触发 | 仅"桌面→弃牌堆/消耗堆/移除"的转移触发，抽牌堆耗尽循环（弃牌堆洗回抽牌堆）不算；背面牌移出时在`[丢弃]`之后触发 |
| `[入场]` | 在场上首次被翻开时触发 | 离场后重置此效果，重新铺场后可再次触发 |

**触发型词条格式：** `[时机]: 效果描述`

**示例：**
```
[翻开]: 随机翻开周围一张背面牌
[翻开]: 获得2点格挡
[翻开]: 造成3点伤害；移除自身     ← 病毒牌的典型实现
[离场]: 抽1张牌到桌面
[翻回]: 获得1点格挡     ← 被挤掉/翻回时触发
[丢弃]: 获得2点格挡     ← 背面被移走时触发
[入场]: 相邻牌获得+1效果     ← 在场上首次被翻开时触发，离场后重置
```

### ② 效果型词条（行为修饰符）

没有触发时机，是挂在卡牌上的**属性/修饰**，改变卡牌的行为方式。一张卡可挂多个效果型词条，它们也可以与触发型词条自由组合。

| 词条 | 效果 |
|---|---|
| `[消耗]` | 这张牌进入弃牌堆时改为进入消耗堆。本场战斗内不再可用。 |
| `[移除]` | 这张牌进入弃牌堆时改为从游戏中移除。 |
| `[顽固(x)]` | 这张牌抵挡接下来的 x 次离场：本应离场时留在桌面原格（主状态不变），x−1；x 归 0 后离场正常生效。不影响`[翻回]`。 |
| `[隐秘]` | 这张牌被丢弃（背面状态下移出桌面）时，触发这张牌的基础效果。 |
| `[迅速]` | 这张牌被翻开时，本次翻牌不使敌人行动条 +1。 |

> 注：消耗/移除的区别——消耗堆的牌在抽牌堆耗尽洗回时不参与（本场战斗永久消耗），移除则更彻底。两者都只作用于战斗牌区，战斗结束后牌库不受影响（见 [01·牌区系统](./01-核心战斗机制.md#9-牌区系统)）。

**顽固/隐秘/迅速的结算细则：**

- `[顽固(x)]`：
  - 只抵挡**离场**（移出桌面）：匹配消除、效果移走、重新铺满清桌等途径一律拦截。离场被拦截则`[消耗]`/`[移除]`的去向改写自然也不发生。
  - **不影响`[翻回]`**：翻回（正面→背面，如超限挤掉、被效果翻回）照常发生，顽固不拦——它只管"不离场"，不管"不被翻回"。
  - 抵挡时牌留在原格、主状态不变（正面牌保持正面，仍参与匹配判定）；该次离场没有发生——不触发`[离场]`/`[丢弃]`、不记入记忆堆、不计入补牌检查的"有牌离场"判定（见 [01·步骤9](./01-核心战斗机制.md#4-翻牌与匹配流程精确规则)）。
  - **配对仍然成功**：基础效果照常结算，配对的另一张牌正常离场；若配对双方都带顽固且剩余次数>0，则双双留场——此时对留场后的桌面**额外执行一次正面牌超限检查**（同 [01·步骤6](./01-核心战斗机制.md#4-翻牌与匹配流程精确规则)：正面牌超过上限时，最早翻开的正面牌翻回，触发`[翻回]`；匹配路径不经过步骤6，由本条兜底）。
  - 参数写法如`[顽固(2)]`；x 只在战斗内递减，战斗结束词条重置（牌库不受战斗影响，见 [01·牌区系统](./01-核心战斗机制.md#9-牌区系统)）。
- `[隐秘]`：
  - 这张牌被**丢弃**（背面状态下移出桌面）时，**触发这张牌的基础效果**（单牌结算，无配对对象）。触发顺序：`[丢弃]`词条 → 隐秘的基础效果 → `[离场]`词条。
  - 触发途径即一切"背面离场"场景：被效果丢弃（消散风/清理等）、重新铺满清桌等。**正面状态的离场不触发隐秘**（只触发`[离场]`，与普通牌一致）。
  - 配对触发保留：基础效果仍照常在配对成功时结算，隐秘只是增加"被丢弃时"这一额外触发时机；该次触发同样记入记忆堆（见 [01·记忆堆记录规则](./01-核心战斗机制.md#93-记忆堆记录规则)）。
  - 设计用途：丢弃流收益牌——被效果移走/清桌丢弃时暗中发动效果，与风眼（丢弃放大器）天然联动。
- `[迅速]`：
  - 只跳过"翻开这张牌"引发的 +1；同一条结算链中其他牌被翻开（如`[翻开]`词条连锁翻开的牌）照常 +1。
  - 本次行动条未增加 → 没有"行动条数值变化"，因行动条变化触发的状态结算（灼烧/冰冻）不因本次翻牌发生（见 [01·状态结算时机](./01-核心战斗机制.md#61-状态结算时机)）。

### ③ 匹配型词条（修改匹配规则）

声明特殊的跨名匹配关系，是唯一能突破"同名匹配"默认规则的词条类型。这类词条**稀缺**，只出现在少数特殊卡牌上。

| 词条 | 效果 |
|---|---|
| `[共鸣]` | 可与任意其他带`[共鸣]`的牌匹配 |
| `[剑]` | 可与`[盾]`牌跨名匹配 |
| `[盾]` | 可与`[剑]`牌跨名匹配 |

> 注：`[笔记]` 词条已移除（2026-08-27），学者初始卡的专属对改用`[共鸣]`。

### 词条组合规则

一张卡牌可同时挂多个任意类型的词条，它们自由组合。例如一张牌可以同时有：
```
[翻开]: 获得2点格挡        （触发型）
[消耗]                    （效果型）
[共鸣]                    （匹配型）
```

### 词条数量

- 每张卡牌的词条数量**不设上限**。
- 实际设计中通过稀有度和平衡性控制。

### 匹配判定（精确算法）

当新翻的牌触发匹配判定时（与桌面**所有**已翻开的正面牌逐一判定，见 [01·翻牌分步结算](./01-核心战斗机制.md#4-翻牌与匹配流程精确规则)）：

1. 取新翻开的牌的名称 `N2` 和匹配型词条集 `M2`。
2. 按翻开顺序（从最早开始）逐张取桌面正面牌的名称 `N1` 和匹配型词条集 `M1`，判定匹配：
   - **同名匹配**：`N1 == N2` → 匹配成功。
   - **词条匹配**：检查是否存在匹配型词条对 `(a, b)`，其中 `a ∈ M1`，`b ∈ M2`，且 `a` 声明了与 `b` 的匹配关系 → 匹配成功。
3. 与任意一张正面牌满足任一条件 → **匹配成功**，与该张配对（多张可匹配时与最早翻开的配对）。

## 4. 能力牌（特殊生命周期）

能力牌有独特的生命周期，区别于其他三种类型。

**能力牌只具备一种效果——持续效果：**
- 持续效果在能力牌**翻开后触发**，本场战斗内持续生效（不依赖牌是否在场）。
- 能力牌**背面**在桌面时无任何效果，仅作为普通占位牌。

**默认生命周期——翻开即移出桌面：**
- 能力牌被翻开 → 触发持续效果 → 立即移出桌面（进弃牌堆，触发 `[离场]`）。
- 持续效果在牌离场后仍保持生效，直至本场战斗结束。

**核心决策——翻不翻：**
- 翻开能力牌 = 永久获得其持续效果（本场战斗），牌离场并腾出格子。
- 代价：翻开推进行动条（+1）、占用一次翻牌；背面时无法判断哪张是能力牌。

> 注：通用卡背不泄露类型——玩家只能凭记忆或情报（[标记]/[揭示]）判断某张牌是否为能力牌，无法直接知道具体是哪张（除非之前翻开过并记住了位置）。

## 5. 通用卡牌池

以下为通用卡牌池（全角色可获得的奖励卡/商店卡），围绕六类核心效果设计，展示效果在**基础效果**与**事件词条**上的两种承载。角色专属卡牌见 [学者角色卡牌设计](./06-学者角色卡牌设计.md)。

**卡池规则：**
- 每张卡**成对出现**（同名×2），配对成功触发**基础效果**。
- 效果可承载于基础效果（配对时）或**事件词条**（`[翻开]`/`[翻回]`/`[丢弃]`/`[离场]`，时机定义见 [01·卡牌状态](./01-核心战斗机制.md#4-翻牌与匹配流程精确规则)）。
- 六类核心效果：**随机丢弃周围 / 指定丢弃 / 施加状态 / 伤害·护盾 / 恢复生命 / 随机翻开周围**。
- 强度基准与通用基底对齐（普通攻击/格挡基准 6）；事件词条数值约为基础值的 1/3~1/2。
- 状态数值约定：灼烧每层造成 2 点伤害（触发后层数-1）；中毒每层 1 点伤害（层数不衰减）；易伤/虚弱持续 N 回合。

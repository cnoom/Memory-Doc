## 1. 卡牌结构

每张卡牌由以下部分组成：

| 字段 | 说明 | 示例 |
|---|---|---|
| **名称** | 卡牌的唯一标识，决定同名匹配 | 「火球术」 |
| **类型** | 攻击 / 技能 / 能力 / 诅咒（见第2节） | 攻击 |
| **稀有度** | 普通 / 罕见 / 稀有 | 普通 |
| **基础效果** | 配对成功时触发的主要效果 | 造成6点伤害 |
| **词条** | 0~N个，卡牌的规则修饰符列表（见第3节） | 见第3节 |

## 2. 卡牌类型

卡牌分为四种类型，**不同类型的卡牌卡背颜色不同**。玩家能从卡背辨认类型，无需翻开即可知道类别——这是重要的记忆信息分层。

| 类型 | 卡背颜色 | 定位 | 行为 |
|---|---|---|---|
| **攻击** | 红色 | 伤害输出 | 参与同名匹配，配对触发伤害效果 |
| **技能** | 蓝色 | 功能/辅助 | 参与同名匹配，配对触发功能性效果 |
| **能力** | 紫色 | 持续生效 | 特殊生命周期（见第4节） |
| **诅咒** | 黑色 | 负面干扰 | 塞入玩家牌组，翻开触发负面效果 |

**卡背机制的策略意义：**
- 玩家看到的不仅是"某张牌在哪"，还有"它是什么类型"。
- 诅咒牌的黑色卡背一眼可辨——玩家可主动选择避开或承受代价换信息。
- 能力牌的紫色卡背提示"留着它可能有持续收益"。
- 这让记忆体验从"记位置"升级为"记位置+记类型"，增加了信息密度和决策深度。

## 3. 词条系统（核心设计）

词条是挂在卡牌上的规则修饰符，分为三类：

### ① 触发型词条（时机 + 效果描述）

词条名代表**触发时机**，后跟具体的效果描述。同一时机的词条在不同卡上可有不同效果。

**触发时机关键词（固定集合，共3种）：**

| 时机关键词 | 含义 | 内置约束 |
|---|---|---|
| `[翻开]` | 这张牌被翻开时触发 | — |
| `[消除]` | 这张牌从桌面进入弃牌堆时触发 | 仅"桌面→弃牌堆"的转移触发，牌组循环时弃牌堆洗回牌组不算 |
| `[入场]` | 这张牌被铺到桌面时触发 | — |

**触发型词条格式：** `[时机]: 效果描述`

**示例：**
```
[翻开]: 随机翻开周围一张背面牌
[翻开]: 获得2点格挡
[翻开]: 造成3点伤害；移除自身     ← 病毒牌的典型实现
[消除]: 抽1张牌到桌面
[入场]: 相邻牌获得+1效果
```

### ② 效果型词条（行为修饰符）

没有触发时机，是挂在卡牌上的**属性/修饰**，改变卡牌的行为方式。一张卡可挂多个效果型词条，它们也可以与触发型词条自由组合。

| 词条 | 效果 |
|---|---|
| `[消耗]` | 这张牌进入弃牌堆时改为进入消耗堆。本场战斗内不再可用。 |
| `[移除]` | 这张牌进入弃牌堆时改为从游戏中移除。 |

> 注：消耗/移除的区别——消耗堆的牌在牌组耗尽洗回时不参与（本场战斗永久消耗），移除则更彻底。两者战斗结束后都回到牌组。

### ③ 匹配型词条（修改匹配规则）

声明特殊的跨名匹配关系，是唯一能突破"同名匹配"默认规则的词条类型。这类词条**稀缺**，只出现在少数特殊卡牌上。

| 词条 | 效果 |
|---|---|
| `[共鸣]` | 可与任意其他带`[共鸣]`的牌匹配 |
| `[笔记]` | 可与任意其他带`[笔记]`的牌匹配 |
| `[剑]` | 可与`[盾]`牌跨名匹配 |
| `[盾]` | 可与`[剑]`牌跨名匹配 |

### 词条组合规则

一张卡牌可同时挂多个任意类型的词条，它们自由组合。例如一张牌可以同时有：
```
[翻开]: 获得2点格挡        （触发型）
[消耗]                    （效果型）
[共鸣]                    （匹配型）
```

### 词条数量

- 每张卡牌的词条数量**不设上限**。
- 实际设计中通过稀有度和平衡性控制。

### 匹配判定（精确算法）

当玩家翻开第二张牌时：

1. 取第一张牌（刚翻回的）的名称 `N1` 和匹配型词条集 `M1`。
2. 取第二张牌的名称 `N2` 和匹配型词条集 `M2`。
3. 判定匹配：
   - **同名匹配**：`N1 == N2` → 匹配成功。
   - **词条匹配**：检查是否存在匹配型词条对 `(a, b)`，其中 `a ∈ M1`，`b ∈ M2`，且 `a` 声明了与 `b` 的匹配关系 → 匹配成功。
4. 只要满足任一条件 → **匹配成功**。

## 4. 能力牌（特殊生命周期）

能力牌有独特的生命周期，区别于其他三种类型。

**能力牌具备两种效果：**
- **翻开效果**：通过 `[翻开]` 触发型词条实现，翻开时即时触发。
- **持续效果**：只要这张能力牌在桌面上就持续生效，**无论正面或背面**。

**默认生命周期——翻开即消除：**
- 能力牌被翻开 → 触发 `[翻开]` 效果 → 然后立即从桌面消除（进弃牌堆，触发 `[消除]`）。
- 默认情况下能力牌翻开就消失，不会停留在桌面。

**持续效果的生效条件：**
- 能力牌**背面朝上**铺在桌面时 → 持续效果**生效**。
- 能力牌被**翻开** → 持续效果结束（因为翻开即消除）。

**核心决策——留还是翻：**
玩家面临选择：
- **留着它（不翻）** → 持续效果生效，但你不知道是哪张具体的能力牌（除非凭记忆或卡背紫色识别）。代价是它占用一个桌面槽位。
- **翻开它** → 获得一次性翻开效果，但持续效果消失，牌被消耗。

这创造了"牺牲持续收益换即时收益"的策略张力。

> 注：玩家可通过紫色卡背识别某张牌是能力牌，但无法知道具体是哪张能力牌（除非之前翻开过并记住了位置）。

## 5. 卡牌示例（完整）

以下为通用示例，展示卡牌结构的各种组合。角色专属卡牌见 [学者角色卡牌设计](./06-学者角色卡牌设计.md)。

```
═══════════════════════════════════════
  火球术                    [普通·攻击]
  ─────────────────────────────────────
  基础效果: 造成6点伤害
  
  词条: 无
  
  说明: 纯粹的同名匹配卡，需两张火球术配对触发
═══════════════════════════════════════

  侦察兵                    [普通·技能]
  ─────────────────────────────────────
  基础效果: 造成3点伤害
  
  词条: [翻开]: 随机翻开周围一张背面牌
═══════════════════════════════════════

  铁壁                      [罕见·技能]
  ─────────────────────────────────────
  基础效果: 获得6点格挡
  
  词条: [翻开]: 获得2点格挡
═══════════════════════════════════════

  守护结界                  [罕见·能力]
  ─────────────────────────────────────
  持续效果: 背面在桌面上时，相邻牌基础效果+1
  翻开效果: [翻开]: 获得3点格挡
  
  说明: 留着持续生效（增强邻牌），翻开则拿一次性格挡
═══════════════════════════════════════

  魔力共鸣                  [稀有·技能]
  ─────────────────────────────────────
  基础效果: 造成4点伤害，抽1张牌到桌面
  
  词条: [共鸣]
       [消耗]
  
  说明: 稀有的跨名匹配卡，灵活但一次性
═══════════════════════════════════════

  腐化诅咒                  [诅咒]
  ─────────────────────────────────────
  词条: [翻开]: 失去2点血量；移除自身
  
  说明: 事件/敌人塞入玩家牌组，黑色卡背可辨，
       玩家可选择避开或承受代价
═══════════════════════════════════════

  病毒牌（敌人塞入）        [诅咒]
  ─────────────────────────────────────
  词条: [翻开]: 受到3点伤害；移除自身
  
  说明: 不是特殊类别，通过触发型词条组合实现
       （负面效果+移除），和普通牌处理流程一致
═══════════════════════════════════════
```

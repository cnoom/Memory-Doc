## 1. 敌人结构

敌人是玩家所有决策的压力来源。核心职能：用行动条制造时间压力，用意图系统提供策略信息，用特殊能力制造变数。

```
敌人 = {
  名称:         「石巨人」
  最大血量:     当前血量 / 最大血量
  行动条:       当前值 / 阈值
  意图:         下次行动将做的事（对玩家完全可见）
  能力:         被动效果列表
  状态:         增益/减益列表
  阶段:         （仅Boss）当前阶段及切换条件
}
```

## 2. 意图系统

**敌人完全公开下次行动**，包括类型和数值。借鉴杀戮尖塔的意图系统，玩家可据此规划配对策略。

| 意图类型 | 显示内容 | 玩家应对策略 |
|---|---|---|
| **攻击** | "下次攻击造成X点伤害" | 优先配护盾/回血牌 |
| **蓄力** | "正在蓄力，下次攻击翻倍" | 趁机全力输出 |
| **防御** | "将获得X点护甲" | 可能需要破甲手段 |
| **特殊** | "将使用[能力名]" | 根据效果应对 |
| **狂暴** | "行动条阈值降低" | 加速击杀 |

意图在行动条重置时刷新——玩家始终能看到敌人下次会做什么。

> **蓄力语义注记（v1.32）**：「蓄力」= 本回合不攻击的行动占位，为下一波攻击做节奏预告。攻击结算**以意图标注值为准**——意图已显式标注数值与次数时（如双刃执行者"攻击(10×2连击)"）按标注结算，不叠加"翻倍"；「下次攻击翻倍」仅在敌人意图未显式标注攻击数值时用于推算实际伤害。

## 3. 敌人能力

敌人拥有类似卡牌"词条"的被动特性，用来制造变数。

**核心设计原则：敌人只能干扰桌面牌的物理状态，不能干扰玩家的记忆。** 系统层面不存在"已被记忆"状态。系统只记录牌的位置和内容，玩家记不记得是玩家自己的事。敌人只能动牌，不能动记忆。

### 能力分类

**位置干扰型：**

| 能力 | 效果 |
|---|---|
| 「混乱」 | 行动时随机交换桌面2张牌的位置 |
| 「换位」 | 行动时将网格第1列和第4列的牌整体互换 |
| 「洗牌」 | 行动时重新随机排列所有桌面牌 |

**可用性干扰型：**

| 能力 | 效果 |
|---|---|
| 「封锁」 | 行动时给一张桌面牌加`[封锁]`标记，暂时无法参与匹配 |
| 「冰封」 | 行动时冻结一张桌面牌，翻开时不触发词条效果 |

**桌面污染型：**

| 能力 | 效果 |
|---|---|
| 「污染」 | 行动时往桌面塞一张病毒牌（详见第4节） |
| 「增生」 | 行动时复制一张桌面牌（增加一张同名牌，可能帮助或干扰玩家） |

**节奏施压型：**

| 能力 | 效果 |
|---|---|
| 「急躁」 | 行动条阈值低（如7而非10），更频繁攻击 |
| 「重击」 | 攻击伤害高但行动条阈值也高 |
| 「连击」 | 行动条满时连续攻击2次 |
| 「狂暴」 | 血量低于50%时行动条阈值降低 |

> 具体敌人的能力配置与数值，见 [原型敌人设计](./08-原型敌人设计.md)。

#### 能力细则（v1.32）

- **连击结算**：「连续攻击2次」= **2 个独立伤害实例**依次结算——格挡池依次扣减、易伤/虚弱各自独立乘算、受击触发类效果各自触发。
- **换位（列互换）**：「第1列和第4列整体互换」= 两列**同行格位成对互换**（第1列第i行 ↔ 第4列第i行，i=1~4）。移动的牌主状态不变（正/背面保持），与「混乱」共用桌面移动路径——**稳定锚对换位/混乱/洗牌均免疫**（07§4，免疫作用于全部敌人桌面移动）。
- **封锁细则**：
  - 目标选取：随机 1 张**桌面存活牌**（正/背面皆可；排除病毒牌与已封锁牌——封锁病毒牌无意义）。
  - 效果：被封锁的牌**可正常翻开**（[翻开]词条照常触发），但**不发起也不接受匹配判定**；正面被封锁的牌仍占正面牌数量上限。
  - 解除时点：「持续至本回合结束」= 敌人**下次行动序列完成时**统一清除全部封锁标记（与新回合开始同步）。
- **污染落格**：病毒牌塞入桌面**随机 1 个空格**（背面朝上）——桌面因配对消除/批次未补常态存在空格（01§7 补牌为"可配对牌对数≤1"才触发）；**塞入时若无空格则本次落空**（不替换、不移除现有牌）。病毒牌离场后其格位进入正常补牌检查流。

## 4. 病毒牌

敌人通过"污染"能力塞入桌面的干扰牌。

**特性：**
- 不属于玩家牌库，是敌人塞入桌面的诅咒牌。
- **无法匹配**——不带匹配型词条，默认同名匹配下找不到搭子（因为桌面只有一张）。
- **翻开即结算**——通过 `[翻开]: 负面效果` + `[翻开]: 移除自身` 的触发型词条组合实现，和普通牌处理流程一致。
- 不会永久卡死桌面，玩家有多种处理方式：
  - 不小心翻到 → 承受负面效果 + 行动条 +1，但病毒牌被清除。
  - 记得它在哪 → 主动避开，但它持续占位阻碍配对。
  - 主动翻它清掉 → 承受代价换桌面干净。
  - 花行动条 +2 重新铺满 → 不承受病毒效果，但敌人加速。

> 具体病毒牌设计（腐化种子、记忆尘埃、虚空裂痕等），见 [原型敌人设计·病毒牌配套设计](./08-原型敌人设计.md#5-病毒牌配套设计)。

## 5. 普通敌人 vs Boss

**普通敌人：**
- 1~2 个能力。
- 单阶段。
- 行动条阈值较低（更快结束战斗）。
- 血量适中。

**Boss：**
- 3~4 个能力。
- **多阶段**——血量降到阈值触发阶段切换。
- 阶段切换时改变能力组合、行动条阈值、意图模式。
- 可能改变桌面规则（如阶段2开始封锁词条）。
- 必掉稀有遗物。

### Boss 阶段切换规则

- 阶段切换以血量百分比为触发条件（如 60%、30%）。
- 每次切换：能力增加或替换、行动条阈值可能降低、攻击伤害可能提升。
- 意图模式在阶段切换时重新设定。
- 阶段切换给玩家清晰的"形势恶化"感知。

**切换时点与状态处理（v1.32）**：

- **检查时点**：每次对 Boss 造成伤害的结算完成后**立即检查**血量百分比跨越（含配对伤害、独立伤害实例、病毒牌代价等全部玩家伤害来源；多处跨越如一击从 70% 打到 25% 时直接进入目标阶段，不逐段结算中间阶段）。
- **即时更新**：跨越时立即切换——能力组合、行动条阈值、攻击伤害即时更新为新阶段值；**行动条当前值保留**（不清零、不回退）。
- **意图重置**：意图索引重置为 0（新阶段意图模式从头开始，玩家立即可见新阶段首次意图）。
- **遗物阈值修饰**：行动条阈值类修饰（减速印记 +1）作用于**当前阶段基础阈值**（如阶段3基础8 → 实际9），阶段切换时随基础值重算。

> 具体Boss设计（记忆吞噬者的三阶段配置），见 [原型敌人设计·Boss](./08-原型敌人设计.md#4-boss1种)。

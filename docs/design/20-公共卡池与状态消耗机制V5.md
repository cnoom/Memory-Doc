## 1. 设计裁决及范围

1. **所有职业共用50种奖励卡牌**：旧S01–S30、N01–N20保留编号，仅是历史来源，不代表职业权限。稀有度普通23／罕见21／稀有6。奖励、商店、事件以后使用统一公共奖励池；职业没有专属卡牌，差别来自专有职业被动或将来单独设计的主动。
2. 正常奖励牌仅**攻击**、**技能**两种；**删除能力牌类型与翻开即激活光环**的生命周期。旧6张能力牌转为带[消耗]的技能牌，其效果必须通过成功配对结算。负面诅咒与病毒仍属于特殊负面卡，不计入奖励类型。
3. 设定**10种[消耗]**、40种普通循环奖励牌；具体见表。消耗只在成功配对完成后执行；战斗结束不删Run牌库。
4. **连击＝同一攻击卡的一次效果造成多段直接攻击**（如2×3），并非连续成功配对次数的公共增益。连续配对仅为少数卡牌的独立条件。
5. **力量对每一段直接攻击以及每一次独立附加伤害都+1/层**；灼烧／中毒的行动条结算伤害不享受力量。新增力量、流血两种状态，原6种状态保持原行为。
6. **学者「融会贯通」**：每次真正手动翻开一张战斗牌实例，其可强化数值效果+1；同实例最多叠2层，离场清零。角色机制不影响公共卡池权限。
7. 不使用相邻、同排、角落、象限等配对格位条件，也不使用行动条数值窗口当奖励收益条件；记忆位置本身仍是核心玩法。
8. 保留现有4×4桌面、同名匹配、异名共鸣基础30%规则、行动条、死亡即停、12张学者起始牌配方及Run级软扩容。**本版数值和10张消耗密度为待试玩平衡基准**。

## 2. 卡牌类型与[消耗]完整语义

| 类别 | 行为 |
|---|---|
| 攻击 | 直接攻击段、附伤、状态施加、状态引爆，可带[消耗] |
| 技能 | 格挡、护甲、治疗、力量、增伤、流血、附伤等，可带[消耗] |
| 诅咒／病毒 | 保持特殊负面牌处理，不归入正常奖励牌 |
| 能力 | **取消**；原翻开即触发并持续生效的能力牌取消 |

- 正常奖励卡配对时，两个参与配对的战斗实例各自结算写明“每张”的效果；“整对”只执行一次。同名配对和合法异名共鸣成功均遵循这套规则。成功配对的两张牌按各自词条分别去向。
- **[消耗]**：当该牌**成功参与配对且其结算正常完成并离场时**，送入消耗堆，本场无法重抽／洗回；若因未配对的普通弃置、主动重铺等离场则按普通弃牌处理，保留循环机会。未配对不会提前消耗。该语义**有意覆盖**旧02“任何进入弃牌堆时都改为消耗”的规则，是未来实施需迁移的差异。
- 一对两个战斗实例均具[消耗]时各自进消耗堆；配对时若触发死亡即停，未完成的效果不补结算。消耗只影响本场战斗复制的实例，不删除局外牌库。
- [顽固]阻止离场、[隐秘]背面弃置效果、[移除]优先级及异名共鸣混合配对的去向，需要在实施时做专项验证；本轮先以**成功配对正常完成且真实离场**作为[消耗]生效必要条件。
- 转换后的长夜编目、校对、连环索引、学术直觉、应急护符、磨砺必须配对才能生效；力量等已获得的持久状态或“下一组配对”增益在卡牌消耗后按其自身持续期继续有效。

## 3. 力量、直接攻击、附加伤害与流血

| 机制 | 新规则 |
|---|---|
| 力量（新增） | 自身叠加，默认本场持续。每一段直接攻击和每个独立附伤包基础伤害+力量层数；不加成灼烧或中毒的定时结算 |
| 多段攻击 | 写作2×3＝每张2段，每段基础3伤；两个实例成功配对通常共4次直接攻击。每段独立受力量、易伤、格挡、护甲 |
| 附加伤害 | 独立伤害事件，**受力量**；不再算一次直接攻击命中，不会再次触发流血、追击、施毒或自身同类附伤，禁止递归 |
| 流血（新增） | 持有者每受到一段**有效直接攻击**，在该段结算后按当前流血层数造成**一包附伤**，然后流血-1；流血附伤受力量、易伤 |
| 有效命中 | 直接攻击段在格挡／护甲扣减前修正后伤害大于0；即便被护甲抵尽，仍触发命中附带效果；段伤害为0则不触发 |
| 状态引爆 | 消耗指定状态层数，将“层数×系数”的伤害**合并为一包附伤**，力量只加一次，不可拆包刷力量；0层不产生伤害包 |
| 易伤/虚弱 | 沿用既有规则：易伤放大受到的伤害（含附伤和定时状态伤），虚弱只影响敌方攻击，百分比修饰一次向下取整 |
| 结算序 | 卡牌基础段值＋学者来源强化＋力量＋其他固定加法 → 百分比效果 → 格挡 → 护甲 → HP；死亡立即停止后续段与触发 |

- 例如4层流血连续受到3段有效攻击，触发4、3、2的**三包附伤**，基础合计9；若力量2且无其他修饰，每包额外+2，流血附伤合计15。
- 冰冻可能抑制灼烧的行动条变化、延迟中毒的敌人行动触发，这种流派取舍保留。
- **整对引爆一次**、**命中附伤每有效直接攻击段一次**，必须严格区分，以免多段乘法重复结算。

## 4. 学者职业被动「融会贯通」

> 每次**真正手动翻开**一个战斗卡牌实例，该实例可强化的有益固定数值效果**+1**，累计最多**2层**；本次翻牌即时生效，**任何原因离开桌面后清零**。不因顺序入场预览、查看详情、仅UI展示或自动翻开而强化。再次手动翻开同一实例可累加，两个同名实例分开记数。

| 被动可强化 | 不强化 |
|---|---|
| 每段直接攻击的伤害基数；每次有卡牌来源的固定附伤基数；格挡、护甲、治疗；施加力量／流血／中毒／灼烧／冰冻等层数；固定护甲削减值 | **攻击段数**、触发次数／周期限制、概率、百分比倍率、状态持续回数（易伤／虚弱）、条件门槛、固定代价（支付格挡／生命／状态）、动态的状态层数转换系数 |

- 标明“整对一次”的固定数值，按照配对两个来源实例的强化层数**取最大值后强化一次**，不将两张卡的强化层数相加。
- 例如两张磨砺都首次手动翻开，基础整对+1力量，双方强化+1，最终整对获得**2力量**，完成配对后两张消耗。
- 2×3的攻击牌实例第一次手动翻开后为2×4；若自身已有力量2，则该实例每段最终基础6，不额外加攻击次数。
- 状态引爆的“每消耗1层造成3伤”属于公式系数，**不会变成每层4**；若这一引爆形成固定基础附伤，可以只对该独立附伤包按来源规则加固定值，不修改系数。

## 5. 状态体系（8种）

| 状态 | 结算方式 |
|---|---|
| 力量（新增） | 自身叠加、默认本场持续；每段直接攻击与每个独立附伤包+1／层 |
| 流血（新增） | 每次有效直接攻击后按现有层数造成一包附伤，然后层数-1；附伤受力量和易伤，不递归 |
| 灼烧 | 原规则：行动条实际变化后造成层数×2伤，再减1层 |
| 中毒 | 原规则：敌人行动后造成层数×1伤，层数不衰减 |
| 冰冻 | 原规则：消耗层数抵消行动条增长，可能阻止灼烧此次触发 |
| 护甲 | 原规则：受击时在格挡后抵消伤害，池可累加 |
| 易伤 | 原规则：目标受伤×1.5，按原回合持续和取整 |
| 虚弱 | 原规则：敌人攻击伤害×0.75，按原回合持续和取整 |

## 7. 职业、起始牌与构筑

- 职业**没有专属奖励卡**，也不把学者原S来源的卡牌锁定给学者。未来狂战士、术士可使用同一奖励牌集合；差异由独特职业被动／将来定义的主动能力产生。尚未确定其他职业被动，不继续采用旧占位的“狂怒”“双面”作为本版已定案。
- 现阶段学者正式Run起始牌保留12份：打击×5（单张1×6）、格挡×5（单张6格挡）、笔记×1（单张1×8／共鸣）、读书笔记×1（单张7格挡／共鸣）。这是**目前起始配方**，不表示其他职业无法获得相同牌名。
- 推荐流派：力量＋多段（磨砺／长夜编目→墨锋／续写→孤注或论证成篇）；流血＋追击（挫锋／开篇→追猎→定稿）；毒层积累与消耗（毒针／墨蚀→苦药／订正）；灼烧与引爆（火星／引火注→插叙）；格挡转换攻击（铁卫／皮甲→盾击／孤注）。
- 10种消耗卡分成**启动技能**（磨砺、长夜编目等）、**救急／施加易伤**（急救包、应急护符、破绽打击）和**终结**（定稿、论证成篇）；长期循环由剩余40种承担。

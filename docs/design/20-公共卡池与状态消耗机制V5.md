## 1. 设计裁决及范围

1. **所有职业共用50种奖励卡牌**：旧S01–S30、N01–N20保留编号，仅是历史来源，不代表职业权限。稀有度普通23／罕见21／稀有6。奖励、商店、事件以后使用统一公共奖励池；职业没有专属卡牌，差别来自专有职业被动或将来单独设计的主动。
2. 正常奖励牌仅**攻击**、**技能**两种；**删除能力牌类型与翻开即激活光环**的生命周期。旧6张能力牌转为带[消耗]的技能牌，其效果必须通过成功配对结算。负面诅咒与病毒仍属于特殊负面卡，不计入奖励类型。
3. 设定**10种[消耗]**、40种普通循环奖励牌；具体见表。消耗只在成功配对完成后执行；战斗结束不删Run牌库。
4. **连击＝同一攻击卡的一次效果造成多段直接攻击**（如2×3），并非连续成功配对次数的公共增益。连续配对仅为少数卡牌的独立条件。
5. **力量对每一段直接攻击以及每一次独立附加伤害都+1/层**；灼烧／中毒的行动条结算伤害不享受力量。新增力量、流血两种状态，原6种状态保持原行为。
6. **学者「融会贯通」**：每次真正手动翻开一张战斗牌实例，其可强化数值效果+1；同实例最多叠2层，离场清零。角色机制不影响公共卡池权限。
7. 不使用相邻、同排、角落、象限等配对格位条件，也不使用行动条数值窗口当奖励收益条件；记忆位置本身仍是核心玩法。
8. 保留现有4×4桌面、同名匹配、异名共鸣基础30%规则、行动条、死亡即停、12张学者起始牌配方及Run级软扩容。**本版数值和10张消耗密度为待试玩平衡基准**。

## 2. 卡牌类型与[消耗]完整语义

| 类别 | 行为 |
|---|---|
| 攻击 | 直接攻击段、附伤、状态施加、状态引爆，可带[消耗] |
| 技能 | 格挡、护甲、治疗、力量、增伤、流血、附伤等，可带[消耗] |
| 诅咒／病毒 | 保持特殊负面牌处理，不归入正常奖励牌 |
| 能力 | **取消**；原翻开即触发并持续生效的能力牌取消 |

- 正常奖励卡配对时，两个参与配对的战斗实例各自结算写明“每张”的效果；“整对”只执行一次。同名配对和合法异名共鸣成功均遵循这套规则。成功配对的两张牌按各自词条分别去向。
- **[消耗]**：当该牌**成功参与配对且其结算正常完成并离场时**，送入消耗堆，本场无法重抽／洗回；若因未配对的普通弃置、主动重铺等离场则按普通弃牌处理，保留循环机会。未配对不会提前消耗。该语义**有意覆盖**旧02“任何进入弃牌堆时都改为消耗”的规则，是未来实施需迁移的差异。
- 一对两个战斗实例均具[消耗]时各自进消耗堆；配对时若触发死亡即停，未完成的效果不补结算。消耗只影响本场战斗复制的实例，不删除局外牌库。
- [顽固]阻止离场、[隐秘]背面弃置效果、[移除]优先级及异名共鸣混合配对的去向，需要在实施时做专项验证；本轮先以**成功配对正常完成且真实离场**作为[消耗]生效必要条件。
- 转换后的长夜编目、校对、连环索引、学术直觉、应急护符、磨砺必须配对才能生效；力量等已获得的持久状态或“下一组配对”增益在卡牌消耗后按其自身持续期继续有效。

## 3. 力量、直接攻击、附加伤害与流血

| 机制 | 新规则 |
|---|---|
| 力量（新增） | 自身叠加，默认本场持续。每一段直接攻击和每个独立附伤包基础伤害+力量层数；不加成灼烧或中毒的定时结算 |
| 多段攻击 | 写作2×3＝每张2段，每段基础3伤；两个实例成功配对通常共4次直接攻击。每段独立受力量、易伤、格挡、护甲 |
| 附加伤害 | 独立伤害事件，**受力量**；不再算一次直接攻击命中，不会再次触发流血、追击、施毒或自身同类附伤，禁止递归 |
| 流血（新增） | 持有者每受到一段**有效直接攻击**，在该段结算后按当前流血层数造成**一包附伤**，然后流血-1；流血附伤受力量、易伤 |
| 有效命中 | 直接攻击段在格挡／护甲扣减前修正后伤害大于0；即便被护甲抵尽，仍触发命中附带效果；段伤害为0则不触发 |
| 状态引爆 | 消耗指定状态层数，将“层数×系数”的伤害**合并为一包附伤**，力量只加一次，不可拆包刷力量；0层不产生伤害包 |
| 易伤/虚弱 | 沿用既有规则：易伤放大受到的伤害（含附伤和定时状态伤），虚弱只影响敌方攻击，百分比修饰一次向下取整 |
| 结算序 | 卡牌基础段值＋学者来源强化＋力量＋其他固定加法 → 百分比效果 → 格挡 → 护甲 → HP；死亡立即停止后续段与触发 |

- 例如4层流血连续受到3段有效攻击，触发4、3、2的**三包附伤**，基础合计9；若力量2且无其他修饰，每包额外+2，流血附伤合计15。
- 冰冻可能抑制灼烧的行动条变化、延迟中毒的敌人行动触发，这种流派取舍保留。
- **整对引爆一次**、**命中附伤每有效直接攻击段一次**，必须严格区分，以免多段乘法重复结算。

## 4. 学者职业被动「融会贯通」

> 每次**真正手动翻开**一个战斗卡牌实例，该实例可强化的有益固定数值效果**+1**，累计最多**2层**；本次翻牌即时生效，**任何原因离开桌面后清零**。不因顺序入场预览、查看详情、仅UI展示或自动翻开而强化。再次手动翻开同一实例可累加，两个同名实例分开记数。

| 被动可强化 | 不强化 |
|---|---|
| 每段直接攻击的伤害基数；每次有卡牌来源的固定附伤基数；格挡、护甲、治疗；施加力量／流血／中毒／灼烧／冰冻等层数；固定护甲削减值 | **攻击段数**、触发次数／周期限制、概率、百分比倍率、状态持续回数（易伤／虚弱）、条件门槛、固定代价（支付格挡／生命／状态）、动态的状态层数转换系数 |

- 标明“整对一次”的固定数值，按照配对两个来源实例的强化层数**取最大值后强化一次**，不将两张卡的强化层数相加。
- 例如两张磨砺都首次手动翻开，基础整对+1力量，双方强化+1，最终整对获得**2力量**，完成配对后两张消耗。
- 2×3的攻击牌实例第一次手动翻开后为2×4；若自身已有力量2，则该实例每段最终基础6，不额外加攻击次数。
- 状态引爆的“每消耗1层造成3伤”属于公式系数，**不会变成每层4**；若这一引爆形成固定基础附伤，可以只对该独立附伤包按来源规则加固定值，不修改系数。

## 5. 状态体系（8种）

| 状态 | 结算方式 |
|---|---|
| 力量（新增） | 自身叠加、默认本场持续；每段直接攻击与每个独立附伤包+1／层 |
| 流血（新增） | 每次有效直接攻击后按现有层数造成一包附伤，然后层数-1；附伤受力量和易伤，不递归 |
| 灼烧 | 原规则：行动条实际变化后造成层数×2伤，再减1层 |
| 中毒 | 原规则：敌人行动后造成层数×1伤，层数不衰减 |
| 冰冻 | 原规则：消耗层数抵消行动条增长，可能阻止灼烧此次触发 |
| 护甲 | 原规则：受击时在格挡后抵消伤害，池可累加 |
| 易伤 | 原规则：目标受伤×1.5，按原回合持续和取整 |
| 虚弱 | 原规则：敌人攻击伤害×0.75，按原回合持续和取整 |

## 9. V5.1 机制增补：移位、蓄步与翻开前移动收益（2026-11-12；无限蓄步修订）

> **状态：策划提案，尚未进入50张奖励牌正式表，未改 Unity。** 本节是在旧50牌 V5 正本之外增补通用效果原语。**用户最新裁决：蓄步累计不设上限；位移造成的持续追踪和记忆成本就是获得更高收益的核心代价。** 无需恢复以前的“相邻配对增伤”条件。任何职业均可使用相关卡牌效果。

### 9.1 [移位]：一格移动或交换

- **目标**：通过卡牌效果选择一张桌面上合法的**背面牌**及其**上、下、左、右**相邻格；不允许斜向、越界或选择封锁、正面等不合法牌。选择基于**格子**而不是读取背面牌名，移动前后不偷偷揭示牌面。
- **空目标格**：源卡移动到空目标格，源格变空；源实例记录一次实际移位。
- **目标格已有可移动背面牌**：双方立即交换，**每个实际改变位置的实例各记录一次移位**；不是只有主动选择的源卡得到记录。
- **一次移动结算**：所有移动/交换位置在同一原子步骤完成，再发位置变化事件、播放可追踪动画；每个实际参与交换的实例每次最多记录1次，不按跨过的坐标距离计数。失败、无可用目标、不发生位置变化则不计。
- **限制**：不提供可无限点击的“免费移动”主动操作。由配对后的技能效果、职业能力（如未来设计）或其他明确机制产生，结算已包含在原翻牌/配对消耗的行动成本内；移位本身不额外推进敌方行动条。
- **时机**：建议在配对的两张牌完成效果并离开决策面后、补牌检查前完成移位选择与结算；仅能移动当时仍在桌面上的合法背面牌，无法再选择刚刚配对离场的实例。若后续同时存在其它牌区转换事件，先确定有效移位目标再提交位置变化。
- **玩家与敌人的移动完全等价（已确认，不是可选项）**：无论位移来自玩家配对技能、未来职业效果，还是**敌人的换位、混乱、局部循环置换、洗牌等位置干扰**，只要背面玩家卡实例实际改变了所在格位，就为该实例增加**1次蓄步**。敌人造成的位移既不会清空蓄步，也不会让移位收益失效；反而可以被玩家记住并用于构筑。移动来源不决定奖励，**实际发生位移**才决定奖励。
- **敌人多牌置换的计数**：一次原子换位/洗牌事件里，每个实例按事件前后格位是否变化计0或1，移动距离不决定次数；同时交换的双方各+1，涉及3张牌的循环换位则三张各+1。若敌人连续执行两个独立、合法的位置变化事件，同一实例可分别累计两次；UI动画的中间帧不是额外移动事件。位置未变、被封锁/无效操作、仅播放动画都不计数。**敌方不必遵守玩家[移位]词条的正交相邻限制**，仍按该敌人已有位置被动定义的合法目标与范围执行；但移动后的蓄步判定口径相同。
- **记忆公平性**：保持统一卡背与完整移动轨迹展示；玩家能依靠记忆追踪换位后的真实位置，不允许在背面显示只对某一牌名生效的秘密数值角标，以免泄露身份。预览期间不可执行移位。

### 9.2 [蓄步]：下一次真实翻开前的移动计数

- 每个**战斗牌实例**独立维护一个非负的“蓄步次数”，**不设层数上限，也不设收益硬上限**。卡牌处于背面期间，每发生一次真正改变该实例桌面位置的有效移动就+1，**玩家效果和敌人效果一律累计**，包括作为交换另一方而被移动。连续移动5次就是5层，不截断为2层；记住它每一次换位后的真实位置是玩家需要承担的认知挑战。
- **下一次真实逻辑翻开**前读取计数，先兑现该卡实际描述的蓄步收益，再清空计数。这里的“翻开”不包括顺序入场预览、只读查看或动画展示；无蓄步奖励的牌即便累积过计数，也不会凭空得到全局增伤。
- 同名的两个实例分别记数；离场、消耗、主动重铺等离开桌面的行为清除未使用的蓄步计数；若卡牌已在正面，不增加“翻开前”的蓄步计数。
- **蓄步收益由具体卡牌决定**，可以是每次移动为下一次配对的**直接攻击各段+1**、翻开时获得护甲、施加状态等，随有效位移次数线性成长且**不人为封顶**。明确与现有学者职业被动独立：学者真实手动翻开时自身仍至多获得2层+1强化；**这是学者被动的上限，不是蓄步上限**。“每移动一次+1”的倍率系数是事件公式，不因学者被动变为“每移动一次+2”，但该卡独立的基础伤害/格挡/状态固定数值可照常受学者强化。
- **不递归、不免费刷位移**：移位不触发翻牌、配对或伤害；蓄步效果不得无条件自动产生新移位，进而组成无限自触发循环；不能新增没有翻牌代价、可反复手动操作的免费移动按钮。**只限制移动的合法来源、次数和资源机会，不限制已经合法累积的蓄步收益**。伤害按V5直接攻击/附加伤害口径结算。
- **本条只是通用词条机制**，不意味着50张现有卡自动带蓄步，也不要求所有卡背向玩家展示蓄步计数。

### 9.3 候选卡牌（**不计入现有50张；未来替换卡位后再改清单**）

| 提案卡名 | 类型/建议稀有度 | 效果 | 定位 |
|---|---|---|---|
| **挪页** | 技能/普通 | 每张配对获得4格挡；整对结算后选择一张合法背面牌向正交相邻格移位一次，目标有可移动背面牌则交换 | 稳定的移动来源 |
| **游刃** | 攻击/罕见 | 每张基础攻击2×2；本实例下一次真实翻开之前每经历1次有效移位，下一次配对时该实例**每段直接攻击基础伤害+1**（次数不设上限） | 与力量、多段攻击协同 |
| **藏锋** | 技能/普通 | 每张配对获得4格挡；本实例下一次真实翻开前每经历1次有效移位，在翻开时获得**1护甲**（次数不设上限），之后计数归零 | 移位防御，兼顾探索 |

**重要的收益锁定**：游刃的蓄步记录**不区分敌我来源**；例如玩家效果移动2次、敌人换位3次，总计蓄步5次。游刃在翻开时将已经累积的**全部蓄步次数（不截断）**转换为“本次待配对的单实例临时增伤”，即便先翻开、稍后才成功配对，依然可以兑现；这份临时增伤仅用于其下一次成功配对或实例离场时作废，**不会因为重复翻回而再次免费兑现**。若游刃在翻回后再次实际移动，可另积累新一轮蓄步并在下一次翻开时刷新未使用的临时奖励（不叠加旧奖励）。藏锋的防御在翻开当下即时获得。例：游刃移动5次→翻开→该实例配对时每段+5；学者被动可独立提升该牌的固定基础伤害，不放大“每移动一次+1”的系数。

### 9.4 关键边界与验收提示

1. 4×4四方向边界、满桌交换、空格移动、非法目标、封锁目标及敌人位置干扰的原子计数。
2. **敌人导致的有效移动必须计数**：双牌交换双方各+1、敌方三牌循环各+1、敌方多牌洗牌逐实例前后格位对比；连续两个独立移动事件可各+1，但同一事件与动画不能重复累计。
3. **蓄步无上限**（3次、5次、10次都准确保留）、下一次真实翻开兑现并清零、翻回重新蓄步、离场清零、入场预览不消耗；不得将学者被动的2层上限误用到蓄步。
4. 学者被动与蓄步收益、力量、攻击段数的增益顺序正确，移动奖励不是所有卡牌的全局+1。
5. 不显示背面牌名或按卡名区别的蓄步数；移动过程可视觉追踪；UI选格不额外形成一次可免费刷的行动。

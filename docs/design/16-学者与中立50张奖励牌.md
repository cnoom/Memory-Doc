## 卡面与结算口径

- 表中伤害默认指对敌伤害，格挡、护甲和治疗默认作用于玩家。配对效果写的是单张数值，同名配对时两张各自结算。「整对一次」的加成整对只结算一份。「全场」「每周期」的同名次数限制由所有同名实例共享。
- 「首翻」指一个战斗实例本场第一次被玩家翻开，洗回后仍保留记录。「回访」指玩家手动翻开一张曾在当前格翻开又翻回的牌。回访的格位记录在牌离场或换格时清除，全场限次的触发记录保留。「本次在场未翻回」从该实例最近一次进入该格起算。
- 一个周期从开局或上一次敌人行动结束开始。配对条件读取本次配对开始时的状态。所有配对条件使用本次配对开始时的同一份共享快照；不得以卡牌几何位置或行动条距离作为奖励触发门槛。
- 记录上一组配对时，以该周期最近一组已完成的配对为准。「同名对的牌名种数」只计该周期已经完成的同名配对，并按牌名去重。卡牌型伤害遵守战斗的死亡即停规则。
- 能力牌由玩家翻开后激活，立即离场，不参与配对。同名能力多份共享一份效果，生效前的触发机会不补发。「整对结算后」的附加效果在两张牌的基础效果之后、行动条常规 +1 之前处理。命中条件与限次计数从相应效果生效时起算，写明「本场首次配对」的牌直接检查全场首对。
- 所有奖励牌均使用统一卡背，没有自动翻牌。位置是玩家记忆内容，不参与奖励的相邻/同行/四角/象限判定。笔记与读书笔记保有既定共鸣规则，本池采用 0 种额外共鸣牌。
- **角色共享机制**：首翻、回访、配对、上一组配对种类与名称、周期内配对次数、状态联动、牌库操作都由通用战斗规则提供，任何角色将来均可使用。学者专属只是**卡池投放归属与主题构筑**，不是机制权限；未来角色开放时须依据角色筛选专属池，同时保留中立池。当前狂战士与术士仍为锁定占位。
- 本修订仅改动 9 张的规则（含「四角索引」更名「连环索引」），「息笔」原本是格挡状态判断，保持不变。全部新规则进入 PR #15 Draft；Unity 测试完成前不视为实装验收通过。

## 投放与试玩顺序

1. **先验证三套小池。** 速读＋考据＋封卷检查探索、回访、出手时机。近注＋书脊＋页角检查配对顺序是否改变选择。旁注＋续写＋承接检查顺序是否带来值得记的组合。每次同敌人、同种子，只换一份奖励牌做对照。
2. **中立牌先用直接攻防校准。** 重击和铁卫是低门槛对照组。普通学者牌如果只有在很罕见的桌面条件下才赶上它们，就提高该牌的触发收益或放宽条件。状态牌放进长短战各一组，分别看首对价值、长期叠层，以及火和毒各有两种独立来源后，炉火守卫和苦药是否更值得提前拿。
3. **记录同名副本的收益。** 每种奖励记录首次拿取、再次拿同名、跳过，以及配对机会与触发收益。顺序牌额外记录已知多组牌对时，玩家是否主动调整配对先后。初期避免把所有 50 种一次性投入测试，以免卡种过多掩盖玩法差异。
4. **优先看三个可能改变节奏的点。** 插叙和寒铁的冰冻控制是否让同一周期拖太久，破绽打击是否放大过多灼烧或爆发，以及急救包是否诱导玩家拖延已经能结束的战斗。

规则依据见 [隐藏牌面、概率共鸣与学者首批设计 PR](https://github.com/cnoom/Memory-Doc/pull/2)。

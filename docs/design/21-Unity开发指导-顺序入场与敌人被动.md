## 执行顺序与任务

### T0 · 建立基线

定位真实手翻和自动翻牌入口、匹配完成点、行动条写入和有效阈值、意图结束、HP/阶段、补牌与重铺、格位映射、战斗 RNG、保存恢复和战斗 HUD。记录代码路径、现行测试、16 敌 ID 与旧意图。用相同种子和牌库保存旧版对照。后续先完成 T1 和 T2 的独立验证，再通过 T3 串联，最后进入 T4 投放。

### T1 · 批次预览

从实际新增实例收集本链新玩家牌，在稳定点按最终格位行优先排序。开局、常规补牌、重铺、其他玩家侧新增纳入；敌方直接产生的病毒/复制体排除。第 i 张在 (i−1)×0.25 秒亮正面，持续 1 秒，各自归背。16 张 4.75 秒，4 张 1.75 秒，空队列直接结束。合并同链多次新增，排除已离桌实例；旧正面牌保留。重铺沿用行动条 +2。

视图覆层与逻辑正背分离，禁止调用翻牌、词条、匹配、首次/回访、记忆记录和行动条写入口。共用桌面输入锁覆盖结算、位移、预览；允许只读和跳过。跳过、场景销毁和战斗结束统一清理临时视图及延迟回调；仅在仍处于有效战斗时恢复交互。明确暂停/恢复与存档边界，重载不能重新抽取或展示一批不同情报。

### T2 · 被动事件与效果

复用现行结算入口采集事件。配置按触发源、条件/阈值、效果序列和周期/整场/每 N 次等限制拆分；缺省空列表可运行。校验配置及未知枚举，使用 battleId、enemyId、cycleIndex、sourceActionId，匹配另带 pairId，用于去重。把触发计数、已消费资格和随机选择纳入现有持久化/可重放策略。

- 无效翻牌：合法手翻时已有可配正面候选，最终完成判定且未配对才计一次。纯探索、无效点击、自动翻开、重铺、预览、能力牌直接离场、死亡中断和实际概率共鸣失败排除（含复用失败结果的回归检查）。[迅速]只影响原行动条逻辑。
- 成功配对：真实完成的一组计一次，同名、成功共鸣和自动链实际配对都可计。按周期清理相应计数；跨周期每 N 次行动的累计单独保存。
- 行动进度：按含阶段、狂暴、遗物修饰的有效阈值计算 ceil(阈值×比例)，从低于节点跨到不低于时收集，动态降阈值同样检查。降条回跨不得重触发。一次跳满跨多个节点默认只取首个合格进度被动，先于主动意图执行。
- HP 条件：伤害时标记，立即应用既有阶段属性，效果延到安全点；一击跨多阶直达目标阶。终止优先于所有排队事件。重铺/病毒清除等显式事件仅按配置启用。
- 位移：仅使用已完成预览的合格背面玩家牌，排除正面、待预览、病毒和稳定锚免疫对象；以实体 ID 做原子格位映射，标记随实体移动，保留牌对缓存与堆顺序。按 15 清除换格实例的考据位置记录。事件、动画均不触发牌生命周期。目标不足消耗本次资格。
- 污染：默认本次生成 min(配置数量至多 2, 空格, 场上病毒额度)，默认同场最多 3 张。强污染仅取本次成功生成的一张病毒，与另一格合格旧背面玩家牌交换。无生成则跳过交换，无合法旧牌则保留病毒。增生有空位才复制真实战斗牌，单独设上限。冰封、封锁、自身强化沿用合法性与持续期，已有狂暴只挂现有效果一次。

### T3 · 串联结算与 HUD

按 19 §4 在 01 原流程采集：真实翻牌/词条/匹配 → 记录配对或无效翻牌 → 原行动条修饰并收集进度 → 安全点应用待执行被动 → 条满执行主动 → 双方存活才记行动完成并执行行动后被动 → 按原规则更新行动条、意图和周期 → 桌面稳定后预览 → 解锁。伤害时记录的阶段效果在最近安全点参与调度。具体钩子以原结算流程为准，不能为了套流程图移动匹配和补牌的既有判定点。

采用有界延迟队列，在遍历外提交。每条被动默认每周期一次，位置扰动同链最多一次、同敌周期默认最多一次；阶段位置候选与普通位置候选同链冲突时保留阶段优先，未执行者记日志且不补发。验证与 19 的进度先于主动约束共同成立；如实仓出现源文档未定义的冲突，记录复现和待裁决顺序，避免静默改规则。非位置效果受独立限制，阻止被动副作用递归触发自身。每个安全点重新检查存活、当前敌人与格位合法性。

HUD 分开显示主动意图和已启用的被动名称、条件、效果、进度与上限。进度型画刻度，计数型显示 2/3 或 1/2，行动后型说明剩余行动数，生命型显示阈值。预告目标范围/数量，位移画出路径，禁止泄漏隐藏牌名、病毒身份或预掷共鸣。09 满条闪光、攻击期间满格、攻击后熄灭规则继续使用；进度刻度与退役的临界闪红区分。

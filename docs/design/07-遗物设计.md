## 1. 设计说明

### 1.1 遗物定位

遗物是**持久被动效果**，贯穿整个run，是Meta成长的核心载体。原型阶段设计19件遗物（另有1件已暂移待重新设计），覆盖以下设计维度：

| 维度 | 说明 | 对应学者流派 |
|---|---|---|
| **记忆辅助** | 降低记忆难度，提供信息优势 | 情报爆发流 |
| **桌面操控** | 改变翻牌/配对的基础规则 | 全流派通用 |
| **配对强化** | 提升配对收益或改变配对行为 | 配对循环流 |
| **防御续航** | 提升生存能力 | 全流派通用 |
| **行动条操控** | 影响敌人节奏 | 全流派通用 |
| **牌库操控** | 影响牌库构成或战斗内牌区（抽牌堆/弃牌堆等）流转 | 知识转化流 |

### 1.2 稀有度与获取

| 稀有度 | 数量 | 获取途径 |
|---|---|---|
| **普通** | 7件 | 普通战斗掉落、商店、事件 |
| **罕见** | 5件 | 精英战斗掉落、商店、事件 |
| **稀有** | 4件 | 精英战斗低概率掉落、商店高价 |
| **Boss** | 3件 | Boss击杀后必掉（三选一） |

Boss遗物为**最强遗物**，通常带有显著代价或改变玩法的强力效果，类似杀戮尖塔的Boss遗物。

### 1.3 设计约束

- 遗物不能"抹除记忆"（遵循[设计原则](./00-项目总览.md#2-设计原则)），只能改变桌面物理状态或提供系统层信息。
- 遗物效果需与学者卡牌、敌人能力形成有意义的交互。
- 数值平衡对齐学者基准（60血，配对6~10伤害，格挡每回合清零）。

## 2. 普通遗物（7件）

普通遗物提供基础增益，出现概率最高。全部为纯被动效果。

### 记忆辅助类

```
═══════════════════════════════════════════════════════
  记忆水晶                              [普通]
  ─────────────────────────────────────────────────────
  效果: 每场战斗开始时，桌面所有牌短暂可见 2 秒
  
  设计意图: 最基础的情报遗物。开局2秒一览全局，
           让玩家在战斗开始就建立初步记忆。
           与学者的构筑型被动「触类旁通」互补——被动强化
           跨名匹配，此遗物强化开局记忆。
           对混乱史莱姆/记忆窃贼的换位有缓冲作用。
═══════════════════════════════════════════════════════

  笔记本                                 [普通]
  ─────────────────────────────────────────────────────
  效果: 每场战斗开始时，自动标记桌面 2 张牌
       （标记：牌面内容对玩家持续可见，直至其移出桌面）
  
  设计意图: 持久情报遗物。与"记忆水晶"的区别——
           记忆水晶是短暂全揭示（考验记忆），
           笔记本是持久部分揭示（稳定信息）。
           适合不擅长快速记忆的玩家。
═══════════════════════════════════════════════════════
```

### 配对强化类

```
═══════════════════════════════════════════════════════
  共鸣石                                 [普通]
  ─────────────────────────────────────────────────────
  效果: 每场战斗前 3 次成功配对，额外造成 +2 伤害
  
  设计意图: 早期配对加速遗物。帮助快速削减普通敌人血量，
           缩短战斗。前3次配对约多6伤害，等于省一次配对。
═══════════════════════════════════════════════════════

  双生骰                                 [普通]
  ─────────────────────────────────────────────────────
  效果: 每次配对成功时，30% 概率揭示桌面 1 张背面牌
  
  设计意图: 配对附带情报。每次配对都有概率窥探一张牌，
           叠加情报优势。随机性带来意外惊喜。
═══════════════════════════════════════════════════════
```

### 防御续航类

```
═══════════════════════════════════════════════════════
  急救包                                 [普通]
  ─────────────────────────────────────────────────────
  效果: 每场战斗开始时，回复 5 点血量
  
  设计意图: 基础续航遗物。每场战斗多5血缓冲，
           降低连续战斗的血量压力。
           对蛮族战士/双刃执行者的高伤害有缓解作用。
═══════════════════════════════════════════════════════

  木盾                                   [普通]
  ─────────────────────────────────────────────────────
  效果: 每回合第一次受到伤害时，抵消 3 点
  
  设计意图: 固定减伤遗物。每回合固定抵消3点，
           对哥林布(8伤→5伤)和训练假人(6伤→3伤)效果显著。
           对双刃执行者连击(20伤)效果有限。
═══════════════════════════════════════════════════════
```

### 行动条操控类

```
═══════════════════════════════════════════════════════
  减速印记                               [普通]
  ─────────────────────────────────────────────────────
  效果: 敌人行动所需的行动条阈值 +1
  
  设计意图: 被动型行动条操控。直接提高敌人行动门槛，
           每回合等效多翻1张牌。
           对低阈值敌人（蛮族战士阈值7→8）效果最好。
           对高阈值敌人（双刃执行者12→13）也有延迟作用。
═══════════════════════════════════════════════════════
```

## 3. 罕见遗物（5件）

罕见遗物提供组合型效果，改变战斗节奏。全部为纯被动效果。

### 记忆辅助类

```
═══════════════════════════════════════════════════════
  思维导图                               [罕见]
  ─────────────────────────────────────────────────────
  效果: 翻过的牌位置在桌面上保留淡淡的轮廓标记
       （仅显示"这里翻过"，不显示内容）
  
  设计意图: 位置记忆辅助。帮你记住哪些位置翻过，
           降低位置记忆负担，但内容仍需自己记。
           对混乱史莱姆/记忆窃贼的换位有追踪作用——
           可以看到牌被移走了（轮廓还在原位）。
═══════════════════════════════════════════════════════
```

### 桌面操控类

> 「永恒之烛」已暂移（2026-08-27）：与正面牌超限挤掉规则冲突，待重新设计。

### 配对强化类

```
═══════════════════════════════════════════════════════
  连锁核心                               [罕见]
  ─────────────────────────────────────────────────────
  效果: 配对成功时，桌面随机 1 张背面牌被揭示
  
  设计意图: 被动情报+配对联动。每次配对都附带情报收益，
           叠加学者情报流。与"双生骰"区别——连锁核心是
           纯揭示（不触发效果，不推进行动条），更安全。
═══════════════════════════════════════════════════════

  蓄能水晶                               [罕见]
  ─────────────────────────────────────────────────────
  效果: 每连续成功配对 3 次（无失败配对），
       下一次配对额外 +5 伤害
  
  设计意图: 连击奖励。鼓励精准记忆配对，
           失败配对会中断连击。高手的伤害放大器。
           对学者情报流极契合——情报越准连击越长。
═══════════════════════════════════════════════════════
```

### 防御续航类

```
═══════════════════════════════════════════════════════
  吸血鬼之牙                             [罕见]
  ─────────────────────────────────────────────────────
  效果: 每三次配对消除时，回复 1 点血量
  
  设计意图: 配对续航。每三次配对回1血，
           一场战斗配对10次≈回3血。
           鼓励高频配对打法，配对越多越肉。
           
  交互注意: 配对消除才回血，翻开未配对不回。
           "失败配对"（翻开两张不同牌）不回血。
═══════════════════════════════════════════════════════

  能量护盾                               [罕见]
  ─────────────────────────────────────────────────────
  效果: 每回合结束时，若你的格挡 ≥ 5，额外保留 3 点格挡
       至下回合（超过5的部分仍清零）
  
  设计意图: 格挡留存遗物。鼓励堆格挡——
           如果每回合配出5+格挡，下回合保留3点。
           改变"格挡每回合清零"的规则，奖励防御型打法。
═══════════════════════════════════════════════════════
```

## 4. 稀有遗物（4件）

稀有遗物提供改变玩法的强力效果。全部为纯被动效果。

```
═══════════════════════════════════════════════════════
  稳定锚                                 [稀有]
  ─────────────────────────────────────────────────────
  效果: 敌人的换位/混乱/洗牌能力对你无效
       （桌面牌位置不会被敌人移动）
  
  设计意图: 完全免疫位置干扰。对混乱史莱姆、记忆窃贼、
           记忆吞噬者（全阶段都有混乱）是克制遗物。
           拿到后这些敌人的核心威胁被消除。
           但不免疫封锁/污染。
═══════════════════════════════════════════════════════

  双生符                                 [稀有]
  ─────────────────────────────────────────────────────
  效果: 同名匹配成功时，额外触发 1 次其中一张牌的基础效果
       （每回合限 1 次）
  
  设计意图: 配对效果翻倍。同名匹配后，多触发一次基础效果。
           对笔记(6伤害)意味着配对=12伤害+6伤害=18伤害。
           注意：仅"同名匹配"触发，匹配型词条配对不触发。
═══════════════════════════════════════════════════════

  镜像回声                               [稀有]
  ─────────────────────────────────────────────────────
  效果: 每次配对成功时，25% 概率将配对的两张牌中的
       一张复制一份放回桌面（背面朝上）
  
  设计意图: 桌面循环遗物。配对的牌有概率循环回桌面，
           等效于"免费"多一次配对机会。
           对高价值牌（真理之眼、图书馆）极强。
           
  交互注意: 复制品是背面朝上新牌，玩家不知道其位置。
           需重新记忆。
═══════════════════════════════════════════════════════

  学者徽章                               [稀有]
  ─────────────────────────────────────────────────────
  效果: 你的"揭示"和"标记"效果数量 +1
       （如"揭示2张"变为"揭示3张"，"标记1张"变为"标记2张"）
  
  设计意图: 学者专属强化遗物。放大所有情报效果。
           与学者的卡牌体系（读书笔记、批注、目录等）
           形成乘法效应。对其他角色价值较低。
═══════════════════════════════════════════════════════
```

## 5. Boss遗物（3件）

Boss击杀后必掉，三选一。强力效果，部分带代价。

```
═══════════════════════════════════════════════════════
  全知之眼                               [Boss]
  ─────────────────────────────────────────────────────
  效果: 场上可同时翻开的牌数量 +1（从1变为2）
  
  代价: 无
  
  设计意图: 放宽核心约束。允许玩家同时保持2张正面牌，
           便于比较和规划配对。温和的桌面操控遗物，
           提升配对效率但不消除记忆挑战。
═══════════════════════════════════════════════════════

  混沌核心                               [Boss]
  ─────────────────────────────────────────────────────
  效果: 每回合开始时，随机将桌面 2 张牌互换位置，
       然后揭示互换后的 2 张牌内容（持续可见）
  
  代价: 无
  
  设计意图: 以毒攻毒型Boss遗物。每回合强制换位，
           但告诉你换了哪两张。制造动态记忆挑战，
           同时提供部分情报。适合喜欢挑战的玩家。
           
  设计哲学: 不是所有Boss遗物都是纯增强。
           这件遗物改变记忆玩法——记忆不再是静态的，
           而是每回合动态更新。
═══════════════════════════════════════════════════════

  记忆王冠                               [Boss]
  ─────────────────────────────────────────────────────
  效果: 你的所有能力牌的持续效果翻倍
       （如"+1伤害"变为"+2伤害"，"每翻牌获1专注"变为"获2专注"）
  
  代价: 无
  
  设计意图: 能力牌强化Boss遗物。让能力牌的持续效果翻倍。
           对学者（有多张能力牌）极强。
           全神贯注的专注积蓄翻倍、博闻强识增伤翻倍等。
           
  设计哲学: 鼓励玩家围绕能力牌构筑。
           拿到后改变deckbuilding优先级——
           能力牌的价值大幅提升。
═══════════════════════════════════════════════════════
```

## 6. 总览

### 遗物按稀有度

| 稀有度 | 数量 | 遗物 |
|---|---|---|
| 普通 | 7 | 记忆水晶、笔记本、共鸣石、双生骰、急救包、木盾、减速印记 |
| 罕见 | 5 | 思维导图、连锁核心、蓄能水晶、吸血鬼之牙、能量护盾 |
| 稀有 | 4 | 稳定锚、双生符、镜像回声、学者徽章 |
| Boss | 3 | 全知之眼、混沌核心、记忆王冠 |

> 遗物总数：19件（全部为纯被动效果；「永恒之烛」已暂移待重设计，见 §3，不计入）

### 按功能维度

| 维度 | 遗物 |
|---|---|
| **记忆辅助** | 记忆水晶、笔记本、思维导图、学者徽章 |
| **桌面操控** | 稳定锚 |
| **配对强化** | 共鸣石、双生骰、连锁核心、蓄能水晶、双生符、镜像回声 |
| **防御续航** | 急救包、木盾、吸血鬼之牙、能量护盾 |
| **行动条操控** | 减速印记 |
| **能力牌强化** | 记忆王冠 |
| **全局改变** | 全知之眼、混沌核心 |

### 与敌人设计的交互矩阵

| 敌人 | 克制遗物 | 说明 |
|---|---|---|
| 混乱史莱姆 | 稳定锚、思维导图 | 免疫换位 / 追踪换位 |
| 蛮族战士 | 减速印记、木盾 | 阈值+1 / 减伤 |
| 腐化花蕾 | — | 病毒牌只能承受代价清除或重新铺满 |
| 幻影 | — | 封锁需灵活配对 |
| 双刃执行者 | 能量护盾、木盾 | 格挡留存 / 减伤 |
| 记忆窃贼 | 稳定锚 | 免疫换位 |
| 记忆吞噬者 | 稳定锚 | 阶段全抗换位 |

### 原型测试建议

原型阶段建议优先测试以下内容，验证各维度机制：

| 优先级 | 遗物 | 验证目标 |
|---|---|---|
| P0 | 记忆水晶 | 基础情报机制是否运作 |
| P0 | 共鸣石 | 配对增伤是否平衡 |
| P0 | 急救包 | 续航机制是否运作 |
| P0 | 减速印记 | 阈值操控是否运作 |
| P1 | 稳定锚 | 敌人能力免疫是否平衡 |
| P1 | 吸血鬼之牙 | 配对续航是否过强 |
| P2 | 全知之眼 | 翻开牌数量+1是否破坏核心体验 |
| P2 | 记忆王冠 | 能力牌翻倍是否过强 |

## 1. 设计说明

### 1.1 原型阶段目标

本批敌人用于**验证核心战斗循环**，需要覆盖以下测试维度：

| 测试维度 | 对应敌人 | 验证内容 |
|---|---|---|
| 基础战斗节奏 | 训练假人、哥林布 | 翻牌→配对→伤害→行动条→敌人攻击的完整循环 |
| 记忆压力 | 混乱史莱姆、幻影 | 敌人换位/洗牌对记忆策略的影响 |
| 桌面污染 | 腐化花蕾 | 病毒牌塞入后的处理决策 |
| 节奏施压 | 蛮族战士、双刃执行者 | 低阈值/连击带来的高压生存 |
| 能力交互 | 全部 | 状态效果（易伤/虚弱/护甲）的施加与利用 |
| 多阶段Boss | 记忆吞噬者 | 阶段切换、能力叠加、桌面规则改变 |

### 1.2 平衡基准（对齐学者卡牌）

**学者玩家：** 60 HP，配对约 6~10 伤害/次，桌面16张牌（4×4网格）。

**战斗时长目标：**

| 敌人类型 | 血量 | 预计配对次数 | 预计回合数 | 预计战斗时长 |
|---|---|---|---|---|
| 普通敌人 | 30~50 | 4~7次 | 3~5回合 | 2~3分钟 |
| 精英 | 70~100 | 8~12次 | 5~7回合 | 4~6分钟 |
| Boss | 150~200 | 15~25次 | 8~12回合 | 8~12分钟 |

### 1.3 意图模式标注说明

每个敌人描述中的"意图模式"使用简写：

| 简写 | 含义 |
|---|---|
| `攻击(N)` | 造成N点伤害 |
| `蓄力` | 本回合不攻击，下回合攻击翻倍 |
| `防御(N)` | 获得N点护甲 |
| `特殊(能力名)` | 触发该能力的特殊效果 |
| `狂暴` | 行动条阈值降低 |

意图按行动条重置时**循环刷新**。如 `攻击(8) → 蓄力` 表示第一次行动攻击8点，第二次蓄力，第三次又攻击8点，循环。

## 3. 精英敌人（2种）

精英敌人比普通敌人更强，出现在地图的精英节点，必掉遗物。

### 3.1 双刃执行者（连击高压型）

```
═══════════════════════════════════════════════════════
  双刃执行者
  ─────────────────────────────────────────────────────
  血量: 85
  行动条阈值: 12
  攻击伤害: 10
  
  能力: [连击]——行动条满时连续攻击2次
        [重击]——单次攻击伤害高(10)，但阈值也高(12)
  
  意图模式: 蓄力 → 攻击(10×2连击) → 攻击(10×2连击)
  
  设计意图: 高伤害精英。蓄力一回合后，连续两次10点攻击
           = 20点伤害（学者1/3血量）。
           阈值12给玩家较多翻牌时间做准备，但一旦行动
           代价极大。测试玩家的防御规划能力。
           
  应对策略: 蓄力回合必须配出足够格挡（≥20）。
           笔记本格挡(6)×2配对=12，速读(4)×2=8，
           加上全神贯注持续格挡，需要精心规划。
           破绽分析的[易伤]可加速击杀减少受击次数。
═══════════════════════════════════════════════════════
```

### 3.2 记忆窃贼（复合干扰型）

```
═══════════════════════════════════════════════════════
  记忆窃贼
  ─────────────────────────────────────────────────────
  血量: 75
  行动条阈值: 10
  攻击伤害: 8
  
  能力: [换位]——行动时将网格第1列和第4列的牌整体互换
        [污染]——每两次行动塞入1张病毒牌
  
  意图模式: 攻击(8) → 特殊(换位) → 攻击(8) → 特殊(污染)
  
  设计意图: 复合干扰精英。换位打乱位置记忆，
           污染塞入病毒牌，双重桌面干扰。
           血量较低(75)作为补偿——它不强在数值，强在烦人。
           测试玩家在多重干扰下的记忆管理能力。
           
  应对策略: 学者的情报能力在这里价值极高——
           揭示/标记可以抵消换位的影响（知道内容就不怕换位）。
           速记的[锁定]可以保护关键正面牌不被换位影响。
           这是"情报流"学者的优势对局。
═══════════════════════════════════════════════════════
```

## 4. Boss（1种）

### 4.1 记忆吞噬者（第一章Boss）

多阶段Boss，每阶段改变能力和意图模式，测试玩家的全面能力。

```
═══════════════════════════════════════════════════════════════
  记忆吞噬者
  ─────────────────────────────────────────────────────────────

  ▸ 阶段1（100% ~ 60%血量）—— 试探
  ─────────────────────────────────────────────────────────────
  血量区间: 150~200（当前血量 100%~60%）
  行动条阈值: 10
  攻击伤害: 12
  
  能力: [混乱]——每次行动随机交换桌面2张牌位置
  
  意图模式: 攻击(12) → 特殊(混乱) → 攻击(12)
  
  阶段感受: 和混乱史莱姆类似的干扰，但攻击力更高(12)。
           让玩家适应Boss战节奏。60%血量=约90~120血时进阶段2。

  ▸ 阶段2（60% ~ 30%血量）—— 施压
  ─────────────────────────────────────────────────────────────
  行动条阈值: 9（降低，更频繁行动）
  攻击伤害: 14
  
  能力: [混乱] + [封锁]——行动时随机交换2张牌，
        且给1张牌加[封锁]标记
  
  意图模式: 攻击(14) → 特殊(混乱+封锁) → 攻击(14)
  
  阶段感受: 双重干扰。换位+封锁同时发生，桌面变得混乱。
           阈值降至9，攻击升至14，压力陡增。
           玩家需要在此阶段快速削减血量到30%。

  ▸ 阶段3（30% ~ 0%）—— 狂暴
  ─────────────────────────────────────────────────────────────
  行动条阈值: 8（再降）
  攻击伤害: 16
  
  能力: [混乱] + [封锁] + [污染]
        ——三重干扰全开
  
  意图模式: 攻击(16) → 特殊(混乱+封锁+污染) → 攻击(16)
  
  阶段感受: 最终阶段。三重干扰+高伤害+低阈值。
           桌面被不断换位、封锁、塞入病毒牌。
           玩家需要在极度混乱中找到配对机会 finish off。
           30%血量=约45~60血，约需5~8次配对击杀。
═══════════════════════════════════════════════════════════════
```

**Boss战设计意图：**

1. **阶段递进测试全面能力**：阶段1测试基础记忆抗干扰，阶段2测试封锁应对，阶段3测试极限压力下的综合应对。
2. **学者的优势对局**：情报能力（揭示/标记）在混乱中价值极高——知道内容就不怕换位。百科全书（翻牌不翻回）更是能极大降低阶段3的混乱影响。
3. **阶段切换的戏剧感**：每次阶段切换，敌人能力增加、阈值降低、伤害提升，给玩家清晰的"形势恶化"感知。
4. **病毒牌在阶段3才出现**：避免前期过于复杂，让玩家逐步适应。

**Boss战数值校验：**
- 总血量150~200，阶段分布约 60%(90~120) + 30%(45~60) + 10%(15~20)
- 学者平均配对8伤害，需约 20~25 次配对击杀
- 每回合阈值8~10，约翻8~10张牌/回合，配对约2~3次/回合
- 预计 8~12 回合击杀，战斗时长 8~12 分钟

## 5. 病毒牌配套设计

腐化花蕾、记忆窃贼、记忆吞噬者（阶段3）会塞入病毒牌。以下是配套的病毒牌设计：

```
═══════════════════════════════════════════════════════
  腐化种子                              [诅咒]
  ─────────────────────────────────────────────────────
  词条: [翻开]: 受到 3 点伤害；移除自身
  
  来源: 腐化花蕾[污染]、记忆窃贼[污染]、记忆吞噬者阶段3[污染]
  
  设计意图: 标准病毒牌。翻到扣3血但清除。
           3点伤害可控——玩家可选择主动翻它清场。
═══════════════════════════════════════════════════════

  记忆尘埃                                [诅咒]
  ─────────────────────────────────────────────────────
  词条: [翻开]: 行动条 +2；移除自身
  
  来源: 仅记忆窃贼[污染]（特殊变种）
  
  设计意图: 加速型病毒牌。翻到直接推进敌人2点，
           可能导致敌人提前攻击。比扣血更危险——
           时间是学者最宝贵的资源。
═══════════════════════════════════════════════════════

  虚空裂痕                                [诅咒]
  ─────────────────────────────────────────────────────
  词条: [翻开]: 受到 5 点伤害；随机交换桌面2张牌位置；移除自身
  
  来源: 仅记忆吞噬者阶段3[污染]（Boss级病毒牌）
  
  设计意图: 最强病毒牌。扣血+换位双重惩罚。
           Boss阶段3的终极干扰——翻到它既掉血又打乱记忆。
           配合阶段3的[混乱]+[封锁]，桌面会极度混乱。
═══════════════════════════════════════════════════════
```

### 病毒牌总览

| 病毒牌 | 效果 | 来源 | 危险度 |
|---|---|---|---|
| 腐化种子 | 受3伤 | 腐化花蕾、记忆窃贼、Boss | ★★ |
| 记忆尘埃 | 行动条+2 | 记忆窃贼（变种） | ★★★ |
| 虚空裂痕 | 受5伤+换位 | Boss阶段3 | ★★★★ |

## 附录：原型敌人测试矩阵

以下是建议的原型测试顺序，逐步引入机制：

| 测试阶段 | 敌人 | 引入的新机制 | 验证目标 |
|---|---|---|---|
| 1 | 训练假人 | 基础翻牌/配对/行动条 | 核心循环可玩性 |
| 2 | 哥林布 | 数值压力 | 配对效率 |
| 3 | 混乱史莱姆 | 换位干扰 | 记忆抗干扰 |
| 4 | 蛮族战士 | 低阈值压力 | 紧凑决策 |
| 5 | 腐化花蕾 | 病毒牌 | 污染处理决策 |
| 6 | 幻影 | 封锁 | 灵活配对调整 |
| 7 | 双刃执行者 | 连击+蓄力 | 防御规划 |
| 8 | 记忆窃贼 | 复合干扰 | 综合记忆管理 |
| 9 | 记忆吞噬者 | 多阶段Boss | 全面能力检验 |

按此顺序测试，可以逐步验证每个机制是否如设计预期般运作，并在发现问题时快速定位是哪个环节需要调整。

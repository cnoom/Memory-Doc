## 1. 格挡与护甲

| 名词 | V7.2效果 | 伤害或回合结束的处理 |
|---|---|---|
| **格挡** | 当前可抵消的临时伤害值 | 受到伤害时先扣格挡；**敌人回合结束阶段**处理旧格挡保留与清理，下一玩家回合开始新增格挡不被上次清理影响 |
| **护甲** | **每个玩家回合开始时**按当前护甲层数获得等量格挡，每个玩家回合仅一次 | 本身不直接抵消伤害、不被普通攻击扣除；玩家回合内获得护甲不会立刻增加格挡，层数本场持续 |

**结算时序（V7.2双回合正本）**：行动条满→完成玩家当前操作和玩家回合结束触发→敌人回合开始→敌人行动及其全部行动后/回合末效果→**旧格挡先判保留、再清理**→敌人回合结束→**玩家回合开始先触发修改护甲的回合初效果→冻结当前护甲层数并仅一次生成等量格挡→结算其它回合初格挡及上个敌人回合延后发放的格挡→开放玩家操作**。中途增加护甲只会影响下一玩家回合；非攻击敌人回合也按同一回合边界处理，死亡中断不补发。

例如：当前护甲3、旧格挡4，敌人造成6伤害。先耗尽4格挡，再失去2生命；护甲仍为3。敌人回合结束时清理剩余旧格挡（明确保留的例外），**下一玩家回合开始**护甲生成3格挡；若在该次玩家回合开始的护甲发盾节点前由其它效果再获得2护甲，则本次产5格挡，发盾后获得护甲不补发。

**旧规则废止点**：原伤害计算“伤害 → 格挡 → 护甲池 → HP”改为“伤害（含固定数值与百分比修正） → 格挡 → HP”；护甲不在同一次伤害中充当第二层直接吸伤池。护甲获得时不即时生成格挡，除非卡牌另外明确写出“获得X格挡”。

**敌方护甲已裁决（34号正本）**：敌人和玩家均使用持续护甲，分别在**自身回合开始**按护甲层数获得格挡一次；**对手回合结束**清理自身旧格挡。敌人开场尚未开始敌人回合，不因初始护甲自动预发格挡；如需开场盾应显式配置。双方护甲均不直接吸伤。

## 2. 统一关键词词典（所有卡牌详情都需能查看）

**不只有方括号词条能解释**。像“格挡”“护甲”“力量”“流血”“多段攻击”等正文专有词也应当支持点按/聚焦查看。每个词条有稳定语义ID、显示名、简短说明、展开说明、适用上下文；战斗、商店、奖励、牌库和其他详情入口共用同一词典。

### 2.1 战斗资源与状态

| 词语 | 卡牌详情中的解释建议 |
|---|---|
| **格挡** | 抵消受到的伤害。敌人回合结束时未被明确保留的旧格挡清零。 |
| **护甲** | 每个玩家回合开始时，按当时护甲层数获得等量格挡（每玩家回合仅一次）。护甲本身不减伤且不会被普通伤害消耗，本场持续。 |
| **力量** | 每层使每段直接攻击和**卡牌/遗物自身生成的独立附加伤害**+1；**不强化流血状态伤害、中毒定时伤害及其他状态伤害**。 |
| **流血** | 每受到一段有效直接攻击，按当前流血层数受到一包**状态来源伤害**，随后层数-1；**不受任何通用伤害增减益修正**，不会递归触发流血。 |
| **中毒** | 敌人行动条满所引发的敌人回合内按当前层数结算一次状态伤害，不减少中毒层数；**不受任何通用伤害增减益修正**。 |
| **灼烧** | 行动条数值真正变化时按当前灼烧层数受到伤害，随后灼烧-1。 |
| **冰冻** | 抵消下次行动条增长的1点，随后冰冻-1；完全抵消为0时不算行动条数值实际变化。 |
| **易伤** | 受到直接攻击或卡牌/遗物自身生成的独立附加伤害时，该伤害提高50%；**流血和中毒等状态伤害不受易伤影响**。敌人身上的易伤在玩家回合结束时计时，玩家身上的易伤在敌人回合结束时计时；施加当次计时回合不立即衰减。 |
| **虚弱** | 自身直接攻击伤害减少25%，不降低状态伤害或非攻击独立附伤；在自身回合结束时计时，施加当次计时回合不立即衰减。 |
| **生命** | 受到格挡无法抵消的伤害后减少；降到0时按战斗死亡中断规则处理。 |

### 2.2 触发与卡牌语义

| 词语 | 卡牌详情中的解释建议 |
|---|---|
| **[翻开]** | 卡牌真正从背面翻到正面时触发，每次都可触发；预览/详情查看不算。 |
| **[翻回]** | 卡牌真正从正面翻回背面时触发；直接配对离场不算。学者的新版被动在翻回时生效。 |
| **临时** | 当前战斗卡牌实例所拥有的成长，翻回保留、离开棋盘时消失。 |
| **移动** | 玩家先选择合法背面来源牌，再从显示的合法上下左右方向中选一个；空格则移动1格，合法背面牌则交换。非法方向不展示，已取消X37远距离交换特例。 |
| **[移动]** | 卡牌实例位置真实变化时触发；敌我造成的真实位置变化均有效。 |
| **蓄步** | 背面牌每次实际改变位置时累计1次；下一次真正翻开时锁定，用于该卡写明的效果。没有玩法上限。 |
| **多段攻击** | “造成2段3点伤害”＝攻击2段、每段基础3点，分别触发命中等规则。 |
| **附加伤害** | 独立伤害包必须区分**来源**：卡牌/遗物自身产生的包可受到适用加成；流血等**状态来源伤害完全不受通用伤害增减益修正**。附伤包不是直接攻击命中，不递归触发命中附效。 |
| **有效命中** | 修正后的直接攻击段伤害大于0；即使被格挡全部挡住也算有效命中。 |
| **配对** | 仅同名卡成功匹配，双方按同一快照分别结算一次；是默认效果，卡面不加“[配对]”。 |
| **[消耗]** | 成功配对并正常离场后，本场战斗不再洗回该牌。是否继续保留此属性仍待审核，不等于支付状态资源。 |
| **玩家回合** | 战斗开始或上一敌人回合结束后开始；开始时护甲产盾一次，可进行多次翻牌和配对，行动条满后且全部相关效果结算完成才结束。 |
| **敌人回合** | 敌人行动条满、玩家回合结束后开始；敌人行动、状态、被动、遗物与回合末效果全部结算、旧格挡清理完成后才结束。 |
| **每个玩家回合首次** | 在该玩家回合开始重置计数，在本回合内符合条件的第一次事件触发；不会每翻一张牌重置。 |
| **每个敌人回合首次** | 在该敌人回合开始重置计数，在该敌回合内符合条件的第一次事件触发。 |

说明文字可根据最终状态设计细化，**词典必须是卡牌文字、状态提示和战斗效果共同使用的规则来源**，不能某处说明“护甲直接减伤”、另一处说明“护甲回合后产格挡”。

## 3. 可复用卡牌详情组件的展示与交互

1. **唯一复用入口**：战斗中的正面卡、牌库、战后奖励、商店、事件等共用独立的 CardDetailPanel。数据由调用场景传入，不能把UI依赖固定在对局；背面牌不可透露卡名、状态或蓄步收益。
2. **展示层级**：卡名、稀有度、类型；当前可见的卡牌效果及动态数值；[翻开]/[翻回]等触发项；从当前正文自动提取的专有名词解释。只显示本卡涉及的词语，避免在所有卡上堆满整本词典。
3. **可解释入口**：专有词可以点击、触屏轻点或键盘聚焦，展开短解释或详细解释；不单靠颜色，需有文字样式或图标提示可交互。
4. **关闭逻辑**：点击面板非交互区域或面板外任意位置关闭详情；点击关键词/说明展开控件属于查看操作，不立即关闭；事件不得穿透导致棋盘误翻牌。关闭之后需要一次新操作才能翻下一张牌。不再以悬停2秒或鼠标移出作为唯一详情触发/关闭路径，符合用户此前的独立详情UI设想。
5. **长文本**：正文与词汇解释区域可滚动，窄屏不溢出、不覆盖必要关闭信息；词典内容与各语言动态布局独立验证。力量、实例成长、学者和其它加成可分项展示；始终与冻结配对快照一致。

**显示示例：**
- 皮甲（示例值、非最终数值）：普通 · 技能。获得7点格挡和1点护甲。下方出现“格挡”“护甲”的可查看解释。
- 探卷（用户已确认原文）：普通 · 攻击。造成2段2点伤害。[翻开] 临时伤害+1。实例累计翻开2次后显示“造成2段（2+2）点伤害。”下方出现“翻开”“临时”等解释。

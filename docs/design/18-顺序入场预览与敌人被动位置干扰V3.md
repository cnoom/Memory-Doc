# 顺序入场预览与敌人被动位置干扰 V3

> **后续 V4 覆盖声明**：本文件第 2 节「顺序入场预览」继续生效；第 3 节固定手动翻牌次数触发（普通5、精英4等）和第 4 节对应触发建议已由 [19·敌人多触发被动机制 V4](./19-敌人多触发被动机制V4.md) 取代。位置移动动画、视觉与逻辑隔离及公平性原则仍为有效约束。

> **设计日期**：2026-11-09  
> **状态**：正式设计规则，待 Unity 实现与数值验收。  
> **适用范围**：覆盖 01《核心战斗机制》中的卡牌入场可见性；覆盖 15《战斗信息与学者卡牌重设计》关于“所有新牌必须直接以卡背入场、完全禁止短暂展示”的旧基线；覆盖 04/08 敌人“混乱、换位、洗牌由敌人主动意图发动”的旧设定。  
> **保持不变**：4×4、每库内牌×2、同名必配/异名概率共鸣、翻牌行动条、牌区、状态与死亡即停、交换牌库规则。这里的**预览**不等于过去的“揭示”效果，也不是牌的逻辑翻开。

## 1. 设计目的

- 让玩家在开局和每批新卡入场时获得短暂、可练习的记忆窗口，降低纯随机盲翻占比，而不是永久公开牌面。
- 让位置干扰具备**触发预警、可追踪的移动、可制定对策的频率上限**。位置干扰不再占用敌人主动行动，敌人行动主要负责攻击、防御、蓄力、污染、封锁、冰封等。
- 不让强记忆玩家因**配对次数更多**而被惩罚：位置被动以有效手动翻牌数计数，成功配对本身不计数。
- 保留敌人只能改变卡牌物理状态、不能抹除玩家记忆的原则；避免频繁全桌随机打乱。

## 2. 入场预览（正式规则）

### 2.1 触发范围与展示节奏

1. 开场铺出的玩家牌、常规补牌、玩家主动「重新铺满」铺出的新玩家牌，及其他由玩家侧效果新增到桌面的牌，都加入本次入场预览队列；**只展示本次新增牌，不重新展示原先留在桌面的牌**。
2. 本次队列按牌在桌面上**行优先、从左到右、从上到下**排序。第 1 张在 t=0.00s 开始，第 i 张在 t=(i−1)×0.25s 开始；每张从自身开始起**正面可见 1.00s**，到期即独立翻回卡背。下一张启动不必等待上一张翻回；允许最多约 4 张同时可见。
3. 单批 N 张入场的总展示时间：N>0 时 **1.00s + (N−1)×0.25s**。16 张完整铺场为 **4.75 秒**；4 张补牌为 **1.75 秒**。此为首轮参数，后续根据体验调整；不把动画时长当真实战斗计时资源。
4. 同一结算链的多次入场合并到一个队列，按最终格位排序；玩家在预览结束后才恢复操作。允许「跳过预览」，跳过立即将本队列全部还原统一卡背、直接进入可操作状态，**不保留任何预览可见信息**。
5. 被动敌人**直接生成**的污染/病毒牌和增生复制体作为特殊干扰，首轮不获得免费正面预览，仍按统一卡背入桌；这是明确例外，后续按试玩决定是否调整。

### 2.2 逻辑隔离（避免改写现有战斗）

- 入场预览是**仅视觉的临时覆盖层**。卡牌在逻辑上保持**背面**；不计入正面牌数量上限，不参与正面候选配对，不触发 `[入场]` / `[翻开]` / `[翻回]` / `[离场]` / `[丢弃]`、能力牌效果、记忆堆记录、敌人行动条或敌人位置被动计数。
- 原有 `[入场]` 仍按 **该实例在场上首次被真正翻开** 触发；预览不会消耗首次翻开机会、`首翻`或`回访`记录。预览翻回也不构成一次逻辑「翻回」。
- 展示期间锁定会改变桌面状态的玩家输入、敌人行动和位置移动；允许只读查看与跳过。时间仅驱动动画；不得靠暂停、存档重载反复刷取不同入场信息。
- 若一条实际翻牌结算链产生新增牌：**先完成卡牌效果、匹配、补牌及必要的被动结算，再开始新牌预览**。不可在递归效果链中间插入可操作时段。
- 已留在桌面的逻辑正面牌不因新牌预览而自动翻回；预览中的新牌不参与匹配，也不挤占正面上限。

### 2.3 重铺平衡

- 主动「重新铺满」仍按现行规则消耗敌人行动条 **+2**，未另加费用。
- 因它也会让新铺的玩家牌依次预览，必须记录玩家每战重铺次数、重铺后首次配对的效率及是否出现「为获取预览信息而反复重铺」；只有证明过强再调价，不预先增加复杂的冷却或资源。

## 3. 敌人位置干扰改为被动

### 3.1 行动与被动的职责边界

- **位置移动类：**「混乱 / 换位 / 洗牌」不再作为敌人可选择的主动意图执行；改由敌人身上的被动规则按玩家操作计数或 Boss 阶段事件触发，不消耗敌人行动，也**不额外推进敌人行动条**。
- **非位置类：**「污染 / 封锁 / 冰封 / 增生」暂保留主动意图或既有能力机制，不与本次位置被动改造捆绑；攻击、蓄力、防御等照常由行动条执行。
- 旧敌人意图队列中的纯「特殊(混乱/换位/洗牌)」需在实现迁移时替换为该敌人的**蓄力/防御或其他非位置意图**；不要机械地全部换成攻击、抬高受到伤害的频率。具体敌人逐一校准，文档未声称游戏内已迁移。
- 敌人被动在战斗 UI 中单列名称、进度和**下一次触发效果**，不混入「下次行动意图」。主动意图仍公开。

### 3.2 公平性与结算时序

1. **计数来源**：仅玩家主动点选一张合法背面牌产生的「手动翻牌」累计 +1；成功/失败都计，`[迅速]` 免行动条也仍计数。卡牌效果自动翻开、入场预览、只读查看、敌人扰动和重铺不计数。
2. **首轮阈值**：普通敌人每周期累计 **5 次**有效手动翻牌触发一次局部干扰；精英 **4 次**；Boss 的常规位置被动暂按 **4 次**。每个**敌人行动周期最多1次**，周期在敌人完成下一次行动后重置计数。没有位置被动的敌人不显示该计数。
3. **预警**：阈值前至少 1 次有效手动翻牌时，UI 明示「下次翻牌后交换哪一类位置」，显示 4/5、3/4 等进度。目标若是随机的，至少预告目标范围、数量与移动方式；不泄漏牌名。
4. **移动时机**：手动翻牌完整结算完成、卡牌状态和补牌稳定后，优先解析敌人行动条满导致的主动行动与死亡中断。如果同次翻牌正好推动敌人出手，则**跳过本周期未兑现的位置被动**，周期计数随敌人行动结束重置；避免换位后立即敌人行动、玩家无法反应。
5. **触发时若没有敌人行动**：结算一次位置被动；目标只在**原本已在场且完成入场预览的背面玩家卡**中选，排除待预览新牌、病毒、稳定锚/免疫对象、正面牌。若目标不足则本次落空并消耗触发，不欠账、不无限补触发。之后对本轮新牌执行顺序预览。
6. **移动表现**：所有目标位移沿屏幕上的明确路径动画播放，不瞬移；牌面仍为统一卡背，标记随实体移动，不凭特效泄漏牌名。移动时锁定输入，动画完成后才恢复操作。只改变实体格位，不触发卡牌的翻开、翻回、离场或入场事件。
7. 同一操作链多种位置被动同时满足时每次最多执行 **1 次**位置扰动，优先 Boss 阶段事件，再精英/普通计数；其他事件只计入日志，不在同一结算里连环洗牌。Boss 阶段切换在伤害发生时按旧规则立即改变阶段属性，但位置移动动画延迟到链结束。
8. 若存在由「主动重铺」导致的新批预览，则这次操作本身不增加干扰计数；已有待展示队列完成前不触发新的位置干扰。
9. 位置移动不改变原有牌对的身份、同名/异名共鸣的本场缓存结果或牌堆顺序；只改变牌格。稳定锚等免疫仍生效。

### 3.3 干扰强度梯度（首轮建议）

| 对象 | 被动实例 | 触发 | 强度与玩家对策 |
|---|---|---|---|
| 混乱史莱姆等普通干扰敌 | **局部混乱** | 本周期第5次手动翻牌；每周期最多一次 | 随机交换2张合格背面玩家牌，动画可跟踪；在触发前完成重要配对。 |
| 记忆窃贼等精英干扰敌 | **边缘换位** | 第4次手动翻牌；每周期最多一次 | 随机选一行，将第1和第4列的2张合格背面玩家牌互换；标明行范围/播放位移动画。目标不可用则落空。 |
| 乱序墨灵等高阶干扰敌 | **小范围乱序** | 第4次手动翻牌；每周期最多一次 | 从合格背面玩家牌中取至多4张（至少2张），做可观察的循环换位；**不是全桌无提示洗牌**。 |
| Boss 阶段能力 | **阶段记忆冲击** | 进入指定阶段时，整场最多1次 | 提前在阶段提示中预告；阶段切换结算后选择最多6张合格背面玩家牌做一次可观察循环换位。普通周期干扰同一操作链不叠加。 |

- 普通战建议最多 1 种位置被动；精英最多 1 种位置被动加 1 种非位置干扰；Boss 才允许阶段升级。**不允许多个常规位置被动同时累积频繁触发**。
- 早期敌人先使用「2牌交换」，只在二章/精英逐渐引入局部循环与定向列位移；全桌无提示随机洗牌**暂停在新 V3 投放中**，暂不作为常规能力。
- 伤害预算必须与干扰强度联动：位置干扰强的敌人应降低直接伤害/施压频率，不能在旧特殊回合被改为攻击后白得额外输出。

## 4. 旧敌人配置迁移原则

- 04《敌人系统》是机制分类的正本；08《原型敌人设计》中“每次行动混乱、特殊(换位)、特殊(洗牌)”以及依赖「揭示破坏洗牌」的描述，属于**旧实现与历史原型记录**，应依据本文件重新配置。
- **混乱史莱姆**：纯位置「特殊(混乱)」移除，改「局部混乱」被动；旧该轮意图优先改非攻击的蓄力/防御，避免输出上涨。
- **记忆窃贼**：旧「特殊(换位)」改「边缘换位」被动；污染仍可保留在主动意图中。
- **乱序墨灵、沉没总管、沉沦典狱**：常规「特殊(洗牌)」改「小范围乱序」被动；沉沦典狱可在阶段转换追加整场一次的「阶段记忆冲击」。
- **记忆吞噬者**：常规「混乱」改被动，阶段间可提高复杂度；封锁、污染仍作为主动效果单独平衡。
- **其他敌人**：如果并不依赖位置干扰，不因为改版强行添加被动。三章全部敌人及 JSON 数据按 04/08/游戏仓对照后逐一迁移，旧数据**仍是当前 Unity 实现现状**。

## 5. 验收标准与调参信号

### 功能/规则验收

- 16张 4.75s、4张 1.75s 的视觉序列；每张独立1s翻回，跳过立即统一卡背；补牌不重复预览旧卡。
- 预览不触发 `[入场]` `[翻开]` `[翻回]`、首翻/回访/共鸣骰、行动条、正面牌上限；预览前后逻辑结果相同。
- 预览期间无玩家状态改变动作和敌人位置移动；暂停/重读档/跳过不会产生额外预览收益。
- 4/5、3/4 预警可见；有效手动翻牌计数准确；与敌人行动同次到达阈值时不出现无意义换位；位置动画可以追踪实体。
- 稳定锚/特殊牌排除、候选不足落空、阶段切换一次性、死亡即停、已知牌逻辑正面保留、多牌新入场补牌均通过。
- 原行动意图中不再出现纯位置变化；旧特殊位迁移后同难度敌人有效伤害/治疗消耗与当前版本对比校准。

### 首轮试玩数据

- 与“无入场预览”的基线比较：首次配对前的手动翻牌数、白翻率、失误率、战斗时长、每战重铺次数。
- 与“位置动作干扰”的基线比较：每战被移动的旧牌数、移动后配对成功率、玩家是否能描述下一次干扰、配对与受伤次数。
- 重点观察**快速记忆玩家与普通玩家的体验差距**：若位置被动让熟练玩家没有优势，降低频率/规模；若几乎从不触发，提高预警质量或调低阈值而非引入随机全洗。
- 首轮不同时改卡牌数值、共鸣概率、敌人血量与掉落，便于归因；正式迁移时按变更清单和对照验收逐项落实。

## 2. 机制

连击：力量与高频段数；流血：施血—命中—递减—补层；中毒：持久叠毒与主动兑现；护盾：格挡、护甲、反击与防御转伤害。配对、翻开、翻回、消耗横向贯穿，非职业或流派硬锁。普通启动独立有用，稀有组件改变循环。禁止新增位置条件、额外资源与操作。保持同名双实例、配对前快照、真实翻牌事件、双回合、整对消耗和既有伤害来源。数值默认单实例；明确整对的一次性效果不翻倍。命中/状态事件条件按实际结算时点，其余配对条件读不可变快照；禁止递归，死亡不补发。卡文涉及多份准备或事件队列的未锁定语义不得自行实装。

起始牌6/6基线，推荐先测5/5（每对10/10），另测5/6；4/5仅必要时。固定实际发牌、初始组成、敌人、行动条、种子及职业。

## 5. 优先评审的组合与风险

| 组合 | 目标与风险 |
|---|---|
| 并击/近注 | 近注改为力量防御桥，不同步提高并击 |
| 页角/旧识/复习/藏锋 | 实例成长、回访输出、翻回即时盾、再翻开盾，四类区别；检查故意失败获利 |
| 夹页/穿书 | 追加攻击段 vs 回访后的首段伤害，若仍被严格压制则重做穿书 |
| 皮甲/息笔/稳步/应急护符 | 普通护甲启动、空盾防御、消耗护甲、翻开盾；首章护甲不能导致永久安全 |
| 盾击/刃甲/续写 | 即时格挡、长期护甲、高盾整对终端；若续写仍同质则重做，不靠无条件数值覆盖 |
| 三拍/锯齿/影袭 | 高频输出、普通施血、较强补血；检查命中时点 |
| 毒发/订正/腐蚀环 | 主动状态伤害、持续施毒、一次性叠毒；毒发不产生定时事件 |
| 追影/考据/游刃 | 高段条件、低章条件、有限成长；若追影只是上位则重做 |
| 连锁核心×双生符×血契剑鞘 | 直接段与独立附伤分流，消融对照力量乘法风险 |
| 血潮×血潮棱镜×撕裂指环 | 流血净增长及补层非递归；追加伤害与死亡短路 |
| 毒雾×腐蚀环×能量护盾 | 长战和故意翻毒刺是否占优；保留敌人周期强化 |
| 构篇×随风成阵×叠页行军旗×记忆王冠 | 消耗实际去向、永久力量/护甲成长、耗尽和只剩一对 |
| 混沌核心×思维导图 | 敌方自动换位与补偿触发；不得泄露身份或额外操作 |

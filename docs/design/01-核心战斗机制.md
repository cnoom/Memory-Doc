## 1. 战斗目标

- **胜利条件**：敌人血量归零。
- **失败条件**：玩家血量归零。

---

## 2. 玩家资源

| 资源 | 说明 |
|---|---|
| **血量（HP）** | 持久资源，跨战斗保留（run内）。归零 = 游戏结束。 |
| **格挡（Block）** | 临时防御资源，抵消受到的伤害。每次受击时优先消耗格挡。格挡在每个回合结束时清零（敌人行动后残余格挡消失），不跨回合保留。 |

---

## 3. 翻牌与匹配流程（精确规则）

战斗桌面为 **4×4 网格（16 格）**，每格放一张卡牌。初始所有牌背面朝上。玩家通过"翻牌"行动来触发效果和配对。

**网格与相邻定义：**
- 桌面是 4×4 的方格阵列，每张牌占据一个格子，有明确的行列位置。
- **相邻** = 以某格为中心的 **8 格范围**（上、下、左、右 + 四个对角线方向）。边缘和角落的格相邻格数较少（角落3格，边缘5格，中央8格）。
- 卡牌效果中的"相邻""周围"均以此定义为准。

**核心约束：默认任意时刻桌面上最多一张正面朝上的牌（正面牌上限=1）。**

> 正面牌上限可通过角色被动（如术士被动）或卡牌效果（如能力牌「百科全书」）提升。上限提升时，新翻的牌先与最早翻开的正面牌判定匹配，匹配失败才将其挤掉（见步骤1与步骤5）。

### 卡牌状态（Card States）

战斗中的每张卡牌在任意时刻处于**背面**或**正面**两种主状态之一。翻开、翻回、丢弃、离场是**状态转换事件**。

**主状态（互斥，每张牌恰有其一）：**

| 状态 | 内容可见 | 参与匹配判定 | 受正面牌上限约束 | 进入方式 | 离开方式 |
|---|---|---|---|---|---|
| **背面**（Face-down） | 否 | 否 | 否 | 初始状态；被翻回 | 翻开；被丢弃 |
| **正面**（Face-up） | 是 | 是 | 是 | 翻开 | 翻回；离场 |

**状态转换（事件 → 转换 → 触发词条）：**

| 事件 | 转换 | 触发词条 |
|---|---|---|
| **翻开** | 背面 → 正面 | `[翻开]` |
| **翻回** | 正面 → 背面 | `[翻回]` |
| **丢弃** | 背面 → 移出桌面 | `[丢弃]` |
| **离场** | 任意主状态 → 移出桌面 | `[离场]`（原`[消除]`） |

- **翻开**：玩家点击背面牌（翻牌操作），或效果翻开。翻牌操作的行动条+1见翻牌分步结算。
- **翻回**：挤掉（匹配失败）、被效果翻回等。
- **丢弃**：背面牌被移出桌面（重新铺满、被效果移走等），触发`[丢弃]`。
- **离场**：牌被移出桌面（进入弃牌堆/消耗堆或从游戏移除），不再受桌面操作影响，触发`[离场]`。触发来源：匹配成功、能力牌翻开即移出、效果移走、重新铺满等。**离场覆盖所有移出桌面情况：背面牌移出时先触发`[丢弃]`、再触发`[离场]`；正面牌移出时只触发`[离场]`。**

### 翻牌操作的分步结算

```
玩家点击一张背面牌翻开
│
├─ 步骤1: 若桌面上正面牌数已达上限（默认1），确定"最早翻开的
│         正面牌"为待匹配对象（暂不翻回）；若未达上限，则无对象
│         （挤掉规则：上限为N时，桌面保持最多N张正面牌。新翻的牌
│          先与最早翻开的那张判定匹配（见步骤5），匹配成功则两牌
│          移出桌面、无需挤掉；匹配失败才将其挤掉（翻回背面））
│
├─ 步骤2: 这张牌正面朝上
│
├─ 步骤3: 结算这张牌的 [翻开] 触发型词条效果
│
├─ 步骤4: 能力牌特殊处理
│         若这张牌是能力牌，默认翻开即移出桌面：
│         ├─ 触发 [离场] 效果 → 进入弃牌堆
│         └─ 跳过步骤5、6，直接到步骤7（能力牌不参与匹配）
│         （非能力牌继续步骤5）
│
├─ 步骤5: 匹配判定（先匹配，后挤掉）
│         若步骤1确定了待匹配对象（正面牌已达上限），检查这张牌与
│         待匹配对象是否存在匹配关系
│         ├─ 匹配成功 → 进入步骤6
│         └─ 不匹配 → 将待匹配对象翻回背面（挤掉），这张牌保持
│                     正面朝上（等待下一次翻牌判定）
│         （若步骤1未确定待匹配对象——上限未满——则不进行匹配判定，
│          这张牌直接保持正面朝上，与已有正面牌共存）
│
├─ 步骤6: 匹配结算（若匹配成功）
│         ├─ 触发两张牌各自的基础效果
│         ├─ 两张牌从桌面移出
│         └─ 触发两张牌的 [离场] 效果
│
└─ 步骤7: 行动条 +1（所有效果结算完毕后的最后一步）
```

**关键规则：**
- 行动条 +1 永远是最后一步，发生在所有卡牌效果结算之后。
- 这意味着"行动条 -X"的卡牌效果先结算，再执行 +1，为操控行动条提供了设计空间。
- 病毒牌不是特殊类别，它就是普通卡牌通过触发型词条组合实现的——`[翻开]: 造成负面效果` + `[翻开]: 移除自身`。

### 翻牌流程示例

1. 玩家翻开第一张牌（A）→ A 正面朝上，A 的 `[翻开]` 效果触发，行动条 +1。
2. 玩家翻开第二张牌（B）→ B 正面朝上，B 的 `[翻开]` 效果触发；此时已达上限1，B 与最早翻开的 A 判定匹配：
   - **匹配** → 结算基础效果，两牌移出桌面并触发 `[离场]` 效果，行动条 +1。
   - **不匹配** → A 翻回背面（挤掉），B 留在桌面正面。行动条 +1。
3. 玩家翻开第三张牌（C）→ 与当前最早翻开的正面牌判定匹配（匹配则两牌移出桌面；不匹配则其被挤掉）...（循环）

**上限提升时的流程示例（如术士被动：正面牌上限=2）：**

1. 翻开 A → 正面牌数 0→1（未达上限2），A 保持正面，**不进行匹配判定**，行动条 +1。
2. 翻开 B → 正面牌数 1→2（未达上限2），B 保持正面，**不进行匹配判定**，行动条 +1。
3. 翻开 C → 正面牌数已达上限2，C 先与**最早翻开**的 A 判定匹配：
   - **匹配** → 结算基础效果，C、A 移出桌面，行动条 +1（B 仍在桌面正面，无需挤掉）。
   - **不匹配** → A 翻回背面（挤掉），C 保持正面，B、C 共存（上限2），行动条 +1。
4. 翻开 D → 先与当前最早翻开的 B 判定匹配：匹配则 D、B 移出桌面；不匹配则 B 被挤掉，C、D 共存...（循环，A 移出/被挤掉后 B 成为"最早"）

## 4. 匹配规则

**默认匹配规则 = 同名匹配。**

两张卡牌**名称完全相同**才能匹配。这是绝大多数卡牌的匹配方式。

- 不存在相似卡名（如"火球术"和"大火球术"）。卡牌名称是唯一标识。
- 特殊匹配关系只能通过**匹配型词条**实现（见 [卡牌与词条系统](./02-卡牌与词条系统.md#③-匹配型词条修改匹配规则)）。

## 5. 行动条机制

```
行动条: 0 ──→ [阈值] ──→ 敌人行动 ──→ 重置为0
         翻牌+1
         重新铺满+2
```

- 行动条从 0 开始。
- **玩家每翻一张牌，行动条 +1**（在所有效果结算后）。
- **玩家主动"重新铺满桌面"，行动条 +2**。
- 行动条达到敌人阈值 → 敌人执行意图所示的行动 → 行动条重置为 0。
- **配对成功不影响行动条**。防御完全依赖卡牌效果。
- 某些卡牌效果可以减少行动条（如冰冻状态、特定词条）。

**回合概念：**
- 本游戏没有传统回合制（玩家行动→敌人行动的固定交替），但存在**以敌人行动为分隔的隐性回合**。
- **回合 = 敌人两次行动之间的间隔**（行动条从某次重置到下次填满）。
- 翻牌推进行动条，行动条满 → 敌人行动 → 当前回合结束，新回合开始。
- 部分卡牌效果使用"本回合""持续N回合"等表述时，以此定义为基准。
- **格挡在每个回合结束时清零**（敌人行动后，残余格挡消失）。

## 6. 批次补充规则

桌面牌从玩家牌组抽取。当桌面上牌被消耗后，按以下规则补充：

**补充触发条件：**
- 桌面上**可配对的牌对数 ≤ 1** 时，补充新一批。
- "可配对牌对数"指：桌面上存在的能互相匹配的牌对数量。
- 残留的未配对牌（无法互相匹配的单牌）不触发补充，它们留在原位。

**补充方式：**
- 残留的未配对牌**位置不变**（保持原网格位置）。
- 新牌从牌组抽取，铺到空出的格子中。
- 玩家之前翻过的残留牌，其位置和内容信息对玩家有效（凭记忆可利用）。

**批次的意义：**
- 每一批 = 一个小目标，"清掉这批所有配对"有清晰的成就感。
- 批次切换时记忆"归零重来"，但这是玩家主动完成带来的，挫败感低。
- 残留牌创造跨波次的记忆价值——下一批可能补上同名牌，凭记忆直接配对。

## 7. 重新铺满桌面（主动操作）

玩家随时可以选择"重新铺满桌面"，作为卡住时的紧急逃生手段。

**效果：**
- 当前桌面所有牌（包括残留牌）进入弃牌堆。
- 从牌组重新抽牌铺满桌面。

**代价：**
- 行动条 **+2**。

**用途：**
- 桌面残留牌无法配对且玩家记不住/找不到时，强行重置。
- 配合牌组循环（牌组耗尽 → 弃牌堆洗回），重新铺满 = 一次"洗牌重抽"。

## 8. 牌组循环

战斗中存在三个牌区：

| 牌区 | 说明 |
|---|---|
| **牌组（Deck）** | 未抽到桌面的牌，桌面补牌从此抽取。 |
| **桌面（Board）** | 当前铺开的牌（背面/正面朝上）。 |
| **弃牌堆（Discard）** | 丢弃/离场的牌、被"重新铺满"清除的牌。 |

**牌组耗尽规则：**
- 当牌组抽空时，弃牌堆的所有牌重新洗回牌组。
- 消耗堆的牌**不参与**重新洗牌（它们在本场战斗内永久消耗）。

> 注意：消耗堆只在单场战斗内生效。战斗结束后，所有牌（包括消耗堆）回到牌组，供下一场战斗使用。详见 [Meta系统·牌组系统](./05-Meta系统.md#2-牌组系统)。

---

## 9. 战斗结束

- **胜利**：敌人血量归零。结算奖励（卡牌/金币/遗物）。
- **失败**：玩家血量归零。Run 结束。

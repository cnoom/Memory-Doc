## 1. 战斗目标

- **胜利条件**：敌人血量归零。
- **失败条件**：玩家血量归零。
- 血量归零的判定时机见 [中断规则](#34-中断规则死亡即停)。

---

## 2. 玩家资源

| 资源 | 说明 |
|---|---|
| **血量（HP）** | 持久资源，跨战斗保留（run内）。归零 = 游戏结束。 |
| **格挡（Block）** | 临时防御资源，抵消受到的伤害。每次受击时优先消耗格挡。格挡在每个回合结束时清零（敌人行动后残余格挡消失），不跨回合保留。 |

## 3. 战斗流程总览

本章给出一场战斗从开始到结束的完整流程框架。所有流程均为显式规则，不做隐含约定；各环节的精确规则见后续章节。

### 3.1 战斗开始（初始化）

1. **载入敌人**：血量、行动条 = 0/阈值、意图（首次生成）、能力、状态。
2. **载入玩家**：血量沿用 run 内当前值；格挡 = 0；行动相关的临时状态清空。
3. **铺桌面**：以玩家牌库为源，**每张卡各复制 2 份**洗牌生成**抽牌堆**（抽牌堆张数 = 牌库张数 × 2），从抽牌堆抽 16 张铺满 4×4 网格，全部背面朝上。战斗牌组不足 16 张（即牌库不足 8 张）时铺满所有可用牌，空格留空（见 [05·桌面铺牌规则](./05-Meta系统.md#桌面铺牌规则)）。**记忆堆置空**。
4. 初始化完成，进入玩家决策循环。

> 牌库是 run 级牌区，本步骤只以它为源**每张 ×2 复制**生成抽牌堆，牌库本身不发生任何变化；牌库按**单份**记录收藏（获取卡牌一律给 1 张），战斗中每张恰有一对（见 [§9 牌区系统](#9-牌区系统)）。

### 3.2 玩家可用操作

战斗中玩家的全部操作如下，任意时刻可执行：

| 操作 | 行动条 | 说明 |
|---|---|---|
| **翻牌**（点击背面牌） | **+1** | 核心操作，走完整翻牌结算链（见 [§4](#4-翻牌与匹配流程精确规则)） |
| **重新铺满桌面** | **+2** | 清空桌面重铺，卡住时的紧急逃生手段（见 [§8](#8-重新铺满桌面主动操作)） |
| **查看** | 无 | 悬浮预览正面牌、查看抽牌堆/弃牌堆/消耗堆/记忆堆列表、查看牌库、查看意图详情、暂停菜单——不触发任何结算 |

### 3.3 主循环

```
玩家操作（翻牌 / 重新铺满）
  → 操作结算链
  → 行动条满？
      ├ 否 → 回到玩家决策
      └ 是 → 行动条满结算：
             1. 敌人执行意图所示行动（玩家先扣格挡，再扣血量）
             2. "行动条满时"状态结算（如中毒按层数造成伤害）
             3. 行动条重置为 0
             4. 意图刷新（敌人下次行动重新预告）
             5. 回合结束：格挡清零
             → 回到玩家决策
```

- **回合** = 敌人两次行动之间的间隔（行动条从某次重置到下次填满）。
- 状态效果不统一在敌人行动后结算，而是各自绑定触发时机（见 [§6.1 状态结算时机](#61-状态结算时机)）。

### 3.4 中断规则（死亡即停）

结算链中任意节点导致一方血量归零，战斗**立即**结束，当前结算链的后续节点不再执行：

- **敌人血量归零** → 立即胜利，进入奖励结算。后续节点不再执行——包括行动条 +1、状态结算、补牌检查，以及本应触发的敌人行动。
- **玩家血量归零** → 立即失败，Run 结束。
- 伤害发生即检查，没有延时结算或死亡豁免。

> 例：匹配结算的伤害将敌人打到 0 血，但本次翻牌的行动条 +1 恰好也会填满行动条——敌人已死亡，不会出手，直接胜利。

## 4. 翻牌与匹配流程（精确规则）

战斗桌面为 **4×4 网格（16 格）**，每格放一张卡牌。初始所有牌背面朝上。玩家通过"翻牌"行动来触发效果和配对。

**网格与相邻定义：**
- 桌面是 4×4 的方格阵列，每张牌占据一个格子，有明确的行列位置。
- **相邻** = 以某格为中心的 **8 格范围**（上、下、左、右 + 四个对角线方向）。边缘和角落的格相邻格数较少（角落3格，边缘5格，中央8格）。
- 卡牌效果中的"相邻""周围"均以此定义为准。

**核心约束：默认任意时刻桌面上最多一张正面朝上的牌（正面牌上限=1）。**

> 正面牌上限可通过角色被动（如术士被动）或卡牌效果（如能力牌「百科全书」）提升。上限不影响匹配判定——只要桌面存在正面牌，新翻的牌就与**所有**正面牌判定匹配（任一匹配即配对）；上限只约束**结算后的超限检查**：正面牌数超过上限时，最早翻开的正面牌被翻回（见步骤4与步骤6）。

### 卡牌状态（Card States）

战斗中的每张卡牌在任意时刻处于**背面**或**正面**两种主状态之一。翻开、翻回、丢弃、离场是**状态转换事件**。

**主状态（互斥，每张牌恰有其一）：**

| 状态 | 内容可见 | 参与匹配判定 | 受正面牌上限约束 | 进入方式 | 离开方式 |
|---|---|---|---|---|---|
| **背面**（Face-down） | 否 | 否 | 否 | 初始状态；被翻回 | 翻开；被丢弃 |
| **正面**（Face-up） | 是 | 是 | 是 | 翻开 | 翻回；离场 |

**状态转换（事件 → 转换 → 触发词条）：**

| 事件 | 转换 | 触发词条 |
|---|---|---|
| **翻开** | 背面 → 正面 | `[翻开]`；带`[入场]`的牌在场上首次被翻开时同时触发`[入场]` |
| **翻回** | 正面 → 背面 | `[翻回]` |
| **丢弃** | 背面 → 移出桌面 | `[丢弃]` |
| **离场** | 任意主状态 → 移出桌面 | `[离场]` |

- **翻开**：玩家点击背面牌（翻牌操作），或效果翻开。效果翻开的牌同样走本节结算链（嵌套结算）。带`[入场]`词条的牌在场上**首次被翻开**时同时触发`[入场]`（与`[翻开]`同一结算步骤，先结算`[入场]`）；`[入场]`离场后重置，重新铺场后可再次触发。
- **翻回**：超限挤掉、被效果翻回等。
- **丢弃**：背面牌被移出桌面（重新铺满、被效果移走等），触发`[丢弃]`。
- **离场**：牌被移出桌面（进入弃牌堆/消耗堆或从游戏移除），不再受桌面操作影响，触发`[离场]`。触发来源：匹配成功、能力牌翻开即移出、效果移走、重新铺满等。**离场覆盖所有移出桌面情况：背面牌移出时先触发`[丢弃]`、再触发`[离场]`；正面牌移出时只触发`[离场]`。词条修饰**：带`[顽固(x)]`且 x>0 的牌抵挡离场事件——不离场、不触发词条，但`[翻回]`不受影响（细则见 [02·效果型词条](./02-卡牌与词条系统.md#②-效果型词条行为修饰符)）；带`[隐秘]`的牌被丢弃（背面移出）时触发其基础效果。

### 翻牌操作的分步结算

```
玩家点击一张背面牌
│
├─ 步骤1: 这张牌翻开（背面 → 正面）
│
├─ 步骤2: 结算这张牌的触发型词条效果
│         先结算 [入场]（若带此词条且为场上首次被翻开；离场后重置），
│         再结算 [翻开]
│
├─ 步骤3: 能力牌特殊处理
│         若这张牌是能力牌：
│         ├─ 触发持续效果（本场战斗内持续生效，牌离场不影响）
│         ├─ 触发 [离场] → 移出桌面，进入弃牌堆
│         └─ 跳到步骤7（能力牌不参与匹配）
│         （非能力牌继续步骤4）
│
├─ 步骤4: 匹配判定（先匹配）
│         若桌面上存在已翻开的正面牌，与**所有**正面牌逐一判定
│         （按翻开顺序，从最早的一张开始）：
│         ├─ 与任意一张匹配成功 → 进入步骤5
│         │   （与最早匹配成功的那张配对；多张可匹配时只配对一张）
│         └─ 全部不匹配 → 进入步骤6
│         （桌面上没有正面牌时跳过判定，直接进入步骤6）
│
├─ 步骤5: 匹配结算
│         ├─ 触发两张牌各自的基础效果
│         └─ 两张牌从桌面移出（触发各自的 [离场] 效果）；
│            带[顽固(x)]且x>0的牌抵挡离场：留在原格、x-1、
│            不触发[离场]/[丢弃]（[翻回]不受顽固影响）
│            （双方都被顽固留场时，正面牌可能超过上限：
│             额外执行一次步骤6 的超限检查）
│         → 跳到步骤7
│
├─ 步骤6: 正面牌超限检查
│         若当前桌面正面牌数量超过上限（默认1），
│         将**最早翻开**的正面牌翻回背面（挤掉，触发 [翻回]），
│         其余正面牌保留；未超限则无事发生
│
├─ 步骤7: 敌人行动条 +1（被翻开的牌带[迅速]时，本次 +1 跳过）
│
├─ 步骤8: 状态结算
│         结算因本次行动条变化而触发的状态效果
│         （如灼烧：每次行动条数值变化时按层数造成伤害，层数-1；
│          冰冻：使本次行动条增长-1后，层数-1）
│
├─ 步骤9: 补牌检查
│         本次结算链中有牌离场 → 检查桌面可配对牌对数：
│         ≤1 时从抽牌堆抽新牌填入空格（残留未配对牌位置不动）
│         （本步骤无牌离场时跳过）
│
└─ 步骤10: 抽牌堆耗尽检查
          步骤9抽牌时若抽牌堆已空 → 弃牌堆所有牌洗回抽牌堆
          （消耗堆不参与洗回）
```

**关键规则：**
- **匹配判定面向所有正面牌**：新翻的牌与桌面所有已翻开的牌逐一判定，任一匹配即配对，不限定"最早翻开"的那张。上限为1时桌面上只有一张正面牌，判定对象天然唯一；上限提升时（如术士被动），新牌可与任意一张可匹配的正面牌配对。
- **超限检查是状态收敛**：结算链中翻开（含效果翻开）可能导致正面牌暂时超限，步骤6保证结算结束后正面牌数 ≤ 上限。多个正面牌超限时按翻开顺序从最早开始逐张翻回。
- **行动条 +1 在所有牌面效果之后**、"状态结算/补牌检查"之前——"行动条 -X"的卡牌效果先结算，再执行 +1，为操控行动条提供设计空间。
- **死亡即停**：步骤5的伤害若击杀敌人，后续步骤（含步骤7）全部跳过（见 [§3.4](#34-中断规则死亡即停)）。
- **`[顽固]`/`[隐秘]`/`[迅速]`是离场与行动条规则的词条修饰**：顽固抵挡离场（牌留场、配对仍成立、另一张正常离场，`[翻回]`不受影响，详见步骤5）；隐秘在牌被丢弃（背面移出）时触发其基础效果；迅速跳过本次翻牌的行动条 +1。细则见 [02·效果型词条](./02-卡牌与词条系统.md#②-效果型词条行为修饰符)。
- 病毒牌不是特殊类别，它就是普通卡牌通过触发型词条组合实现的——`[翻开]: 造成负面效果` + `[翻开]: 移除自身`。

### 翻牌流程示例

1. 玩家翻开第一张牌（A）→ 桌面无正面牌，跳过匹配判定；A 保持正面（正面牌数 1 ≤ 上限），行动条 +1，状态结算，补牌/耗尽检查。
2. 玩家翻开第二张牌（B）→ B 正面，结算 `[翻开]`；B 与正面牌 A 判定匹配：
   - **匹配** → 结算基础效果，两牌移出桌面并触发 `[离场]` 效果，行动条 +1（桌面无正面牌）。
   - **不匹配** → 超限检查：正面牌 2 > 上限1 → A（最早）翻回背面（挤掉），B 留在桌面正面。行动条 +1。
3. 玩家翻开第三张牌（C）→ 与当前所有正面牌逐一判定（与任一匹配则配对移出；全部不匹配则最早的一张被挤掉）...（循环）

**上限提升时的流程示例（如术士被动：正面牌上限=2）：**

1. 翻开 A → 桌面无正面牌，跳过判定，A 保持正面，行动条 +1。
2. 翻开 B → 与正面牌 A 判定匹配：
   - **匹配** → A、B 移出桌面，行动条 +1。
   - **不匹配** → 超限检查：正面牌 2 ≤ 上限2，不挤掉，A、B 共存（玩家可同时比较两张牌），行动条 +1。
3. 翻开 C → 与**所有**正面牌（A、B）逐一判定：
   - **与任一匹配**（如与 B 同名）→ 与最早匹配成功的那张配对，两牌移出桌面，行动条 +1。
   - **全部不匹配** → 超限检查：正面牌 3 > 上限2 → 最早的 A 翻回背面（挤掉），B、C 共存，行动条 +1。
4. 翻开 D → 与当前所有正面牌逐一判定...（循环，A 移出/被挤掉后 B 成为"最早"）

## 5. 匹配规则

**默认匹配规则 = 同名匹配。**

两张卡牌**名称完全相同**才能匹配。这是绝大多数卡牌的匹配方式。

- 不存在相似卡名（如"火球术"和"大火球术"）。卡牌名称是唯一标识。
- 特殊匹配关系只能通过**匹配型词条**实现（见 [卡牌与词条系统](./02-卡牌与词条系统.md#③-匹配型词条修改匹配规则)）。

## 6. 行动条机制

```
行动条: 0 ──→ [阈值] ──→ 敌人行动 ──→ 行动条满状态结算 ──→ 重置为0
         翻牌+1
         重新铺满+2
         （每次变化后结算行动条相关状态）
```

- 行动条从 0 开始。
- **玩家每翻一张牌，行动条 +1**（在所有卡牌效果结算之后，见 [§4 步骤7](#翻牌操作的分步结算)；被翻开的牌带`[迅速]`词条时本次不增加）。
- **玩家主动"重新铺满桌面"，行动条 +2**。
- **每次行动条数值变化后，立即结算"行动条变化"触发的状态效果**（见下节）。
- 行动条达到敌人阈值 → 敌人执行意图所示的行动 → 结算"行动条满时"状态（如中毒）→ 行动条重置为 0。
- **配对成功不影响行动条**。防御完全依赖卡牌效果。
- 某些卡牌效果可以减少行动条（如冰冻状态、特定词条）——行动条的减少同样是"行动条数值变化"，同样触发状态结算。

**回合概念：**
- 本游戏没有传统回合制（玩家行动→敌人行动的固定交替），但存在**以敌人行动为分隔的隐性回合**。
- **回合 = 敌人两次行动之间的间隔**（行动条从某次重置到下次填满）。
- 翻牌推进行动条，行动条满 → 敌人行动 → 当前回合结束，新回合开始。
- 部分卡牌效果使用"本回合""持续N回合"等表述时，以此定义为基准。
- **格挡在每个回合结束时清零**（敌人行动后，残余格挡消失）。

### 6.1 状态结算时机

状态效果**没有统一的结算时点**，各自绑定自己的触发时机：

| 触发时机 | 结算内容 | 发生位置 |
|---|---|---|
| **行动条数值变化后**（翻牌+1、重新铺满+2、效果增减行动条） | 灼烧（按层数造成伤害）、冰冻（已使本次增长-1，层数-1） | 翻牌结算链步骤8；重新铺满结算链对应步骤 |
| **行动条满时** | 中毒（按层数造成伤害，层数不衰减） | 敌人行动之后（见 [§3.3 主循环](#33-主循环)） |
| **受到伤害时** | 护甲（抵消伤害）、易伤（伤害+50%） | 伤害结算内 |
| **敌人攻击时** | 虚弱（敌人攻击伤害-25%） | 敌人伤害结算内 |

> 状态的详细定义见 [状态效果系统](./03-状态效果系统.md)。任何状态结算导致一方死亡时，适用 [中断规则](#34-中断规则死亡即停)。

## 7. 批次补充规则

桌面牌从抽牌堆抽取。补充采用**事件驱动检查**：**每次有牌离场后，待当前效果结算完毕，立即检查一次**（翻牌结算链中为固定步骤9；其他来源的离场——如效果移走牌——在该效果结算后同样检查）。

**补充触发条件：**
- 桌面上**可配对的牌对数 ≤ 1** 时，补充新一批。
- "可配对牌对数"指：桌面上存在的能互相匹配的牌对数量。
- 残留的未配对牌（无法互相匹配的单牌）不触发补充，它们留在原位。

**补充方式：**
- 残留的未配对牌**位置不变**（保持原网格位置）。
- 新牌从抽牌堆抽取，铺到空出的格子中。
- 玩家之前翻过的残留牌，其位置和内容信息对玩家有效（凭记忆可利用）。
- 抽牌时抽牌堆已空 → 先执行弃牌堆洗回（见 [§9 牌区系统](#9-牌区系统)）。

**批次的意义：**
- 每一批 = 一个小目标，"清掉这批所有配对"有清晰的成就感。
- 批次切换时记忆"归零重来"，但这是玩家主动完成带来的，挫败感低。
- 残留牌创造跨波次的记忆价值——下一批可能补上同名牌，凭记忆直接配对。

## 8. 重新铺满桌面（主动操作）

玩家随时可以选择"重新铺满桌面"，作为卡住时的紧急逃生手段。

**效果：**
- 当前桌面所有牌（包括残留牌）进入弃牌堆：背面牌先触发`[丢弃]`、再触发`[离场]`；正面牌只触发`[离场]`。被丢弃的`[隐秘]`牌额外触发其基础效果（触发顺序见 [02·效果型词条](./02-卡牌与词条系统.md#②-效果型词条行为修饰符)）；带`[顽固(x)]`且 x>0 的牌抵挡清桌，留在原格主状态不变。
- 从抽牌堆重新抽牌铺满**其余格子**（顽固牌占据的格子保留原牌；战斗牌组不足16张时铺满所有可用牌；抽牌时抽牌堆已空 → 弃牌堆洗回）。

**结算顺序：**

```
点击"重新铺满"
  → 1. 清桌：所有桌面牌进入弃牌堆（触发[丢弃]/[离场]；顽固牌留场）
  → 2. 重抽：从抽牌堆抽牌铺满空格（顽固牌留场的格子保留原牌），全部背面朝上
  → 3. 敌人行动条 +2
  → 4. 状态结算（行动条变化触发的状态）
  → 5. 抽牌堆耗尽检查（若步骤2抽牌时抽牌堆已空，弃牌堆洗回——
      洗回发生在抽牌过程中，此处为显式确认点）
  → （行动条满则进入 [§3.3 主循环] 的敌人行动流程）
```

**代价：**
- 行动条 **+2**。

**用途：**
- 桌面残留牌无法配对且玩家记不住/找不到时，强行重置。
- 配合抽牌堆循环（抽牌堆耗尽 → 弃牌堆洗回），重新铺满 = 一次"洗牌重抽"。

## 9. 牌区系统

战斗相关的卡牌存放于**六个牌区**。其中五个为**战斗牌区**（只在单场战斗内变化，战斗结束销毁），**牌库**为 **run 级牌区**（贯穿整个 run，不受战斗影响）。

### 9.1 牌区总览

| 牌区 | 级别 | 说明 |
|---|---|---|
| **牌库（Library）** | run 级 | 玩家在本 run 中收集的所有卡牌（初始牌库 + 战斗奖励/事件/商店获得 − 移除），**按单份记录**。**不受战斗影响，仅用于玩家查看了解**（局外与战斗中均可查看）。 |
| **抽牌堆（Draw Pile）**（原"牌组"） | 战斗 | 战斗开始时以牌库为源**每张 ×2** 洗牌复制生成（张数 = 牌库 × 2，库内任意一张牌在战斗中至少恰有一对，不存在落单无法同名配对的牌）；桌面铺牌与批次补牌从此抽取。 |
| **桌面（Board）** | 战斗 | 当前铺在 4×4 网格上的牌（背面/正面朝上）。 |
| **弃牌堆（Discard Pile）** | 战斗 | 离场/被"重新铺满"清除的牌的暂存区；抽牌堆耗尽时洗回抽牌堆。 |
| **消耗堆（Exhaust Pile）** | 战斗 | 带`[消耗]`词条的牌进入弃牌堆时改为进入此处，本场战斗不再可用、不参与洗回。 |
| **记忆堆（Memory Pile）** | 战斗·**记录** | 战斗中**触发过效果的牌按触发顺序**的记录。牌本体不移动（见 [9.3](#93-记忆堆记录规则)）。 |

### 9.2 牌区流转

```
【战斗开始】
  牌库 ──洗牌复制（每张×2）──→ 抽牌堆 ──抽16张铺场──→ 桌面        （记忆堆置空）

【战斗中】
  抽牌堆 ──铺场/批次补牌──→ 桌面
  桌面 ──离场（匹配/能力牌/效果移走/清桌）──→ 弃牌堆
       （带[消耗]改为进入消耗堆；带[移除]改为移出游戏）
  弃牌堆 ──抽牌堆耗尽时洗回──→ 抽牌堆                （消耗堆不参与）
  任意效果触发 ──按顺序记录──→ 记忆堆                  （牌本体不移动）

【战斗结束】
  五个战斗牌区全部销毁；牌库不受战斗影响，无需归还操作。
```

- 牌库在战斗中**不参与任何结算**，任何卡牌效果都不能改变牌库内容；影响牌库的操作（获得/移除/升级卡牌）只发生在局外（见 [05·牌库系统](./05-Meta系统.md#2-牌库系统)）。
- 弃牌堆洗回抽牌堆属于战斗牌区内部的循环，**不是**"移出桌面"，不触发`[离场]`等任何词条。
- 战斗结束后消耗堆/被移除的牌随战斗牌区一起销毁——消耗/移除只在单场战斗内生效，牌库中对应的牌仍在，下一场战斗重新以牌库生成抽牌堆。

### 9.3 记忆堆（记录规则）

记忆堆是**记录型牌区**：只按顺序记录"哪些牌触发过效果"，不存放牌本体。

1. **记录时机**：每当一张牌触发效果，该牌记入记忆堆**末尾**。触发效果的途径为——
   - 配对结算触发**基础效果**；
   - `[隐秘]`牌被丢弃（背面移出桌面）时触发**基础效果**；
   - 触发型词条 `[入场]` / `[翻开]` / `[翻回]` / `[丢弃]` / `[离场]` 触发；
   - 能力牌**持续效果**触发（翻开时）。
2. **可重复入堆**：同一张牌每次触发都记一条（如先触发`[翻开]`、后被配对触发`[离场]`，则为两条）。
3. **牌本体不移动**：记录行为不改变牌所在的实体牌区，不影响任何结算，也不触发任何词条（记录本身不再产生记录）。
4. **生命周期**：战斗开始时为空；战斗结束清空。
5. **查看**：属于 [§3.2 查看](#32-玩家可用操作)操作，随时可看，不触发结算。

> 记忆堆是战斗的"经历回放"：按触发顺序查看本场战斗发生过的效果。它也是后续效果引用的锚点（如"记忆堆顶的牌""记忆堆中同名牌数"类词条可基于此设计）。

### 9.4 抽牌堆耗尽循环

- 当抽牌堆抽空时，弃牌堆的所有牌重新洗回抽牌堆。
- 消耗堆的牌**不参与**重新洗牌（它们在本场战斗内永久消耗）；带`[移除]`词条的牌已移出游戏，同样不回流。

> 注意：战斗结束后所有战斗牌区销毁，牌库不受战斗影响（包括消耗堆/被移除的牌——牌库中它们依然存在），供下一场战斗重新生成抽牌堆。详见 [Meta系统·牌库系统](./05-Meta系统.md#2-牌库系统)。

---

## 10. 战斗结束

- **胜利**：敌人血量归零（任意结算节点触发，见 [中断规则](#34-中断规则死亡即停)）。结算奖励（卡牌/金币/遗物）。
- **失败**：玩家血量归零。Run 结束。
- **牌区收尾**：无论胜负，五个战斗牌区（抽牌堆/桌面/弃牌堆/消耗堆/记忆堆）全部销毁；牌库不受战斗影响（见 [§9 牌区系统](#9-牌区系统)）。

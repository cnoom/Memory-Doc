## 1. 战斗目标

- **胜利条件**：敌人血量归零。
- **失败条件**：玩家血量归零。

---

## 2. 玩家资源

| 资源 | 说明 |
|---|---|
| **血量（HP）** | 持久资源，跨战斗保留（run内）。归零 = 游戏结束。 |
| **格挡（Block）** | 临时防御资源，抵消受到的伤害。每次受击时优先消耗格挡。格挡在每个回合结束时清零（敌人行动后残余格挡消失），不跨回合保留。 |

---

## 3. 翻牌与匹配流程（精确规则）

战斗桌面为 **4×4 网格（16 格）**，每格放一张卡牌。初始所有牌背面朝上。玩家通过"翻牌"行动来触发效果和配对。

**网格与相邻定义：**
- 桌面是 4×4 的方格阵列，每张牌占据一个格子，有明确的行列位置。
- **相邻** = 以某格为中心的 **8 格范围**（上、下、左、右 + 四个对角线方向）。边缘和角落的格相邻格数较少（角落3格，边缘5格，中央8格）。
- 卡牌效果中的"相邻""周围"均以此定义为准。

**核心约束：默认任意时刻桌面上最多一张正面朝上的牌（正面牌上限=1）。**

> 正面牌上限可通过角色被动（如术士被动）或卡牌效果（如能力牌「百科全书」）提升。上限提升时的翻牌流程遵循"挤掉最早"规则（见步骤1）。

> 注：以下"揭示"和"标记"机制不改变牌的物理状态（不翻面），不触发`[翻开]`效果，不推进行动条。

**翻开 vs 揭示 vs 标记（三个不同操作）：**

| 操作 | 定义 | 是否改变牌状态 | 是否触发`[翻开]`效果 | 是否推进行动条 |
|---|---|---|---|---|
| **翻开（Flip）** | 玩家主动点击背面牌，使其正面朝上 | 是（背面→正面） | 是 | 是（+1，结算后） |
| **揭示（Reveal）** | 显示一张背面牌的内容一定时间，时间到后内容隐藏，牌仍保持背面 | 否（保持背面） | 否 | 否 |
| **标记（Mark）** | 持久显示一张背面牌的内容，即使被翻过再翻回仍可见，直至其被配对消除 | 否（保持背面） | 否 | 否 |

**锁定（Lock）：**

锁定是一种桌面操控机制。被锁定的正面牌在下次翻牌操作时不翻回背面，保持正面朝上，直至被配对消除或本批结束。锁定不改变牌的物理状态以外的任何属性。

### 翻牌操作的分步结算

```
玩家点击一张背面牌翻开
│
├─ 步骤1: 若桌面上正面牌数已达上限（默认1），将其中"最早翻开的
│         正面牌"翻回背面；若未达上限，则不翻回任何牌
│         （挤掉规则：上限为N时，桌面保持最多N张正面牌，新翻的牌
│          挤掉最早的一张并与之判定匹配。被锁定的牌不参与挤掉——
│          跳过它选择次早的正面牌。锁定牌可与上限内的牌共存）
│
├─ 步骤2: 这张牌正面朝上
│
├─ 步骤3: 结算这张牌的 [翻开] 触发型词条效果
│
├─ 步骤4: 能力牌特殊处理
│         若这张牌是能力牌，默认翻开即消除：
│         ├─ 触发 [消除] 效果 → 进入弃牌堆
│         └─ 跳过步骤5、6，直接到步骤7（能力牌不参与匹配）
│         （非能力牌继续步骤5）
│
├─ 步骤5: 匹配判定
│         若步骤1翻回了牌（正面牌已达上限），检查这张牌与刚翻回的
│         那张牌是否存在匹配关系
│         ├─ 匹配成功 → 进入步骤6
│         └─ 不匹配 → 这张牌保持正面朝上（等待下一次翻牌判定）
│         （若步骤1未翻回任何牌——上限未满——则不进行匹配判定，
│          这张牌直接保持正面朝上，与已有正面牌共存）
│
├─ 步骤6: 匹配结算（若匹配成功）
│         ├─ 触发两张牌各自的基础效果
│         ├─ 两张牌从桌面消除
│         └─ 触发两张牌的 [消除] 效果
│
└─ 步骤7: 行动条 +1（所有效果结算完毕后的最后一步）
```

**关键规则：**
- 行动条 +1 永远是最后一步，发生在所有卡牌效果结算之后。
- 这意味着"行动条 -X"的卡牌效果先结算，再执行 +1，为操控行动条提供了设计空间。
- 病毒牌不是特殊类别，它就是普通卡牌通过触发型词条组合实现的——`[翻开]: 造成负面效果` + `[翻开]: 移除自身`。

### 翻牌流程示例

1. 玩家翻开第一张牌（A）→ A 正面朝上，A 的 `[翻开]` 效果触发，行动条 +1。
2. 玩家翻开第二张牌（B）→ A 翻回背面，B 正面朝上，B 的 `[翻开]` 效果触发。
3. 匹配判定：B 与 A 是否匹配？
   - **匹配** → 结算基础效果，两牌消除并触发 `[消除]` 效果，行动条 +1。
   - **不匹配** → B 留在桌面正面。行动条 +1。
4. 玩家翻开第三张牌（C）→ B 翻回背面，C 正面朝上...（循环）

**上限提升时的流程示例（如术士被动：正面牌上限=2）：**

1. 翻开 A → 正面牌数 0→1（未达上限2），A 保持正面，**不进行匹配判定**，行动条 +1。
2. 翻开 B → 正面牌数 1→2（未达上限2），B 保持正面，**不进行匹配判定**，行动条 +1。
3. 翻开 C → 正面牌数已达上限2，挤掉**最早翻开**的 A，C 与 A 判定匹配：
   - **匹配** → 结算基础效果，C、A 消除，行动条 +1（B 仍在桌面正面）。
   - **不匹配** → C 保持正面，B、C 共存（上限2），行动条 +1。
4. 翻开 D → 挤掉当前最早翻开的 B，D 与 B 判定匹配...（循环，A 被挤掉后 B 成为"最早"）

## 4. 匹配规则

**默认匹配规则 = 同名匹配。**

两张卡牌**名称完全相同**才能匹配。这是绝大多数卡牌的匹配方式。

- 不存在相似卡名（如"火球术"和"大火球术"）。卡牌名称是唯一标识。
- 特殊匹配关系只能通过**匹配型词条**实现（见 [卡牌与词条系统](./02-卡牌与词条系统.md#③-匹配型词条修改匹配规则)）。

## 5. 行动条机制

```
行动条: 0 ──→ [阈值] ──→ 敌人行动 ──→ 重置为0
         翻牌+1
         重新铺满+2
```

- 行动条从 0 开始。
- **玩家每翻一张牌，行动条 +1**（在所有效果结算后）。
- **玩家主动"重新铺满桌面"，行动条 +2**。
- 行动条达到敌人阈值 → 敌人执行意图所示的行动 → 行动条重置为 0。
- **配对成功不影响行动条**。防御完全依赖卡牌效果。
- 某些卡牌效果可以减少行动条（如冰冻状态、特定词条）。

**回合概念：**
- 本游戏没有传统回合制（玩家行动→敌人行动的固定交替），但存在**以敌人行动为分隔的隐性回合**。
- **回合 = 敌人两次行动之间的间隔**（行动条从某次重置到下次填满）。
- 翻牌推进行动条，行动条满 → 敌人行动 → 当前回合结束，新回合开始。
- 部分卡牌效果使用"本回合""持续N回合"等表述时，以此定义为基准。
- **格挡在每个回合结束时清零**（敌人行动后，残余格挡消失）。

## 6. 批次补充规则

桌面牌从玩家牌组抽取。当桌面上牌被消耗后，按以下规则补充：

**补充触发条件：**
- 桌面上**可配对的牌对数 ≤ 1** 时，补充新一批。
- "可配对牌对数"指：桌面上存在的能互相匹配的牌对数量。
- 残留的未配对牌（无法互相匹配的单牌）不触发补充，它们留在原位。

**补充方式：**
- 残留的未配对牌**位置不变**（保持原网格位置）。
- 新牌从牌组抽取，铺到空出的格子中。
- 玩家之前翻过的残留牌，其位置和内容信息对玩家有效（凭记忆可利用）。

**批次的意义：**
- 每一批 = 一个小目标，"清掉这批所有配对"有清晰的成就感。
- 批次切换时记忆"归零重来"，但这是玩家主动完成带来的，挫败感低。
- 残留牌创造跨波次的记忆价值——下一批可能补上同名牌，凭记忆直接配对。

## 7. 重新铺满桌面（主动操作）

玩家随时可以选择"重新铺满桌面"，作为卡住时的紧急逃生手段。

**效果：**
- 当前桌面所有牌（包括残留牌）进入弃牌堆。
- 从牌组重新抽牌铺满桌面。

**代价：**
- 行动条 **+2**。

**用途：**
- 桌面残留牌无法配对且玩家记不住/找不到时，强行重置。
- 配合牌组循环（牌组耗尽 → 弃牌堆洗回），重新铺满 = 一次"洗牌重抽"。

---

## 8. 牌组循环

战斗中存在三个牌区：

| 牌区 | 说明 |
|---|---|
| **牌组（Deck）** | 未抽到桌面的牌，桌面补牌从此抽取。 |
| **桌面（Board）** | 当前铺开的牌（背面/正面朝上）。 |
| **弃牌堆（Discard）** | 被消除的牌、被"重新铺满"清除的牌。 |

**牌组耗尽规则：**
- 当牌组抽空时，弃牌堆的所有牌重新洗回牌组。
- 消耗堆的牌**不参与**重新洗牌（它们在本场战斗内永久消耗）。

> 注意：消耗堆只在单场战斗内生效。战斗结束后，所有牌（包括消耗堆）回到牌组，供下一场战斗使用。详见 [Meta系统·牌组系统](./05-Meta系统.md#2-牌组系统)。

---

## 9. 战斗结束

- **胜利**：敌人血量归零。结算奖励（卡牌/金币/遗物）。
- **失败**：玩家血量归零。Run 结束。

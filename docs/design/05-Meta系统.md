## 1. Run结构：节点地图

杀戮尖塔式分支地图：玩家从底部的**起点**出发，**自下而上**沿连线选择路径、逐节点推进，直至章节顶端的 Boss。

```
               [Boss]
              /      \
        [篝火]         [事件]
       /      \       /      \
  [战斗]──[事件]──[商店]──[战斗]──[篝火]
       \      /       \      /
        [战斗]         [事件]
              \      /
              [起点]
```

### 节点类型

| 节点 | 说明 |
|---|---|
| **战斗** | 普通战斗，胜利后获得奖励（卡牌/金币/遗物） |
| **精英** | 强敌，高风险高回报，必掉遗物 |
| **商店** | 花金币买卡牌、遗物、移除卡牌 |
| **篝火** | 回血 或 升级一张卡 |
| **事件** | 随机遭遇，做选择获得奖励或惩罚 |
| **Boss** | 章节最终Boss，必掉稀有遗物 |

### 章节结构

一层地图 = 一个章节，顶端是 Boss。默认设计为 **3 章**（约 30~40 场战斗），通关即胜利。

> **原型阶段实装注记（v1.32）**：009 起实装**第一章**——章末 Boss（记忆吞噬者）胜利即 **run 胜利**，暂代"第三章 Boss → S11 胜利界面"的最终胜利口；第二三章随敌组扩充另行启用（多章地图结构与章间衔接届时再定）。

### 节点投放结构

每章内容节点的类型分布采用**保底 + 加权随机**：

- **保底**：每章至少投放 商店 ×1、篝火 ×1、事件 ×2。
- **加权随机**：保底投放后的其余内容节点按权重抽取类型——战斗 70 / 商店 10 / 篝火 10 / 事件 10（权重为平衡参数，随调参调整）。
- 随机只决定类型落位，不改变连线结构；**同一章节种子生成结果完全一致**。
- **精英/Boss 投放（v1.32，不参与上述随机池）**：
  - **精英 ×1**：固定落在第 3 内容层的其中一个节点（类型升格，不改连线结构——与"随机只决类型不改连线"同哲学）。
  - **Boss**：固定为章顶节点（章节最顶端，承接所有上层出口）。
- **首战教学（v1.32）**：第一章**首个战斗节点固定为训练假人**（08§2.1 教学敌人）；其余战斗节点的普通敌人随机池**排除训练假人**。
- **敌人分池（v1.32）**：普通战斗节点从普通敌人池（08§2 六种，排除训练假人后五种）随机；精英节点从精英池（08§3 两种）随机；Boss 节点固定本章 Boss（第一章=记忆吞噬者）。

### 地图结构参数（v1.40）

原型阶段第一章的地图结构数值口径（此前 05§1/09§5.3/09§7.1 三张示意图层数不一致、未定义数值正本——2026-09-26 实现侧澄清，用户裁决）：

- **结构定值**：起点 ×1 → **内容层 ×4（每层 4 节点）** → 章顶 Boss ×1，共 18 节点（正本=09§5.3 章节示意图；05§1 与 09§7.1 的较小示意图为示意简图）。与「3 章约 30~40 场战斗」的每章体量吻合。
- **连线规则**：层间相邻互联——每个节点连向上一层**相邻的 1~3 个节点**（起点连第一层全部节点；Boss 承接最上层全部出口）；具体连线由章节种子决定，同种子完全复现；连线保证起点至 Boss 至少一条路径。

### run 存档写入时点（v1.40）

原型阶段 run 进度的持久化口径（2026-09-26 实现侧澄清，用户裁决）：

- **节点完成即存**：每次节点结算完成（战斗胜利返回地图 / Boss 三选一确认 / 非战斗节点完成）立即写盘；存档恢复点 = 最近节点完成态。
- **战斗中途退出回退重打**：战斗进行中（未结算）应用被关闭/崩溃，该战斗视为未发生——「继续游戏」恢复到进入该战斗节点之前的地图状态、该节点回到未访问，重打本节点（战斗内进度不持久化）。
- **终局清档**：run 胜利/失败结算离开、或经暂停菜单放弃 run 时删除存档（单 run 单档）。

## 2. 牌库系统

牌库（Library）是 run 级牌区：玩家在本 run 中收集的所有卡牌，**按单份记录**。它**不受战斗影响，仅用于玩家查看了解**；每场战斗开始时以牌库为源**每张 ×2** 洗牌复制生成抽牌堆（战斗牌组 = 牌库 × 2，牌区流转见 [核心战斗机制·牌区系统](./01-核心战斗机制.md#9-牌区系统)）。

### 牌库构成

- **初始牌库**：每个角色有固定初始牌库（共10张）= **通用基底8张**（全角色共享的打击×4、格挡×4）+ **角色专属2张**（互为一对，见 [角色系统](#3-角色系统)）。→ 首战抽牌堆 20 张（每张×2），恰好铺满 4×4 桌面。
- **run 中获取**：每次胜利后从3张随机卡牌中选1张加入牌库（事件/商店同样可添加）。**获取一律给 1 张**——牌库单张在战斗中即 ×2 为一对，无需成对给牌。
- **牌库是战斗牌的来源池**——战斗开始时由牌库每张×2 洗牌生成抽牌堆，桌面牌从抽牌堆铺出。

### 牌库与记忆策略的关系（核心设计）

这是记忆配对玩法和传统牌组构建的**核心差异点**：

> **牌库里同名牌的数量（战斗中 ×2），直接决定桌面配对的难易度。**

- 牌库里某张牌只有 1 份 → 战斗中 2 份，**恰为一对**：任何新获得的卡立刻具备完整配对价值，不会出现"落单无法同名配对"的废牌；但整场也只有这一对，是否抽上桌面仍看运气。
- 牌库里某张牌有 4 份 → 战斗中 8 份，桌面上容易出现多张同名，配对机会大，但记忆难度也大。
- 牌库牌种太多太杂 → 桌面全是不同名的牌，配对密度下降，几乎无法配对。

**这创造了独特的 deckbuilding 策略——控制牌库的"重复度"：**

| 流派 | 特点（库内份数 → 战斗份数） | 优劣 |
|---|---|---|
| **精简流** | 少量卡牌每种多份（3~4份 → 6~8份） | 桌面配对容易，但卡牌种类少、效果单一 |
| **多样性流** | 很多种卡牌各 1 份（→ 各 2 份） | 依赖跨名词条匹配，灵活但记忆负担重 |
| **均衡流** | 核心卡2~3份 + 功能卡1份（→ 4~6份 + 2份） | 平衡但需要精心构建 |

### 牌库操作行为

牌库只能在**局外**被改变（战斗中的任何结算都不影响牌库）：

| 行为 | 场景 | 说明 |
|---|---|---|
| **添加卡牌** | 战斗后 / 事件 / 商店 | 牌库增大 |
| **移除卡牌** | 商店 / 事件 | 牌库精简，提升配对稳定性 |
| **升级卡牌** | 篝火 | 提升单卡效果（不改变数量） |
| **复制卡牌** | 特殊事件 | 增加某卡重复度（强化配对） |

> 以上操作均以**库内单张**为单位：库内 ±1 张 = 战斗中 ±2 份。战斗份数恒为偶数（2/4/6/8…），除移除至 0 外任何状态下留存的牌都能同名成对。

### 升级数值规则（v1.41）

原型阶段"升级卡牌"的数值口径（此前 05§2/06 均无升级数值表——2026-09-26 实现侧澄清，用户裁决）：

- **通用规则**：升级 = 该卡**所有数值参数每处独立 +50% 向上取整（最低提升 1）**——6→9、8→12、3→5、2→3、1→2。数值参数覆盖伤害/格挡/治疗/状态层数/张数/回合数等一切可量化效果值。
- **升级单位与次数**：升级作用于**库内单张**（升级一张同名卡不影响其余张——战斗中该张 ×2 副本均生效）；单张至多升级一次、不可逆；复制产生的副本为未升级态（复制"卡牌"而非"升级态"）。
- **可升级范围**：无数值参数的纯功能卡不出现在升级候选列表。

### 桌面铺牌规则

- **铺满网格**：每场战斗桌面为 4×4 网格（16格）。战斗开始时以牌库为源每张×2 洗牌生成抽牌堆（战斗牌组 = 牌库 × 2），从抽牌堆随机抽牌铺满网格。
- 若战斗牌组不足 16 张（即牌库不足 8 张），则铺满所有可用牌，空余格子留空。标准初始牌库 10 张 → 战斗 20 张，**首战即满桌**。
- 记忆难度可控，玩家能形成稳定的记忆习惯（行列坐标辅助记忆）。
- 牌库大小的影响通过"哪些牌被抽到桌面"来体现，而非桌面规模。

### 战斗结束后的牌区处理

战斗中的一切变化只发生在五个战斗牌区（抽牌堆/桌面/弃牌堆/消耗堆/记忆堆）——它们是牌库的**战斗副本**：

| 牌区 | 战斗结束后 |
|---|---|
| 牌库 | **不受影响**（战斗以副本进行，无需归还） |
| 抽牌堆 / 桌面 / 弃牌堆 | 随战斗结束销毁 |
| **消耗堆** | 随战斗结束销毁（消耗只在单场战斗内生效，牌库中对应的牌仍在） |
| 记忆堆 | 随战斗结束清空 |

## 3. 角色系统

每个角色有差异化定位，影响被动能力和专属卡牌。**初始牌库大部分相同**（共享通用基底），角色差异由被动与2张专属卡承载。

### 角色一览

| 角色 | 定位 | 被动能力 | 详细设计 |
|---|---|---|---|
| **学者** | 情报型（新手友好） | **触类旁通**：获得卡牌时，25%概率为其附加`[共鸣]`词条 | [学者角色卡牌设计](./06-学者角色卡牌设计.md) |
| **狂战士** | 暴力输出型 | **狂怒**：每成功配对一次，本场战斗攻击牌配对伤害+1 | 待设计 |
| **术士** | 高风险高回报型（解锁角色） | **双面**：场上可同时翻开的牌数+1（正面牌上限提升至2） | 待设计 |

### 通用基底牌库

所有角色共享的初始牌库主体（8张）。基底牌**无词条、无职业机制**，强度对齐基准值（伤害/格挡基准均为6）——角色差异完全由被动与2张专属卡承载。

```

  ─────────────────────────────────────
  基础效果: 造成 6 点伤害
  词条: 无

  设计意图: 全角色共享的基础攻击牌。4份（战斗中8份）保证桌面配对率
           （同名匹配），是常规输出手段。
═══════════════════════════════════════

  格挡（通用基底）            [普通·技能] ×4
  ─────────────────────────────────────
  基础效果: 获得 6 点格挡
  词条: 无

  设计意图: 全角色共享的基础防御牌。4份（战斗中8份）保证配对率，
```

## 4. 遗物系统

遗物是**持久纯被动效果**，贯穿整个 run。遗物不包含任何主动使用的能力——玩家在战斗中的主动操作只有翻牌与重新铺满。针对记忆玩法特化。

### 遗物分类维度

| 维度 | 说明 |
|---|---|
| **记忆辅助** | 降低记忆难度，提供信息优势 |
| **桌面操控** | 改变翻牌/配对的基础规则 |
| **配对强化** | 提升配对收益或改变配对行为 |
| **防御续航** | 提升生存能力 |
| **行动条操控** | 影响敌人节奏 |
| **牌库操控** | 影响牌库构成或战斗内牌区（抽牌堆/弃牌堆等）流转 |

### 稀有度与获取

| 稀有度 | 获取途径 |
|---|---|
| **普通** | 普通战斗掉落（**10% 概率**，v1.32）、商店、事件 |
| **罕见** | 精英战斗掉落（**必掉**）、商店、事件 |
| **稀有** | 精英战斗低概率掉落（**25% 概率**——精英掉落先按罕见必掉结算，再 25% 升为稀有条目，对齐商店罕见位升稀概率）、商店高价 |
| **Boss** | Boss击杀后必掉（三选一），通常带显著代价或改变玩法的强力效果 |

> 全部遗物的具体设计（19件），见 [遗物设计](./07-遗物设计.md)。重复口径：**全部获取途径（商店/事件/掉落）候选一律排除已持有同款，不重复投放**（重复叠加不做）；事件"获得遗物"候选池尽时降级为金币 +20。
>
> **掉落细则（v1.32）**：掉落候选同商店/事件口径排除已持有；**Boss 三选一候选不足 3 件时剩几件展示几件，全持有（池尽）时降级为金币 +20**（对齐事件口径）。掉落概率与升稀概率为首批平衡基准，随跑数调整。

## 5. 金币系统

- 保留杀戮尖塔式金币系统。
- 战斗/事件获得金币。
- 商店消费金币购买卡牌、遗物、移除卡牌。

### 金币数值（首批平衡基准）

| 项 | 数值 |
|---|---|
| 初始金币 | 50 |
| 普通战斗胜利 | +15 |
| 精英战斗胜利 | +25（v1.32） |
| Boss 战斗胜利 | +50（v1.32） |
| 事件金币 | 随事件条目（§6，+15 ~ +30） |
| 商店卡牌定价 | 普通 45 / 罕见 60 / 稀有 75（货架每店 3 张 = 各稀有度 1 张） |
| 商店移除服务 | 75（固定价） |
| 商店遗物定价 | 普通 95 / 罕见 130 / 稀有 180 |
| 商店遗物货架 | 每店 2 件 = 普通 + 罕见各 1 保底（罕见位 25% 概率升为稀有） |

> 商店货架构成与定价（卡牌/遗物）为首批基准，随 08 平衡矩阵跑数调整。

### 商店货架生成语义（v1.41）

货架生成与刷新口径（此前 09§7.2 示意图注记"离开商店时自动刷新全部商品"、05 未述——2026-09-26 实现侧澄清，用户裁决）：

- **进店生成**：货架按**节点种子**在进入商店节点时确定性生成（卡牌 ×3 + 遗物 ×2 + 移除服务）——同种子完全复现，与地图生成/事件选取同哲学；存档回退重开同店货架一致。
- **不可重入**：商店节点完成即离开、不可重入——玩家无法通过反复进出刷新货架（原"离开时自动刷新"注记消化为**防刷语义**：离开后货架失效、无观察面；09§7.2 注记已同步改写）。
- 卡牌货架不排除已持有卡（重复购入是"重复度"流派的主动策略）；遗物货架候选排除已持有（§4 重复口径）。

## 6. 事件库

事件节点进入后随机遭遇一个事件，从选项中做出选择获得奖励或惩罚。

### 选取规则

- 事件由节点种子确定性选取；**同一 run 内已触发的事件不重复**（章内口径——换章清空已触发集合，见 §1 章间流转），池中全部触发过后重置再来。
- **池形态（混合池，v1.45）**：总池 E01~E20 共 20 条、Id 域 [1,20]；E01~E14 全章共享，E15~E17 仅二章「沉没书库」可选、E18~E20 仅三章「遗忘王座」可选（章专属标签）——各章实际可选池 = 共享条 + 本章专属条；「已触发不重复 / 池尽重置」在**本章可选池**口径上结算。
- 选项顺序即呈现顺序，不重排。
- 事件内涉及"随机卡牌 / 随机复制 / 随机移除"的目标同样由种子派生——同节点重开必复现。
- 效果边界：金币下限 0；血量下限 1（事件不致死）；获得卡牌一律 1 张（库内单份，战斗中 ×2——§2 口径）；复制/移除的随机目标为牌库中随机一张**非诅咒**卡；升级的随机目标为**可升级**的非诅咒卡（无数值卡不可升级——§2 口径），**无可升级目标时该选项无事发生**；移除诅咒无诅咒目标时该选项**整体无事发生、金币不扣**（定价语义=有目标才生效）。
- 每个事件至少含一个零惩罚的"离开"类选项。

### 事件效果原语

事件选项效果由以下原语组合：

| 原语 | 语义 |
|---|---|
| 获得随机卡牌 | 从奖励卡池随机 1 张加入牌库 |
| 获得诅咒牌 | 从诅咒牌池随机 1 张加入牌库（战斗中以 2 份出现，06§4） |
| 复制卡牌 | 牌库中随机 1 张非诅咒卡同名 +1 张 |
| 移除卡牌 | 牌库中随机 1 张非诅咒卡移除单份 |
| 金币增减 | 金币 ±N（下限 0） |
| 血量增减 | 血量 ±N（下限 1，事件不致死） |
| 获得遗物 | 随机（按稀有度域）或指定 1 件加入持有（候选排除已持有，§4 重复口径；池尽降级金币 +20） |
| 升级随机卡牌 | 牌库中随机 1 张**可升级**非诅咒卡升级（全数值每处独立 +50% 向上取整、单张至多一次——§2 篝火同口径；无可升级目标→无事发生）（v1.45 新增） |
| 移除随机诅咒 | 牌库中随机 1 张诅咒牌移除（净化；无诅咒目标→整体无事发生、金币不扣）（v1.45 新增） |
| 无事发生 | 零效果（离开类） |

## 1. Run结构：节点地图

杀戮尖塔式分支地图。玩家在地图上选择路径，逐节点推进。

```
        [战斗]         [精英]
       /      \       /      \
  [战斗]──[事件]──[商店]──[战斗]──[篝火]
       \      /       \      /
        [商店]         [事件]
              \        /
              [Boss]
```

### 节点类型

| 节点 | 说明 |
|---|---|
| **战斗** | 普通战斗，胜利后获得奖励（卡牌/金币/遗物） |
| **精英** | 强敌，高风险高回报，必掉遗物 |
| **商店** | 花金币买卡牌、遗物、移除卡牌 |
| **篝火** | 回血 或 升级一张卡 |
| **事件** | 随机遭遇，做选择获得奖励或惩罚 |
| **Boss** | 章节最终Boss，必掉稀有遗物 |

### 章节结构

一层地图 = 一个章节，末尾是 Boss。默认设计为 **3 章**（约 30~40 场战斗），通关即胜利。

## 2. 牌组系统

### 牌组构成

- **起始牌组**：每个角色有固定初始牌组（约10张）。
- **战斗中获取**：每次胜利后从3张随机卡牌中选1张加入牌组。
- **牌组是桌面牌的来源池**——战斗时从牌组抽牌铺桌面。

### 牌组与记忆策略的关系（核心设计）

这是记忆配对玩法和传统牌组构建的**核心差异点**：

> **牌组里同名牌的数量，直接决定桌面配对的难易度。**

- 牌组里某张牌只有1份 → 它上桌面时很难找到同名搭子，只能靠特殊词条跨名匹配，否则无法触发效果。
- 牌组里某张牌有4份 → 桌面上容易出现多张同名，配对机会大，但记忆难度也大。
- 牌组牌种太多太杂 → 桌面全是不同名的牌，几乎无法配对。

**这创造了独特的 deckbuilding 策略——控制牌组的"重复度"：**

| 流派 | 特点 | 优劣 |
|---|---|---|
| **精简流** | 少量卡牌每种多份 | 桌面配对容易，但卡牌种类少、效果单一 |
| **多样性流** | 很多种卡牌各1~2份 | 依赖跨名词条匹配，灵活但记忆负担重 |
| **均衡流** | 核心卡3~4份 + 功能卡1~2份 | 平衡但需要精心构建 |

### 牌组操作行为

| 行为 | 场景 | 说明 |
|---|---|---|
| **添加卡牌** | 战斗后 / 事件 / 商店 | 牌组增大 |
| **移除卡牌** | 商店 / 事件 | 牌组精简，提升配对稳定性 |
| **升级卡牌** | 篝火 | 提升单卡效果（不改变数量） |
| **复制卡牌** | 特殊事件 | 增加某卡重复度（强化配对） |

### 桌面铺牌规则

- **铺满网格**：每场战斗桌面为 4×4 网格（16格），从牌组随机抽牌铺满网格。
- 若牌组不足 16 张，则铺满所有可用牌，空余格子留空。
- 记忆难度可控，玩家能形成稳定的记忆习惯（行列坐标辅助记忆）。
- 牌组大小的影响通过"哪些牌被抽到桌面"来体现，而非桌面规模。

### 战斗结束后的牌区处理

| 牌区 | 战斗结束后 |
|---|---|
| 牌组 | 保留 |
| 弃牌堆 | 回到牌组 |
| **消耗堆** | **回到牌组**（消耗只在单场战斗内生效） |

## 3. 角色系统

每个角色有差异化定位，影响初始牌组和被动能力。

### 角色一览

| 角色 | 定位 | 被动能力 | 详细设计 |
|---|---|---|---|
| **学者** | 情报型（新手友好） | 游戏开始时查看牌组顺序前5张 | [学者角色卡牌设计](./06-学者角色卡牌设计.md) |
| **狂战士** | 暴力输出型 | 血量越低，翻牌触发的伤害效果越强 | 待设计 |
| **术士** | 高风险高回报型（解锁角色） | 可消耗自身血量来"锁定"一张桌面牌保持翻开 | 待设计 |

### 角色设计草案

```
═══════════════════════════════════════
  角色一：学者
  ─────────────────────────────────────
  被动: 游戏开始时查看牌组顺序前5张
  
  初始牌组: 以含`[翻开]`信息获取效果的技能牌为主，
           擅长降低记忆压力
  
  定位: 新手友好，通过"看牌"能力弥补记忆不足
═══════════════════════════════════════

  角色二：狂战士
  ─────────────────────────────────────
  被动: 血量越低，翻牌触发的伤害效果越强
  
  初始牌组: 以攻击牌为主，效果直接，
           牌组重复度高（易配对），但效果单一
  
  定位: 暴力输出，血量管理是策略核心
═══════════════════════════════════════

  角色三：术士（解锁角色）
  ─────────────────────────────────────
  被动: 可消耗自身血量来"锁定"一张桌面牌保持翻开
  
  初始牌组: 以匹配型词条（跨名匹配）和`[消耗]`效果型
           词条为主，高风险高回报
  
  定位: 进阶角色，主动操控桌面信息
═══════════════════════════════════════
```

## 4. 遗物系统

遗物是**持久纯被动效果**，贯穿整个 run。遗物不包含任何主动使用的能力——主动效果属于道具（见第5节）。针对记忆玩法特化。

### 遗物分类维度

| 维度 | 说明 |
|---|---|
| **记忆辅助** | 降低记忆难度，提供信息优势 |
| **桌面操控** | 改变翻牌/配对的基础规则 |
| **配对强化** | 提升配对收益或改变配对行为 |
| **防御续航** | 提升生存能力 |
| **行动条操控** | 影响敌人节奏 |
| **牌组操控** | 影响牌组构成或抽取 |

### 稀有度与获取

| 稀有度 | 获取途径 |
|---|---|
| **普通** | 普通战斗掉落、商店、事件 |
| **罕见** | 精英战斗掉落、商店、事件 |
| **稀有** | 精英战斗低概率掉落、商店高价 |
| **Boss** | Boss击杀后必掉（三选一），通常带显著代价或改变玩法的强力效果 |

> 全部遗物的具体设计（20件），见 [遗物与道具设计](./07-遗物与道具设计.md)。

## 5. 道具系统

道具是**主动使用的消耗品**，使用后消失（类似杀戮尖塔的药水）。与遗物的区别：

| | 遗物 | 道具 |
|---|---|---|
| 效果类型 | 纯被动 | 主动使用 |
| 持续性 | 永久（整run） | 一次性（用完消失） |
| 携带上限 | 无限制 | 3个槽位 |

道具提供玩家**主动选择时机的紧急手段**——在关键时刻扭转战局。

> 全部道具的具体设计（8种），见 [遗物与道具设计·道具系统](./07-遗物与道具设计.md#6-道具系统药水消耗品)。

## 6. 金币系统

- 保留杀戮尖塔式金币系统。
- 战斗/事件获得金币。
- 商店消费金币购买卡牌、遗物、移除卡牌。

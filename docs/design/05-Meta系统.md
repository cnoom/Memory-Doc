## 1. Run结构：节点地图

杀戮尖塔式分支地图。玩家在地图上选择路径，逐节点推进。

```
        [战斗]         [精英]
       /      \       /      \
  [战斗]──[事件]──[商店]──[战斗]──[篝火]
       \      /       \      /
        [商店]         [事件]
              \        /
              [Boss]
```

### 节点类型

| 节点 | 说明 |
|---|---|
| **战斗** | 普通战斗，胜利后获得奖励（卡牌/金币/遗物） |
| **精英** | 强敌，高风险高回报，必掉遗物 |
| **商店** | 花金币买卡牌、遗物、移除卡牌 |
| **篝火** | 回血 或 升级一张卡 |
| **事件** | 随机遭遇，做选择获得奖励或惩罚 |
| **Boss** | 章节最终Boss，必掉稀有遗物 |

### 章节结构

一层地图 = 一个章节，末尾是 Boss。默认设计为 **3 章**（约 30~40 场战斗），通关即胜利。

## 2. 牌组系统

### 牌组构成

- **起始牌组**：每个角色有固定初始牌组（共10张）= **通用基底8张**（全角色共享的打击×4、格挡×4）+ **角色专属2张**（互为一对，见 [角色系统](#3-角色系统)）。
- **战斗中获取**：每次胜利后从3张随机卡牌中选1张加入牌组。
- **牌组是桌面牌的来源池**——战斗时从牌组抽牌铺桌面。

### 牌组与记忆策略的关系（核心设计）

这是记忆配对玩法和传统牌组构建的**核心差异点**：

> **牌组里同名牌的数量，直接决定桌面配对的难易度。**

- 牌组里某张牌只有1份 → 它上桌面时很难找到同名搭子，只能靠特殊词条跨名匹配，否则无法触发效果。
- 牌组里某张牌有4份 → 桌面上容易出现多张同名，配对机会大，但记忆难度也大。
- 牌组牌种太多太杂 → 桌面全是不同名的牌，几乎无法配对。

**这创造了独特的 deckbuilding 策略——控制牌组的"重复度"：**

| 流派 | 特点 | 优劣 |
|---|---|---|
| **精简流** | 少量卡牌每种多份 | 桌面配对容易，但卡牌种类少、效果单一 |
| **多样性流** | 很多种卡牌各1~2份 | 依赖跨名词条匹配，灵活但记忆负担重 |
| **均衡流** | 核心卡3~4份 + 功能卡1~2份 | 平衡但需要精心构建 |

### 牌组操作行为

| 行为 | 场景 | 说明 |
|---|---|---|
| **添加卡牌** | 战斗后 / 事件 / 商店 | 牌组增大 |
| **移除卡牌** | 商店 / 事件 | 牌组精简，提升配对稳定性 |
| **升级卡牌** | 篝火 | 提升单卡效果（不改变数量） |
| **复制卡牌** | 特殊事件 | 增加某卡重复度（强化配对） |

### 桌面铺牌规则

- **铺满网格**：每场战斗桌面为 4×4 网格（16格），从牌组随机抽牌铺满网格。
- 若牌组不足 16 张，则铺满所有可用牌，空余格子留空。
- 记忆难度可控，玩家能形成稳定的记忆习惯（行列坐标辅助记忆）。
- 牌组大小的影响通过"哪些牌被抽到桌面"来体现，而非桌面规模。

### 战斗结束后的牌区处理

| 牌区 | 战斗结束后 |
|---|---|
| 牌组 | 保留 |
| 弃牌堆 | 回到牌组 |
| **消耗堆** | **回到牌组**（消耗只在单场战斗内生效） |

## 3. 角色系统

每个角色有差异化定位，影响被动能力和专属卡牌。**初始牌组大部分相同**（共享通用基底），角色差异由被动与2张专属卡承载。

### 角色一览

| 角色 | 定位 | 被动能力 | 详细设计 |
|---|---|---|---|
| **学者** | 情报型（新手友好） | **触类旁通**：获得卡牌时，25%概率为其附加`[共鸣]`词条 | [学者角色卡牌设计](./06-学者角色卡牌设计.md) |
| **狂战士** | 暴力输出型 | **狂怒**：每成功配对一次，本场战斗攻击牌配对伤害+1 | 待设计 |
| **术士** | 高风险高回报型（解锁角色） | **双面**：场上可同时翻开的牌数+1（正面牌上限提升至2） | 待设计 |

### 通用基底牌组

所有角色共享的初始牌组主体（8张）。基底牌**无词条、无职业机制**，强度对齐基准值（伤害/格挡基准均为6）——角色差异完全由被动与2张专属卡承载。

```
═══════════════════════════════════════
  打击（通用基底）            [普通·攻击] ×4
  ─────────────────────────────────────
  基础效果: 造成 6 点伤害
  词条: 无

  设计意图: 全角色共享的基础攻击牌。4份保证桌面配对率
           （同名匹配），是常规输出手段。
═══════════════════════════════════════

  格挡（通用基底）            [普通·技能] ×4
  ─────────────────────────────────────
  基础效果: 获得 6 点格挡
  词条: 无

  设计意图: 全角色共享的基础防御牌。4份保证配对率，
           每回合约抵消一次普通攻击（6~10伤害基准）。
═══════════════════════════════════════
```

> 基底牌可被奖励卡逐步替换——它们与杀戮尖塔的"打击/防御"定位相同，是构筑的起点而非终点。

### 角色设计草案

```
═══════════════════════════════════════
  角色一：学者（情报型·新手友好）
  ─────────────────────────────────────
  被动「触类旁通」: 玩家每获得一张卡牌（战斗奖励/事件/商店等
       主动获得途径），有 25% 概率为其附加 [共鸣] 匹配型词条
       （可与任意其他[共鸣]牌匹配；已带[共鸣]的牌不重复附加）
  
  专属卡（互为一对）:
       笔记 ×1       [攻击] 造成6点伤害，[笔记]
       读书笔记 ×1   [攻击] 造成8点伤害，
                     [翻开]: 标记相邻1张背面牌，[笔记]
  
  定位: 把"获得的知识"变成"可联系的网络"——构筑越久，
       牌组中[共鸣]家族越大，跨名匹配越灵活
═══════════════════════════════════════

  角色二：狂战士（暴力输出型）
  ─────────────────────────────────────
  被动「狂怒」: 每成功配对一次，获得1层狂怒
       （每层狂怒使你的攻击牌配对时造成的伤害+1；
        本场战斗内累计，战斗结束清零）
  
  专属卡（互为一对）:
       重击 ×1       [攻击] 造成8点伤害，[怒火]
       猛击 ×1       [攻击] 造成6点伤害，
                     [翻开]: 造成2点伤害，[怒火]
  
  定位: 配对越多越猛——把"配对频率"直接转化为输出成长，
       开局平稳，中后期越打越痛
═══════════════════════════════════════

  角色三：术士（高风险高回报·解锁角色）
  ─────────────────────────────────────
  被动「双面」: 场上可同时翻开的牌数+1
       （正面牌上限从1提升至2；翻牌"挤掉最早"规则见
        [核心战斗机制](./01-核心战斗机制.md#3-翻牌与匹配流程精确规则)）
  
  专属卡（互为一对）:
       血刃 ×1       [攻击] 造成9点伤害，
                     [翻开]: 失去2点生命，[血契]
       血障 ×1       [技能] 获得7点格挡，
                     [翻开]: 失去2点生命，[血契]
  
  定位: 用生命换取信息优势与强度——被动给"同时看两张牌"的
       信息宽松，专属卡翻开必付血，血量成为核心资源
═══════════════════════════════════════
```

## 4. 遗物系统

遗物是**持久纯被动效果**，贯穿整个 run。遗物不包含任何主动使用的能力——主动效果属于道具（见第5节）。针对记忆玩法特化。

### 遗物分类维度

| 维度 | 说明 |
|---|---|
| **记忆辅助** | 降低记忆难度，提供信息优势 |
| **桌面操控** | 改变翻牌/配对的基础规则 |
| **配对强化** | 提升配对收益或改变配对行为 |
| **防御续航** | 提升生存能力 |
| **行动条操控** | 影响敌人节奏 |
| **牌组操控** | 影响牌组构成或抽取 |

### 稀有度与获取

| 稀有度 | 获取途径 |
|---|---|
| **普通** | 普通战斗掉落、商店、事件 |
| **罕见** | 精英战斗掉落、商店、事件 |
| **稀有** | 精英战斗低概率掉落、商店高价 |
| **Boss** | Boss击杀后必掉（三选一），通常带显著代价或改变玩法的强力效果 |

> 全部遗物的具体设计（20件），见 [遗物与道具设计](./07-遗物与道具设计.md)。

## 5. 道具系统

道具是**主动使用的消耗品**，使用后消失（类似杀戮尖塔的药水）。与遗物的区别：

| | 遗物 | 道具 |
|---|---|---|
| 效果类型 | 纯被动 | 主动使用 |
| 持续性 | 永久（整run） | 一次性（用完消失） |
| 携带上限 | 无限制 | 3个槽位 |

道具提供玩家**主动选择时机的紧急手段**——在关键时刻扭转战局。

> 全部道具的具体设计（8种），见 [遗物与道具设计·道具系统](./07-遗物与道具设计.md#6-道具系统药水消耗品)。

## 6. 金币系统

- 保留杀戮尖塔式金币系统。
- 战斗/事件获得金币。
- 商店消费金币购买卡牌、遗物、移除卡牌。

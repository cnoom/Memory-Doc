# 状态效果系统

> **关联文档**：[卡牌与词条系统](./02-卡牌与词条系统.md)、[敌人系统](./04-敌人系统.md)

---

## 状态效果一览

战斗中存在持续性的状态效果，影响敌人和玩家。状态效果是卡牌策略的延伸。

| 状态 | 效果 | 来源 |
|---|---|---|
| **灼烧** | 每次行动条数值变化（增长或减少）时受到X点伤害，层数-1 | 火焰系卡牌/词条 |
| **冰冻** | 下次行动条增长-1（翻牌+1→+0），结算后层数-1 | 寒冰系卡牌/词条 |
| **中毒** | 每次行动条满时按层数受到伤害（每层1点），层数不衰减 | 毒系卡牌/词条 |
| **护甲** | 抵消下次受到的X点伤害 | 护盾系卡牌/词条 |
| **易伤** | 受到伤害+50%，持续N回合 | 特定卡牌 |
| **虚弱** | 敌人攻击伤害-25%，持续N回合 | 特定卡牌 |

> 灼烧与冰冻采用**层数制**：效果每触发一次，层数-1；层数归零时状态消失。**中毒**同为层数制，但层数不随触发衰减——每次行动条满时按层数结算伤害（每层1点），层数只增不减。
>
> 注：上表中"火焰系"、"寒冰系"、"毒系"为**示例性的设计方向**，具体由哪些卡牌/词条施加这些状态，在卡牌内容设计阶段确定。状态效果系统是框架，不绑定特定词条。

---

## 状态结算时机

状态效果**没有统一的结算时点**（不存在"敌人行动后统一结算"），各自绑定自己的触发时机（完整流程定义见 [核心战斗机制·战斗流程总览](./01-核心战斗机制.md#3-战斗流程总览)）：

| 状态 | 触发时机 | 结算位置 |
|---|---|---|
| **灼烧** | 每次行动条数值变化后（翻牌+1、重新铺满+2、效果增减行动条） | 翻牌结算链步骤8；重新铺满结算链对应步骤 |
| **冰冻** | 每次行动条增长时（使该次增长-1） | 同灼烧 |
| **中毒** | 每次行动条满时 | 敌人行动之前 |
| **护甲** | 受到伤害时 | 伤害结算内 |
| **易伤** | 受到伤害时（伤害+50%） | 伤害结算内 |
| **虚弱** | 敌人攻击时（攻击伤害-25%） | 敌人伤害结算内 |

- **行动条的减少同样是"行动条数值变化"**：效果使行动条 -X 时，同样触发灼烧/冰冻结算。
- 任何状态结算导致一方血量归零时，适用 [中断规则（死亡即停）](./01-核心战斗机制.md#34-中断规则死亡即停)。

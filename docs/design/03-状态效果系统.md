## 状态效果一览

战斗中存在持续性的状态效果，影响敌人和玩家。状态效果是卡牌策略的延伸。

| 状态 | 效果 | 来源 |
|---|---|---|
| **灼烧** | 每次行动条数值变化（增长或减少）时受到X点伤害，层数-1 | 火焰系卡牌/词条 |
| **冰冻** | 下次行动条增长-1（翻牌+1→+0），结算后层数-1 | 寒冰系卡牌/词条 |
| **中毒** | 每次行动条满时按层数受到伤害（每层1点），层数不衰减 | 毒系卡牌/词条 |
| **护甲** | 抵消下次受到的X点伤害 | 护盾系卡牌/词条 |
| **易伤** | 受到伤害+50%，持续N回合 | 特定卡牌 |
| **虚弱** | 敌人攻击伤害-25%，持续N回合 | 特定卡牌 |

> 灼烧与冰冻采用**层数制**：效果每触发一次，层数-1；层数归零时状态消失。**中毒**同为层数制，但层数不随触发衰减——每次行动条满时按层数结算伤害（每层1点），层数只增不减。
>
> 注：上表中"火焰系"、"寒冰系"、"毒系"为**示例性的设计方向**，具体由哪些卡牌/词条施加这些状态，在卡牌内容设计阶段确定。状态效果系统是框架，不绑定特定词条。

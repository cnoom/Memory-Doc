# 战斗时序与护甲

适用版本 V7.2。本页定义战斗回合、防御结算和触发窗口。Unity 的实施与验收状态见实现仓对应 PR。

## 1. 战斗与回合流程

| 阶段 | 结算顺序 |
|---|---|
| 战斗开始 `BattleStart` | 初始化牌桌、双方角色、状态、遗物和计数器，结算明确的开场效果，再进入第 1 个玩家回合。入场预览不触发真实翻开。 |
| 玩家回合开始 `PlayerTurnStart` | 重置适用的回合限次。先处理并排空明确改变玩家护甲的回合初效果，再根据此时的护甲产盾一次。之后兑现上一敌人回合挂起的格挡以及其他回合初格挡，结算相关监听后开放操作。 |
| 玩家操作与行动条 `PlayerAction` / `ActionBarAdvance` | 玩家可以进行多次合法翻牌、同名配对、移动或重铺。每次操作先结算完整的卡牌、移动和离场链，再按该操作规则推进敌人行动条并结算行动条变化。最终检查仍达阈值才锁定回合切换。 |
| 玩家回合末 `PlayerTurnEnding` | 排空回合末效果并处理对应状态时钟。判定敌方旧格挡的明确保留资格，清理未保留的敌方格挡后结束玩家回合。已确定的切换不会因回合末行动条变化而撤回。 |
| 敌人回合开始 `EnemyTurnStart` | 重置适用的敌人回合限次。先处理明确改变敌方护甲的回合初效果，再根据此时的护甲产盾一次，之后处理其他敌方回合初效果。 |
| 敌人行动 `EnemyAction` | 完整执行一次意图。一次多段攻击、非攻击意图或位移意图都属于同一个敌人回合。多段攻击逐段结算。 |
| 敌人行动后 `EnemyActionResolved` | 对本次满行动条引发的敌人回合，结算一次定时中毒，随后按各自顺序完成行动后被动、遗物和追加效果。B02 的合法自动交换在进入敌人回合末前完成。 |
| 敌人回合末与收尾 `EnemyTurnEnding` / `EnemyTurnCleanup` | 排空回合末效果并处理对应状态时钟。判定玩家旧格挡的明确保留资格，清理未保留的玩家格挡，重置敌人行动条。收尾全部完成后结束敌人回合，进入下一玩家回合。 |

行动条达到阈值只会在当前操作完整结束后切换。若配对的第二张实例还在结算、玩家仍需选择合法移动方向，或行动条变化效果尚未处理完，继续完成该操作再检查最终阈值。未满条时继续同一个玩家回合。

任一阶段确定胜负后立即结束战斗，未执行的剩余伤害段、后续效果与回合阶段不再补跑。回合末效果也可能在下一方回合开始前结束战斗。

## 2. 双方护甲与格挡

**护甲**是战斗内持续的防御层数。每方在自身回合开始时，按当时的护甲获得一次等量格挡。普通伤害不会减少护甲层数。**格挡**是可被伤害消耗的临时防御值，伤害先扣目标的格挡，余量再扣生命。状态伤害也经过格挡和生命，但伤害金额仅按该状态自身规则计算。

| 一方 | 护甲产盾 | 旧格挡清理 |
|---|---|---|
| 玩家 | 玩家回合开始 | 敌人回合末，先判定保留，再清除未保留的部分 |
| 敌人 | 敌人回合开始 | 玩家回合末，先判定保留，再清除未保留的部分 |

- **首轮**：战斗从玩家回合开始，玩家的初始护甲立即按正常回合初规则产盾。敌方初始护甲等到第 1 个敌人回合开始才产盾。若需要敌人在开场就有格挡，由独立的开场格挡配置或效果提供。
- **产盾时点**：到达产盾节点才读取本方护甲。之后发生的护甲变化，包括产盾所触发的监听再次加甲，都等到该方下一次回合开始才影响产盾。卡牌另行写明立即获得格挡时，直接结算该项格挡。
- **保留与延后**：回合末先结算效果，再对本次应清理的一方判断旧格挡保留。敌人回合中明确供下一玩家回合使用的格挡只记录待发放量，下一玩家回合初在护甲产盾后兑现。敌人回合末直接给玩家的格挡按旧格挡参与当次清理，除非效果明确指定延后。
- **配对快照**：配对前冻结以敌方护甲或格挡为条件的资格。第一张实例打掉敌人格挡后，第二张仍读取配对前的资格，实际伤害逐包扣除结算当时的剩余格挡。

## 3. 触发窗口

| 窗口 | 重置与截止 |
|---|---|
| 玩家回合 | 玩家回合开始重置限次，触发归属当前玩家回合。 |
| 敌人回合 | 敌人回合开始重置限次，触发归属当前敌人回合。 |
| 玩家回合及紧接的敌人回合 | 玩家回合开始重置，在同一玩家回合及其触发的紧接敌人回合中有效，截止于该敌人回合收尾完成。 |

卡牌、状态和遗物的文案写明具体的回合归属。定时中毒在对应敌人行动完成后每回合最多触发一次，按当前层数造成状态伤害，定时结算本身不扣减中毒层。易伤在目标的对手回合末递减，虚弱在持有者自身回合末递减，独立施加批次按各自首次可递减的回合处理。

## 4. 验收示例

| 场景 | 预期 |
|---|---|
| 开场玩家 3 护甲、敌人 2 护甲，双方无额外开场格挡 | 第 1 玩家回合开始后，玩家有 3 格挡，敌人仍为 0。第 1 敌人回合开始时，敌人获得 2 格挡。 |
| 玩家回合内连续翻牌，未填满行动条 | 玩家回合序号不变，护甲只在回合初产盾一次。 |
| 玩家在当前回合产盾后获得 2 护甲 | 当下没有额外的护甲产盾，下一玩家回合按总护甲产盾。 |
| 玩家回合末、敌人回合末分别仍有双方格挡 | 玩家回合末只清理敌方旧盾，敌人回合末只清理玩家旧盾。明确保留的部分继续有效。 |
| 敌人回合末玩家由 R16 保留 3 格挡，并挂起 2 格挡；下一回合有 3 护甲 | 保留量为 3，下一玩家回合初先由护甲增加 3，再兑现挂起的 2。 |
| 满行动条时还有待结算配对或移动；敌人意图为多段攻击 | 玩家操作链完整结束才切换。整个敌人意图只占一个敌人回合，定时中毒至多一次。若其中一段结束战斗，后续结算停止。 |
| 敌人有 3 护甲、2 格挡、4 层中毒，并有易伤 | 定时中毒造成 4 点状态伤害，抵掉 2 格挡并扣 2 生命，护甲仍为 3。 |

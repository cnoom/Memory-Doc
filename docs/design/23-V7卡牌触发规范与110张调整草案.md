## 1. 用户已确认的V7原则

1. **起始Run牌库**：打击×4（每实例基础6伤害）与格挡×4（每实例6格挡），共8份；去掉笔记和读书笔记；每份Run卡在战斗中生成两个实例，初始恰好16张填满4×4。
2. **仅同名配对**：删除异名30%共鸣及所有跨名匹配通道；不再配置 `[共鸣]` / `[剑]` / `[盾]`匹配关系。旧档历史行可保留兼容读取，但不得参与正常V7投放。
3. **默认配对效果**：每张正常攻击/技能牌都必须有无需标注触发时机的主效果，成功同名配对时两张实例各执行一次；不存在共享的“整对触发”效果，也不印 `[配对]` 字样。
4. **同一不可变快照**：成功配对瞬间冻结双方卡牌的实例强化、力量、目标状态、易伤、格挡/护甲、条件判定及**伤害数值**。双方均以同一快照计算自己的输出及触发资格，第一张本次给予的力量、毒、流血等不反过来改变第二张的本次结果；随后原子准备并按确定性顺序提交伤害事件/状态，敌我共用的格挡、护甲只能实际扣减一次，不得重复抵扣。多段命中、流血衰减、死亡短路及下次攻击准备效果需要实现侧定义稳定顺序，并用专项测试验证；伤害结算不可回读本次中途修改的力量或易伤。
5. **触发时机**：`[翻开]` 为每次真实背面→正面时触发；`[翻回]` 为每次真实正面→背面时触发；`[移动]` 为实例所在格发生有效变化时触发；`[离场]` 主要作为清理与去向事件；查看详情、临时预览及纯动画不算状态变化。默认主效果在配对时执行，不写触发标签。
6. **学者「融会贯通」改为翻回**：每次实例真实翻回时，使该实例可强化的**有益固定数值**+1，最多2层，任意来源翻回均可；离场清零；不增加段数、次数、条件门槛、转换比例、百分比或负代价。与卡牌自身的 `[翻开] 临时伤害+1` 等独立累计。
7. **临时**：明确指当前战斗卡牌实例持有的可累计强化，翻回不清、离场清零；不等于只持续一次翻牌。对于依赖某次翻开锁定的蓄步兑现，以具体卡文的覆盖/刷新规则优先。**移动蓄步无上限**，玩家与敌方造成的真实位置变化均计数。
8. **移除主动资源支付**：不再设计“可消耗格挡/护甲/中毒/流血/灼烧/冰冻/生命，以换效果”的选项；改为自动检查快照条件并触发奖励，状态本身固有衰减（例如流血命中后-1、灼烧触发后-1）仍按状态规则进行，不能混为支付。
9. **[消耗]暂存待裁决**：它指本场成功配对正常离场后进入消耗堆、不再洗回的卡牌去向属性，**不是支付资源**。在用户明确裁决删除此牌区机制前，本草案暂沿用V6已登记的21张并标“耗”；这21张的一次性平衡和替代方案尚未通过审阅。
10. **简化条件**：优先采用当前实例经历、已持有力量/格挡/护甲、敌人已有单一状态的即时条件，减少“上一组配对”“几种不同名称”“双方均已回访”“行动窗口”“格位组合”等复杂复合门槛。所有职业共用110奖励牌，不重启能力牌类型。

### 1.1 玩家可选移动的统一交互（2026-11-17 确认）

> **V7操作简化裁决**：每个卡牌实例**每次效果触发最多提出一次移动请求**；取消单张效果内部需要连续完成两次或更多次选格的流程。两张同名卡仍分别触发自身移动效果，因此一次成功配对最多可顺序出现两次移动选择；不把两张卡合并成“整对移动一次”。

1. **入口**：只有正常配对默认效果或 `[翻开]` 等明确写有“可移动/可交换”的效果产生请求；不提供不消耗机会的自由移动按钮。纯数值收益（攻击、格挡等）与是否移动相互独立。
2. **交互统一**：战斗结算在移动请求点暂停 → 高亮合法**背面、非病毒**的来源牌 → 玩家选择来源 → 高亮合法目标位置 → 玩家选择目标或取消来源重选 → 提交移动/交换 → 按逻辑位置更新并播放可追踪动画 → 继续剩余结算。可“跳过”本次移动；无合法候选时直接略过，不阻断战斗；不会随机代选。
3. **一般移动**：来源牌上下左右正交相邻1格；空格直接移入，合法背面牌则两者交换；不许斜移、越界、使用正面/病毒/封锁牌。**X37「穿书」例外**：使用**相同的来源→目标双点击界面**，但允许任选另一张合法背面牌作为交换目标，不要求相邻；一次交换仍只是一项移动请求，不额外提供第二步。
4. **顺序与快照**：配对成功先固定两张牌的条件和伤害快照，之后卡A、卡B按稳定顺序分别处理其移动请求；第二次请求必须基于第一次移动后的**最新棋盘**重新生成合法候选。移动产生的即时后果（如X36交换后获得护甲、X38交换后施加流血）按本次实际操作兑现，**不得改写已锁定的本对伤害、力量或状态条件**。如配对伤害已导致战斗终局，则不再请求移动。
5. **计数与费用**：来源移动至空格，来源蓄步+1；两张背面牌交换，双方各+1；每次原子移动事件每个实际改变格位的实例最多+1；不按移动距离计数。跳过、非法选择、目标仍在原地、动画过渡不计数。移动本身不单独增加敌人行动条；待所有选择完成后再继续敌方行动检查。敌人造成的真实背面位移也按相同规则累计，无上限。
6. **可理解性**：来源/目标只依据可见合法位置，不泄露卡面身份；移动过程应显示位移轨迹。选择期间拦截新的翻牌/重铺指令；过期或非法提交不改变棋盘、保持选择可重试。每次只处理一项请求，不弹出多个选择窗口。

## 2. 卡面与详情显示规范

**标准展示实例（S04 探卷）**：

> **探卷**  
> 普通 · 攻击  
> 造成2段2点伤害。  
> `[翻开]` 临时伤害+1。

实例累计翻开两次、无其他加成时，动态显示为 **造成2段（2+2）点伤害。** 基础值固定可见，括号内第一个数是基础单段伤害，后续数字按来源展示正负修正；无增益则不加括号。两个实例分别展示自己的增益。色彩用于辅助辨认但不应成为唯一的区别途径。力量等外部加成可在详情中分项披露（例如 `2+2+3`），必须和战斗配对快照对齐，不应只是客户端自行猜数。多段计数、治疗、格挡、状态层数采用相同原则。

详情关键词：`[翻开]`＝每次真实翻开后执行；`[翻回]`＝每次真实翻回后执行；`临时`＝本实例累计，离场后消失；`[移动]`＝有效格位变化；`[消耗]`＝待审的一次性离场属性。触发词条的说明应可在复用卡牌详情面板中查看；背面卡详情不能泄露背面隐藏身份。

**展示与快照例**：两张各造成5点伤害并获得1层力量的牌，在配对前力量2时，双方本次各计算7点伤害、总14，结算后力量4；本次获得的力量不追溯抬升本次伤害。卡牌A/B的快照值须分开保存，不能把A成长复制到B。

## 4. 特殊负面卡与兼容边界

- **诅咒4种**（非正常奖励）：遗忘（翻开失去2生命并移除）、混乱笔记（翻开随机交换2张桌面牌并移除）、拖沓（翻开敌行动条+2并移除）、误解（翻开失去1生命、敌方+2护甲并移除）。
- **病毒3种**（非正常奖励）：腐化种子（翻开对玩家造成3伤并移除）、记忆尘埃（翻开敌行动条+2并移除）、虚空裂痕（翻开对玩家5伤、随机换位并移除）。特殊负面牌不用强制满足正常奖励牌的默认配对收益。
- 旧 `笔记`、`读书笔记` 和旧能力牌、旧 `[共鸣]` 定义在实现仓可能仍用于旧档解析；V7必须新增存档兼容和不再投放验证，而不是直接按卡名覆盖旧行。

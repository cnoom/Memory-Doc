# 美术预览资源

本目录保存候选、组合审阅与检查输出。实际状态以用户确认记录及 [开发资源索引](../docs/design/art-inventory/developer-asset-registry.json) 为准；已确认资源可能在此保留原预览，不能只凭目录判断最终状态。

流转：按类型预览 → 用户明确确认 → Assets/UI 按类型收录；被替换或落选的预览归档至 `_archived/日期/类型/`。校验通过不是发布许可，不得将整个目录复制到游戏运行时资源目录。

开发规范见 [13·开发AI美术资源使用说明](../docs/design/13-开发AI美术资源使用说明.md)。当前 A01、B01 等未确认的独立候选仅可用于有明确标识的开发审阅；B02不作为最终视觉外观。

2026-10-15，待审组合参考，1920×1080。未发布到 Assets/UI 或美术资源v1。

三张卡牌使用现有正式插画与框：火球术D07+C04普通攻击框、连锁雷D09+R01罕见攻击框、魔力共鸣D10+R02稀有技能框。插画按每个框自己的窗口遮罩裁切，卡框保持原比例。两件遗物使用记忆水晶E01、连锁核心E02。商品与移除按钮使用B03。完整来源及SHA256见assets.json，合成时已核对正式批准状态和文件哈希。

卡名、效果、稀有度、商品价格由文字层渲染；浅底文字#252F32，按钮文字#F1EEE2。当前系统微软雅黑仅用于排版检查，未分发字体。正式字体仍按项目规范选择。单卡显示350×467，阅读不足时需提供悬停/聚焦放大，原尺寸单卡检查图另存card_1_review.png至card_3_review.png。

底板经内置imagegen从K01移除占位商品生成，提示词见final-prompt.txt；源1672×941适配1920×1080。顶部、分区标题、底部离开按钮和移除装饰仍是底板示意，不是独立正式组件。此图并非全屏运行时成品。

复现：运行 tools/art/scripts/compose_shop_k02.py。脚本仅组合现有PNG、遮罩和独立文字，不重绘正式卡牌及遗物。规则与价格沿用K01。确认后再进行无字底图拆分和购买状态设计。

## 分层与几何

攻击卡框不包含插画、卡名、类型或数值。实际插画开口包围框为x156/y299/w649/h498，边缘有角饰及顶部刻纹，不是完整矩形。不能复用B01的x64/y250/w832/h430，也不能把四角外透明当作插画窗。

辅助遮罩illustration-window-mask.png与卡框同为960×1280，来自封闭插画开口内的alpha反相，外围为透明；不改动卡框原alpha。渲染顺序：原插画和骨白补底→窗口遮罩→卡框→独立文字。保持同一原点、不分别trim。插画优先contain，避免裁掉剑尖。

文字安全区（源像素）：标题x235/y153/w545/h107；效果x180/y858/w600/h192。144px预览标题15px、96px预览10.5px；仅打击样例通过本轮目视检查，长卡名／多词条在后续类型扩展与实机接入时还需验证，不能宣称全卡池排版已完成。

统一卡背只使用这张相同纹理与UV，不按隐藏卡类型、稀有度、病毒或实例随机改变颜色／磨损。它只有外边透明，中心保持不透明。

## 规则

按06§3：通用21与学者奖励29的混合池抽取，三张各自独立按普通60%／罕见30%／稀有10%抽档，再抽不同卡牌；不含诅咒与病毒。图中三档各一张仅是展示不同卡框的示例，不保证每次各一档。牌库已持有卡可再次获得，候选三张互不相同。

点击卡牌仅选中，确认后将所选单张加入牌库；其余两张未获得。例中牌库10→11，不按战斗副本×2计数。学者获得卡牌的共鸣附加判定按真实数据结算，结果页应显示最终附加状态；本例未触发。跳过不加牌并完成卡牌奖励，不撤回其他已结算奖励。

未选中时确认禁用；选中后可切换，使用灰蓝描边及文字“已选中”。键盘焦点和选择分离；卡面可悬停/聚焦放大。提交成功即锁定奖励，不能通过连续点击重复领取。领取或跳过后的结果稿用于展示反馈，可由客户端短暂展示后继续或通过继续按钮推进，不新增奖励逻辑。

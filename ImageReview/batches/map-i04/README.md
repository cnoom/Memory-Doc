## 详情页行为与内容限制

三个页签框架统一：个人信息、当前卡组、遗物。返回地图/Esc关闭后保留原节点焦点；页签切换保留各自筛选、选中项与滚动位置。当前卡组按同名且同升级/附加状态分组，计数按单份牌库，不按战斗×2。列表支持滚动、无匹配空态；遗物为空时显示“尚未获得遗物”。详情区域显示完整效果文本，可滚动。

三张生成稿仅确认信息结构、纸层密度与布局方向：头像、卡框、卡图及遗物图均为示意，正式制作必须换成已批准资源；高亮应使用#648891细线而非图中亮蓝光晕。页签位置以统一顶部栏为准，不能逐图各自布局。卡牌效果与角色被动的生成文案为简写占位，必须读取当前策划/客户端数据；遗物效果区尚未填写真实规则。个人信息示例52/60生命、50金币不是固定数值。

## 客户端文字

文字独立渲染，sRGB、不透明度1。正文/浅底按钮#252F32，深底标题与选中页签#F1EEE2，辅助/提示#48575A，浅底禁用#657174，错误#8D3D35。高亮线#648891，纸底#E7E5D8。思源宋体用于标题和按钮、思源黑体用于密集数值；字体文件不在本批。1920基准标题40、页签30、正文26、辅助22像素；不得通过缩小字体塞入溢出内容。

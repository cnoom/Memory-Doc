# I02 地图界面修订

2026-10-14，待审；本版取代I01三栏提案。用户明确取消“下一站”栏，玩家常驻信息仅需血量和详情入口，当前卡组、遗物、详细个人信息收进详情页。

布局：顶部血量、章节和旅途详情；中部18节点地图；底部节点用途与路线状态图例。不再显示金币、牌库计数、头像或遗物侧栏。

节点必须显示类型名称。悬停/键盘聚焦显示就近说明，包含用途、状态；可达节点点击或Enter直接进入，不使用远端前往按钮。触屏首触显示说明、再次触碰同节点进入。不可达节点仅显示说明，不能进入。此规则替代I01右栏确认交互。

节点说明：战斗—迎战敌人，胜利后获得奖励；精英—更强的敌人与遗物奖励；事件—未知遭遇，作出选择；商店—购买卡牌、遗物或移除卡牌；篝火—休息恢复生命或升级一张卡牌；Boss—本章最终挑战。具体敌人/随机事件内容仅在策划允许时公开。

旅途详情页信息架构：个人信息（角色、生命、金币、被动及当前旅程信息）、当前卡组（按单份牌库计数，不显示战斗复制份数）、遗物（持有列表与效果）。打开与关闭均保留地图焦点和滚动位置。本次只修订地图示意，详情页尚未单独绘制。

字体色沿用H03：浅底正文#252F32，深底顶栏#F1EEE2，辅助#48575A，浅底禁用#657174。节点状态必须结合线型、标签、边框，不只靠颜色。

图片使用内置imagegen编辑I01，原生1672×941，等比适配1920×1080，非原生1080p。图中浮层位置仍有遮挡邻近节点的概念稿局限；正式客户端必须自动避让节点及文字、必要时向左右空白区移位，不能照搬固定位置。实际路线由种子数据绘制，图中线条不作程序拓扑。Boss头像为示意，正式换已批准记忆吞噬者资源。

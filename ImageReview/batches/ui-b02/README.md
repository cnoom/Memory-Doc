# UI 组件 B02 · 待审预览

依据已确认的《11-美术设计方案》与战斗 V02 制作；全部为原生 SVG 组件及 PNG 导出，无 AI 生成文字，无纹理噪声。未发布到 Assets/UI，B01 也未因本次制作而自动发布。

## 内容

40 项逻辑资源，80 个源文件：12 张按钮底图（主/次/危险 × 常态/悬停/按下/禁用），4 张面板，5 张生命/行动条组件，7 张设置控件，2 张卡牌覆层，2 张底签，8 枚功能图标。资源分类存放于 ImageReview/buttons、panels、bars、controls、overlays、badges、icons。

审阅页 index.html 展示状态与组合，支持暂停弹窗、Esc 关闭、开关、复选框、滑条、行动临界切换。数值是样例，不是游戏数据源；不代表实现了游戏功能。控件不保存设置。卡背复用 B01 预览，包内以原路径附带，非本批新增。

## 导入与排版

- 精确规格见 assets.json。slice 顺序为左、下、右、上，单位为源图像素（Unity Sprite Border 顺序）。按钮切片为 28/28/28/28，面板为 20/20/20/20。透明外角保留 alpha。
- 按钮 960×208，常见显示 240×52；面板 512×384，可九宫格延展，不能直接拉伸角部。固定切片宽度按 UI 缩放系数换算，避免将源像素直接当作显示像素。
- 面板内容至少留 24 显示像素内边距。文字、数值、图标、分隔线单独排版；资产不包含中文与数字。按钮长文案优先增宽，不能无限缩小文字。
- 生命条将 track 和 fill 分层，填充用遮罩裁切；行动格按实际阈值生成，显示当前值/阈值。示例的 10 格不代表所有敌人阈值相同。临界颜色改变也需保留数值说明。
- 开关 64×32、复选框/滑块 32×32 为显示建议；点击区域可独立扩大。滑条轨道与填充显示高度 8，滑块独立叠放，随数值移动。
- 覆层源图 960×1280，与 3:4 卡牌等比缩放，禁止九宫格拉伸。悬停不移动卡牌；封锁仅限制配对，不画成禁点；标记只公开 ×N，不能泄露背面身份或增益。
- 标记底签建议显示 64×28，符号在左、层数在右。过大计数应独立增宽文本底签，不能挤压卡名；不要依赖本样例的两位占位限制规则。
- UI 图标 128×128 导出，显示 32×32。默认深墨适配浅底；深底用 SVG 修改 stroke 为骨白，或在引擎中用 alpha mask 的纯色材质重着色。不要依赖普通乘法 tint 将深色 PNG 变白。格挡盾形与 B01 护甲胸甲不同。
- 按钮禁用不接受输入，并在具体流程旁解释原因；本页四态对照为静态样张。键盘焦点由 UI 层提供高对比轮廓。危险操作的具体确认流程由功能定义。

## 验证与源文件

生成：tools/art/scripts/build_ui_b02.cjs。审阅页：build_ui_b02_gallery.cjs。浏览器检查：check_ui_b02.cjs。

asset-validation.json 记录尺寸、alpha、哈希与切片边界；browser-validation.json 记录图片加载、1280×720 横向溢出、常态/临界与控件交互检查。PNG 使用无损 RGBA，无预乘底色加工；引擎实装仍需按实际 Canvas/字体再校验。

本批补充基础 UI 组件，不包含地图节点、遗物插画、整屏背景、完整动画或全流程页面。新资源经本批确认后再收录正式目录。

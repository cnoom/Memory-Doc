# K04 移除卡牌选牌流程

2026-10-15，待审组合参考；无新增独立美术，不发布为运行时整图。

selected.png与unselected.png均1920×1080。复用A03纸面板（四边32px九宫格）、B03按钮、已确认卡图及对应卡框。背景为K03组装预览，黑色遮罩透明度约0.65。脚本tools/art/scripts/compose_shop_k04.py可重建。

列表展示的是玩家牌库，不是商店货架。本图4张牌仅为小牌库示例；按卡牌实例单独选择，同名卡不合并以免丢失升级和词条差异。正式需加载实例的真实状态，较多卡牌在左侧区域滚动，右侧预览与底部操作固定；卡面支持悬停或聚焦放大。

选中后右侧预览目标、牌库张数和金币变化。移除只影响库内1张；战斗份数按05文档派生。点击确认才扣75金币并移除，取消、关闭或Esc不扣费。未选中、余额不足或无合法卡牌时确认禁用。确认前重新验证目标与余额，完成后返回商店并刷新相关数据。可移除范围及服务次数由游戏规则提供，本预览不新增限制，也不套用事件的随机非诅咒目标规则。

客户端坐标：模态面板(130,105,1660,870)，列表起点(185,350)，卡牌245×327，横向步长250；右侧信息x1260，分隔x1210。取消(1045,862,300,52.5)，确认(1390,862,320,56)。按钮命中高度至少48。关闭命中区需明确配置，不能只依赖文字像素。

颜色：正文#252F32，辅助#48575A，深底按钮字#F1EEE2，浅底禁用按钮字#485356，选中描边#648891，选中标签#355C67。标题42px、正文25—26px、按钮24px、卡下名称21px。预览使用系统微软雅黑，不分发字体；最终使用项目字体。所有文字独立渲染。

与K03一样，本批仅验证视觉和流程方向，不代表游戏实现或引擎接入完成。

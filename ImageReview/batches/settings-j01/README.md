2026-10-14，待审视觉参考。对应09文档S13设置模态：声音、画质与操作说明。沿用骨白纸层、冷墨灰与灰蓝强调；1920×1080。

左栏三条音量滑杆与低/中/高画质选择，右栏操作说明，底部恢复默认与完成，右上关闭。主菜单、地图、暂停菜单可共用该模态，背景为进入前页面的暗化层，不固定为图中遗迹。游戏中打开阻止底层输入并暂停战斗计时；从暂停菜单打开，关闭后仍停留暂停菜单。

音量0—100，0为静音；拖动即试听并更新数值，释放保存。方向键微调、Home/End到边界；具体步长建议1%。画质按客户端现有档位执行，示例“中”不规定项目默认。完成、X和Esc均保留已调整的设置并返回来源页；恢复默认先确认，仅重置设置，不影响存档。80/60/80为展示值，不是默认值。

操作说明不代表按键重绑定。正式文案区分“翻开背面牌：鼠标左键”和“查看正面牌详情：点击正面牌”，避免示意稿简写的“选择卡牌/查看详情”混淆；Esc按页面关闭弹窗或打开暂停。客户端应以实际输入绑定生成说明。

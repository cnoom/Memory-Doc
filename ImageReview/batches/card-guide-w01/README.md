# W01 卡牌美术实现指导

2026-10-21。配套图：`card_art_guide_2400x1800.png`；机器可读坐标：`frame-specs.json`。本批为待审指导文档，保留在 ImageReview，不是新增运行贴图。所引用卡框、插画、字体均为已有正式资源。本图不改变游戏规则，也不代表客户端已验收。

## 1. 输入与资源选择

客户端从卡牌数据读取类型、稀有度、名称、效果、强化状态与实例标记，分别渲染。不要把整张指导图或带字示意卡裁下来用作游戏卡牌。

正式资源以 `docs/design/art-inventory/developer-asset-registry.json` 为准。本批 JSON 的路径相对项目根目录；导出包使用导出索引解析，不拼接本批路径。`sourceSize` 是实际运行 PNG 尺寸，`spec.sourceResolution` 如存在，仅是原始生成图尺寸，不能用于布局。

## 2. 坐标、遮罩与合成

所有卡框画布为 960×1280，原点左上。标题安全区为 `(235,153,545,107)`，描述安全区为 `(180,858,600,280)`，均按 x、y、宽、高解释。安全区是文字不可越过的范围，不是背景色块。

每个框必须加载其 `spec.windowMask`，并使用该框自己的 `spec.window`。例如普通攻击窗口为 `(156,300,649,496)`，其他框略有差异，不能共享同一窗口或遮罩。窗口外接矩形不是实际轮廓；框外透明角也不是插画窗口。

推荐合成顺序：

1. 创建透明 960×1280 卡片容器。
2. 插画等比 cover 到窗口外接矩形，初始居中。检查脸、武器等主体，必要时为单张插画配置裁切焦点；不能拉伸。若 cover 无法保全主体，再调整该卡的布局配置并审阅。
3. 将插画放入窗口位置，最终 alpha = 插画原 alpha × 专属 mask / 255。遮罩只约束插画，不裁掉卡框本身；不得把整幅卡框透明区当成遮罩。
4. 叠加正式卡框，再独立渲染标题、效果，最后叠加状态标记、焦点提示。

插画里的骨白底色是风格组成部分，不进行自动抠白。卡框禁止九宫格和非等比缩放。若打入图集，保留原画布坐标或补偿 trim 偏移，遮罩和框保持同一变换；同时验证图集采样边缘无串色。

## 3. 字体、颜色与不同尺寸

标题：`Assets/UI/fonts/q01/SourceHanSerifSC-Regular.otf`；正文：同目录 `SourceHanSansSC-Regular.otf`。标题与短效果居中，长词条在描述安全区内分行；换行不得把数值与其单位拆开。完整卡文应来自当前实例数据。

| 用途 | HEX |
|---|---|
| 标题、正文、关键数值 | #252F32 |
| 辅助说明 | #48575A |
| 焦点提示 | #648891 |
| 损失、负向提示 | #8D3D35 |

颜色不能作为唯一的信息标识；详情和奖励提供稀有度文字。不要把图里的红蓝标注矩形画到实际卡面上。

显示宽为 W 时，缩放系数 s=W/960，高为 1280s；各坐标和安全区乘 s。位置与字形应由界面布局直接渲染，避免把带字大卡截图整体缩小。

- 1080p 战斗参考：144×192；720p 等比参考：96×128。先保证卡名和关键数值，完整效果通过详情查看。U01 的 13/11px 仅为现有样例，不是已经验收的最低可读字号。
- 奖励参考：380×507（高度四舍五入）；详情按容器等比，并为完整词条保留独立文本排版。
- 指导图示例在源画布上使用标题 70px、正文 48px，仅说明构图；不能把它们简单乘 s 当作小卡字号规范。
- 遇到长卡名、多词条，先换行或使用详情承载完整内容，不无限缩小字号，也不溢出到饰边。最终字号、最大行数和交互展开方式需按实机验证，不能以本图宣称已验收。

## 4. 状态与信息约束

- 翻背状态不能暴露类型、稀有度、病毒或隐藏词条；统一卡背。已知标记的背面仅显示 ×N。
- 标记纸签使用 `badge_mark_paper_b03`，配对封印使用 `seal_pairing_b03`；状态层独立，不盖住标题、效果和关键数值。
- 封锁不等同于禁止查看详情。焦点、选中和不可操作态需要区分，不能用同一种灰色覆盖所有状态。
- 强化复用原插画；文字取该实例强化后数据。图中“造成6点伤害”仅为单卡示例，不重新定义配对结算或强化计算。
- 多个状态同时出现时验证位置冲突；本指导没有新增状态图标或重新规定游戏交互。

## 5. 客户端验收

核对 10 个框及其 mask 是否一一对应，按索引校验文件哈希。分别测试普通、罕见、稀有、诅咒；测试短名、长名、多词条、强化、翻背、标记、封锁和状态叠加。

在实际 144px 卡宽和 720p 缩放下检查文字，不只看放大截图。浅底与深底分别检查透明边缘、插画裁切、字体回退、图集偏移与状态遮挡。与现有 U01 战斗布局对齐，逐层比对框、插画、文字与状态；未完成实机检查时记录为“未验证”，不要记录为已通过。

通过标准：不拉伸、不用错框/遮罩、不裁掉主要主体、不溢出饰边、不泄露背面信息；完整描述可通过详情读取；动态数值与实际实例一致。

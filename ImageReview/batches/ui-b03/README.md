# UI 精修 B03：战斗信息区与暂停弹窗

状态：用户已确认（「可以，就这个风格吧」）。本批 11 项组件与组合截图已收录 Assets/UI，作为后续 UI 风格基准。用户认为 B02 过于简单，本轮依照确认的精修方向制作组合样张，增强纸层、装订、刻痕和压印。保留 B01/B02 原预览；本次确认不自动发布其他批次。

## 设计变化

- 战斗信息区增加图鉴页眉、装订侧脊、错位底板；敌人展示的圆形辅助线与竖排批注保持低对比。
- 生命条为细长连续槽，行动条为独立刻槽，右端复用断环主题。临界以朱红填充并显示 9/10、距行动 1 点，不增加实时倒计时。
- 暂停弹窗采用三层错位纸页、左侧装订、细线页眉和断环题饰；文字区留净。
- 主次按钮各提供常态、悬停、按下、禁用四态，增加双线框、切角、两端刻痕和墨影。文字仍由界面单独排版。
- 标记为雾蓝批注纸签，只显示层数；封锁使用独立六角印。封锁限制配对，仍允许翻开。

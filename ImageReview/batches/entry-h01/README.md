## 主界面行为

- 有有效存档：默认聚焦“继续旅程”，摘要显示真实角色、章节和最近完成节点；图中内容为示例。继续恢复到最近节点完成态，未完成战斗依既有规则从进入前重打。
- 无存档：隐藏继续入口与摘要，将“开始新旅程”提升到首位，其余入口顺序不变。
- 新旅程进入角色选择。有旧存档时先提示“开始新旅程将覆盖当前旅程”，默认聚焦“取消”；确认新旅程后才替换存档，取消保留原存档。
- 设置返回时恢复原焦点；退出使用确认弹窗，默认取消。
- 默认态骨白纸面与墨线；悬停/键盘焦点显示暗红书签及清晰外轮廓；按下轻微下沉；禁用降低对比并说明原因。不只靠颜色区分状态。
- 键盘上下切换、Enter确认、Esc关闭弹窗；鼠标与键盘焦点统一。

## 加载行为

- 用于启动或场景资源切换，不为普通面板开关增加整屏加载。沿用现有≤2秒软目标，不人为延长展示。
- 图中68%只是示例。可测量任务使用真实进度，单调递增；不可测量时隐藏百分比，使用书页循环和状态文字，不显示虚假百分比。
- 完成后自动进入目标场景，无需额外按键。短于约200毫秒的切换可直接过渡，避免闪屏。
- 提示文案在一次加载期间保持稳定：“记住位置，让每一次翻牌更有把握。”
- 失败时停止进度动画，显示简明原因、“重试”与“返回主界面”；保留存档。启动阶段无法进入主界面时提供重试或退出。
- 翻页/浮纸动效建议低幅、无闪烁；减少动态效果选项下静态展示。动效尚未制作。

## 适配与待制作项

以1920×1080为唯一设计基准；其他16:9分辨率整体等比缩放。非16:9视口保持UI安全区，背景可向外扩展或裁切，禁止横向拉伸按钮、文字与主体。

后续需制作无字背景、标题字标排版、按钮与书签状态、独立进度条和翻页动效；本批仅完成两屏视觉与交互方案。未经用户确认不发布到Assets/UI或美术资源v1。

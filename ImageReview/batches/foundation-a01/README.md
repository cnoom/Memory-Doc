## 组合与复核

背景、敌人、学者、HUD各自独立。预览底部支持隐藏立绘、在史莱姆/训练假人/哥林布间切换；同步名称、生命、基础攻击、阈值。切换其他敌人时禁用仅针对史莱姆的临界/详情演示，避免把35生命/10阈值套到其他敌人。不是完整战斗模拟。

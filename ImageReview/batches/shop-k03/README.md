正文#252F32；深底文字#F1EEE2；辅助#48575A；B03禁用主按钮底图为浅色，文字#485356；错误提示#8D3D35。禁止全组降低透明度导致文字不可读。标题42px，正文23—30px，常规按钮24px、小按钮20px；卡文在960×1280源画布用55px等比缩放，提供悬停/聚焦放大。系统微软雅黑仅为组装检查字体，不随资产分发，正式按项目字体配置。

## 状态与交互

按钮复用B03 normal/hover/pressed/disabled。价格实时取配置，余额不足保留价格并说明“不足”，禁止扣款；售罄替换按钮文案，保留商品方便查看。购买成功后刷新余额、库存和所有按钮状态，避免重复结算。离开完成节点且不可重入，不提供刷新功能。详情入口仅打开当前旅途信息。

移除服务点击后进入选牌流程，不直接扣款；选牌页面与确认流程仍待制作，本批不视为已完成。预览不是游戏实现，实际业务规则以05文档为准。

底图使用内置imagegen编辑，提示词见final-prompt.txt；状态预览由tools/art/scripts/compose_shop_k03.py组合正式PNG和独立文字生成。底图与商品、文字、按钮在客户端分层加载。

## 分层

1. 背景：`../backgrounds/bg_main_menu_h03.png`、`../backgrounds/bg_loading_h03.png`。无UI文字、按钮或进度条；人物和书本仍在背景中，不支持独立骨骼动画。内置imagegen编辑H02产生，源图保存在原项目ImageReview/batches/entry-h03目录；1920×1080交付经等比缩放适配，非原生1080p。
2. 按钮：直接使用 `../buttons/btn_primary_{normal,hover,pressed,disabled}_b03.png` 与 `btn_secondary_{normal,hover,pressed,disabled}_b03.png`。不从概念图抠按钮。原尺寸640×112，建议等比显示512×89.6，不设未经验证的九宫格参数。

index.html支持逐项播放与明暗背景切换。预览图形为整张纹理运动，碎纸不包含独立粒子轨迹，火焰不是逐帧序列。正式引擎可使用同样的基础变换；减少动态时取消位移/缩放，保留短暂淡入淡出即可。篝火原背景已有火焰时需要避免双重叠加，必须实景确认位置和范围。

使用普通Alpha混合保留黑墨刻线，不默认Additive。贴图保留原生分辨率；客户端按需要生成图集和边缘扩展，保持透明边距。建议命中/消散128–240px、治疗200–320px；火焰按场景比例。数值是1080p参考，非游戏规则。

贴图无文字。客户端伤害文字#8D3D35、治疗文字#355C67、深底正文#F1EEE2，均独立渲染。治疗环和火焰的生成色比提示词更鲜明，仍需审阅；未声称精确匹配HEX。Boss三阶段静态图均已收录。

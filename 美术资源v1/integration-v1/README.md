# v1 客户端接入与视觉一致性验收

更新：2026-10-17。此文件是接入约束与验收方案，不是新的美术审批，也不表示客户端已经通过验收。基准画布1920×1080，风格细节V05，基础组件B03。

## 1. 唯一入口与冲突处理

先读本文件，再加载交付包资源索引.json与设计参考索引.json；仓库内对应docs/design/art-inventory/developer-asset-registry.json。正式独立资源与组合参考必须分别使用。文件名相似、目录存在或历史README写“候选”，均不能代替最新索引状态。

优先顺序：用户最新确认 → 当前索引的批准范围与资源元数据 → 本文件及对应页面最新接入说明 → 已确认参考图的视觉构图 → 历史文档。玩法数值、随机规则、状态来自最新策划数据；参考图仅固定视觉，不固定样例数值。发现同一层级冲突须记录，不默默混搭。

旧09/10文档中的青金色、拱窗、B01旧框及早期候选状态属于历史。正式卡框是C04/C05及其稀有度变体，窗口、遮罩、文字安全区逐ID读取spec。禁止统一使用旧B01窗口坐标。不得把全透明像素都当插画窗口。

## 3. 布局与图层契约

- 1920×1080是首次验收基准。参考中的x/y/w/h为左上原点、向右/向下的逻辑像素；不是源贴图像素。源图切片与窗口数据另看索引。实现时记录锚点和pivot转换。
- 背景等比裁切；人物等比contain；卡面保持3:4；按钮B03保持640:112比例。不得独立拉伸宽高。只有明确提供slice的普通面板使用九宫格。手记结构各层共用父容器和原始偏移，不单独trim后居中。
- 稳定层级：背景→路线/场景→人物→面板→内容图片→文字/数值→选中/焦点→弹窗/提示。卡牌内部为插画+对应遮罩→框→文字→允许的状态覆盖。特效放在目标对象上方、读数下方，避免遮住文本；封锁不能盖掉描述。
- 固定卡阵的格心，悬停不放大挤压；地图只保留血量和详情入口，不恢复废弃的右侧下一站栏。旅途详情使用P01真实资源稿，不使用I04早期占位稿。
- 720p可先按2/3映射，随后检查文字；不能承诺所有页面已有720p确认稿。其他宽高比需提交适配截图，禁止拉伸整个界面。重排时保留语义关系与阅读顺序。

## 4. 字体与颜色

正式字体：fonts/q01/SourceHanSansSC-Regular.otf、SourceHanSerifSC-Regular.otf；携带对应许可。禁用系统默认字体无提示替换，禁止伪造已交付Bold字重。页面有明确字体角色时遵从页面；未规定时标题用宋体、正文/数值/按钮用黑体。地图原说明明确标题与按钮宋体，是页面差异而非全局覆盖。

正文#252F32，深底文字#F1EEE2，辅助#48575A，深主按钮禁用文字#485356，浅底禁用#657174，焦点线#648891，损失/错误#8D3D35，治疗/结果强调#355C67。页面client-tokens或client-layout若有更具体token，按具体用途覆盖；不能把disabled颜色不分底色合并。颜色使用sRGB，正文透明度1。

字号、行高、字距、对齐和文本框宽度均需记录。字体迁移后先调文本框和换行，再检查布局；不靠无限缩小字号容纳长文。卡牌正文溢出应转详情/滚动；按钮文案不截断关键动作与代价。旧示意图用系统字体的页面，允许字形变化，但须交付字体替换后的同状态对照图。

## 5. 状态与真实数据

按钮normal/hover/pressed/disabled及键盘focus必须可区分；禁用要停止提交。奖励确认后阻止重复发奖，弹窗阻断背后输入。状态变化不应无故改变面板高度或整体位置。

最少检查：奖励未选/已选/领取/不足/空池；商店余额不足与售罄；强化无候选及原卡对比；详情空列表与长列表；事件2或3选项、长叙事、卡牌/遗物/金币结果；Boss阶段切换与长复合意图。不要为尚无参考的状态套用虚构规则。

## 6. 尚未完全规格化的部分

当前并非每张稿都有逐控件JSON。排序展开、滚动长列表、全部悬浮说明、复杂文本溢出，以及非16:9适配仍需客户端布局验证。Boss各阶段精确pivot尚需实景标定；不能从透明包围盒自动推断脚底。特效单图形变不等于逐帧/骨骼动画。

这些项不能标记“像素级复现已完成”。客户端应先提交布局补充表（ID、父节点、矩形、锚点、资源ID、字体token、状态、溢出策略），再以截图确认。不要擅自添加玩法选项，亦不要因缺少一张状态图删掉既有功能。

## 7. 可复核的交付验收

1. 建立页面资源映射：每个控件关联准确asset ID，记录引用版本/hash，禁止从整屏截图裁切已有独立组件。
2. 固定测试夹具：分辨率、语言、字体版本、角色/敌人、卡组、生命、金币、奖励候选、阶段和交互状态。随机结果固定测试数据；不同数据截图不能直接作像素差异判断。
3. 保存“确认参考、客户端截图、50%叠加图、差异备注”四项，先比结构与对齐，再比文字与材质。允许字体抗锯齿和明确的数据差异，不能用整图相似度掩盖错框、错层或漏信息。
4. 建议1920基准下关键面板/格心位置偏差不超过2px；这是工程检查阈值，不是既有用户批准标准。超出应解释；明显错位、裁切和遮挡不因总误差小而通过。
5. 交付状态覆盖清单和未解决差异。没有目标客户端实际截图，只能标记“资源准备完成”，不能标记“接入验收通过”。
